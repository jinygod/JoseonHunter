# 로비·연구·전투 가독성 검증

## 적용 결과

- 로비에서 한연화 실사 이미지와 `한연화의 순찰`, `귀곡 야행`, `우두머리 출현` 문구를 제거했다.
- 출전 화면에서 편성 번호, 편성 전환, 편성 저장을 제거하고 현재 무기 아이콘·이름·좌우 전환·출전만 유지했다.
- 하단 메뉴는 `무기 연구`, `출전`, `공통 수련` 세 개를 유지했다.
- 모든 로비 버튼을 픽셀랩 기반 9-slice 버튼으로 통일했다.
- 무기 연구에 선택 무기 이미지, 초록 숙련도 진행 바, `현재 / 목표` 수치를 추가했다.
- 3단계 연구는 2단계 선행 해금을 강제하고 안내 문구를 정확히 `2단계 연구 완료 시 해금`으로 고정했다.
- 출전은 `Lobby -> Bootstrap -> Gameplay` 경로를 사용하며 로딩 화면은 최소 1.5초 유지한다.
- 씬 전환 코루틴 소유자가 파괴돼도 `GameSceneRouter.IsRouting`이 해제되어 승전 후 로비 복귀가 막히지 않는다.
- 경험치 획득 반경과 공통 수련 배율은 그대로 유지했다. 반경 안에서만 2.2에서 13까지 가속하고 실제 흡수 거리를 0.18로 줄여 빨려드는 시간이 보이게 했다.
- 경험치·엽전·자석·보물상자 표시 크기를 키웠다.
- 인게임 귀환 텍스트 버튼을 우측 상단 일시정지 아이콘과 `계속하기 / 로비로 돌아가기` 메뉴로 교체했다.
- 하단 무기 HUD를 4열 정사각형 아이콘 슬롯으로 교체했다. 레벨은 테두리 색으로, 잠재 옵션은 작은 그림 아이콘으로 표시하며 클릭 시 기존 상세 화면을 연다.

## 자동 검증

- Unity: `6000.5.5f1`
- 전체 EditMode: 633 / 633 통과, 실패 0
- 전체 PlayMode: 237 / 237 통과, 실패 0
- 출전 로딩 경로, 파괴되는 라우트 호스트, 승전 후 로비 복귀를 PlayMode로 검증했다.
- 기본 획득 반경 밖 1월드 유닛의 경험치가 움직이지 않고 트레일도 생기지 않는 것을 검증했다.
- 0.5월드 유닛의 경험치는 캐릭터 방향으로 이동하고 짧은 트레일을 생성하는 것을 검증했다.
- 720x1280부터 1440x3200까지 전투 HUD, 일시정지 버튼, 무기 슬롯, 모달의 safe-area 포함 여부를 검증했다.

## 시각 검증

- 유효한 런타임 캡처: `Artifacts/PortraitValidation/720x1280/01-gameplay.png`
- 720x1280 캡처에서 우측 상단 일시정지 아이콘과 하단 정사각형 무기 슬롯이 화면 안에 있고 글자와 겹치지 않는다.
- 로딩용 한연화는 상반신 근접 구도이며 양손과 손가락이 화면에 보이지 않는다.
- 정사각형 무기 슬롯은 검정·짙은 자주·금색만 사용하고 흰 테두리를 사용하지 않는다.
