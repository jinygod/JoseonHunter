## 해결한 원인과 동작

- 일반 몬스터가 넓은 단계 단위 무작위 목록에서 섞이던 구조를 경과 시간 편성으로 바꿨다. 0~45초는 쥐, 45~53초는 원한 처녀귀신, 90~100초는 도깨비를 집중 소개하고 이후 편성은 세 역할만 사용한다.
- 특수 몬스터는 일반 스폰 목록에서 제거했다. 방패 도깨비(102초), 돌진 쇠뿔귀(120초), 원혼 무당(138초), 분열 쥐(150초)를 한 번씩 소개한 뒤 일반 몬스터 8마리당 최대 1마리, 최소 8초 간격으로 재등장시킨다.
- 방패 도깨비의 근접 애니메이션 프레임 교체가 몸체를 검은 프레임과 번갈아 보이게 하던 원인이었다. 방패 몸체는 기본 스프라이트로 고정하고, 정면 직접 공격 6회의 확정 타격에만 줄어드는 청동색 내구도 막대를 추가했다. 후방·폭발·끌어당김·반응 공격은 방패를 우회하며 중복 충돌은 내구도를 중복 소모하지 않는다.
- 전승 카드의 장식 프레임 가운데가 투명해 전투 배경과 글자가 겹쳤다. 각 카드 안쪽 12px에 완전 불투명 한지 바탕을 추가하고 제목/본문은 먹색, 약점은 인장색으로 고정했다.
- 감정 화면의 짧은 `전승 경로/현재 경지/다음 경지` 표현을 `선택한 성장/현재 상태/다음 강화` 문장으로 교체했다. 성장 구조 안내와 `지금까지 적용된 효과 · ...` 행을 별도 배치하고 완료 상태는 `성장 완료 · 최종 효과 적용 중`으로 표시한다.
- 성능 테스트의 자동 스폰 차단이 새 특수 몬스터 소개 스폰에는 적용되지 않던 테스트 격리 누락을 수정했다. 실제 게임 스폰 규칙은 변경하지 않았다.

## 세로 화면 캡처

`PortraitStateValidationCapture.CaptureInBatchMode`를 `-nographics` 없이 실행해 아래 5개 해상도에서 게임플레이·레벨업·감정·복귀 전투 화면 총 20장을 생성했다.

- 720×1280
- 1080×1920
- 1080×2340
- 1170×2532
- 1440×3200

720×1280과 1080×2340의 실제 감정 PNG를 확인했다. 성장 안내, 첫 결과 상자, 세 성장 행, 확인 버튼이 한지 패널 안에 있으며 서로 겹치지 않는다. 누적 효과 행도 첫 결과 상자 아래의 독립 공간에 배치된다. 캡처 위치는 `Artifacts/PortraitValidation/`이며 생성물은 소스 관리에 포함하지 않는다.

기존 캡처 도구는 전승 선택 화면과 방패 소개 전투 상태를 만들지 않는다. 두 화면은 관련 PlayMode 레이아웃/렌더러 테스트로 검증했으며 실제 기기에서의 육안 확인은 남은 항목으로 기록한다.
