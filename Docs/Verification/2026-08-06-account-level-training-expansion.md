# 계정 레벨 및 수련 100강 확장 검증

검증일: 2026-08-06

## 구현 결과

- 계정 레벨 1~100과 누적 계정 경험치가 추가되었다.
- 한 판 정산에서 생존 시간, 처치 수, 승리 여부, 포기 여부를 바탕으로 계정 경험치를 계산한다.
- 계정 레벨 1당 총 수련 한도 5강이 열리고 계정 레벨 20에서 총 100강에 도달한다.
- 여섯 수련 트랙은 각각 최대 20강이며 전체 합계는 100강을 넘지 않는다.
- 1~5강 기존 효과와 비용을 유지하고, 6~20강은 체감 효과와 증가 비용을 사용한다.
- 로비 좌측 상단에서 계정 레벨, 계정명, 현재 레벨 경험치 바를 확인할 수 있다.
- 수련 화면은 총 단계/한도, 트랙별 20강, 현재·다음 효과, 비용, 강화 후 잔액, 다음 계정 해금 레벨을 표시한다.
- 전투 결과창은 저장 성공 때 획득 계정 경험치와 계정 레벨 상승을 표시한다.
- 저장 실패 시 계정 경험치를 포함한 한 판 보상이 라이브 데이터에 부분 적용되지 않는다.

## 저장 호환성

저장 스키마는 3이다.

- 스키마 1과 2를 계속 읽는다.
- 기존 엽전, 숙련도, 무기 연구 해금, 수련 단계와 소비 엽전, 최고 기록을 보존한다.
- 구버전 저장의 총 수련 단계가 현재 계정 레벨 한도를 넘지 않도록 `ceil(총 수련/5)`의 최소 계정 레벨 시작 경험치를 부여한다.
- 총 수련 17강 fixture는 계정 레벨 4 시작 경험치로 이관되고 기존 17강과 엽전이 보존됨을 자동 테스트로 확인했다.
- 스키마 3은 계정 경험치를 0부터 계정 레벨 100 시작 누적치 사이로 정규화한다.
- 저장 문서 체크섬과 현재/백업 복구 정책은 유지된다.

## 수치 확인

- 15분 생존 경험치 상한: 150
- 800처치 경험치 상한: 200
- 승리 보너스: 250
- 한 판 최대 계정 경험치: 600
- 포기 지급률: 전체 계산값의 25%, 내림
- 계정 레벨 20 시작 누적 경험치: 12,958
- 한 트랙 20강 총비용: 24,700 엽전
- 한 트랙 20강 최대 효과: 15%
- 수호 20강 받는 피해 배율: 0.85

## TDD 증거

각 기능 단위는 새 테스트를 먼저 작성하고 의도한 실패를 확인한 뒤 구현했다.

- 계정 경험치 규칙 RED: `AccountProgression` 미구현 컴파일 실패
- 수련 확장 RED: 계정 필드, 20강 비용/효과, 한도 오류와 실제 수호 배율 미구현 실패
- 스키마 3 RED: 스키마가 2로 유지되어 3개 이관 테스트 실패
- 정산 상태 RED: 계정 결과 필드 미구현 컴파일 실패
- 로비 RED: 계정 헤더와 수련 표시 API 미구현 컴파일 실패
- 결과창 RED: 새 계정 경험치 문구 2개 실패
- 수련 100강 경계 RED: `계정 레벨 20에서 추가 수련`이라는 잘못된 문구 재현

모든 RED는 해당 기능을 구현한 뒤 focused GREEN으로 전환했다.

## 최종 Unity 검증

Unity 6000.5.5f1을 batchmode로 직접 실행했다. 모든 프로세스는 `BelowNormal` 우선순위와 `ProcessorAffinity = 15`로 제한해 순차 실행했다.

### EditMode

- 결과 파일: `Logs/account-feature-final-editmode-results-20260806.xml`
- 결과: 717/717 통과
- 실패: 0
- 소요 시간: 17.682초

### PlayMode

- 결과 파일: `Logs/account-feature-final-playmode-results-20260806.xml`
- 결과: 251/251 통과
- 실패: 0
- 소요 시간: 116.230초
- 실행 중 Unity 작업 집합: 약 1.7GB

전체 테스트 실행이 스크립트 컴파일과 실제 Lobby/Gameplay 씬 로드를 포함하므로 별도의 컴파일 오류는 없다.

## 변경 안전성

- 씬, 프리팹, ProjectSettings, 패키지와 새 이미지 에셋을 수정하지 않았다.
- 계정 헤더는 기존 Lobby 씬의 직렬화된 UI를 감지하고 런타임에 한 번만 보강한다.
- 매 프레임 계정 진행 UI를 다시 만들거나 저장을 읽지 않는다.
- 기존 사용자 소유의 CombatChoices 및 각궁 아이콘 `.meta` 로컬 변경은 스테이징·커밋하지 않았다.
- 새 C# 파일과 테스트 파일에는 대응하는 Unity `.meta` 파일이 있다.

## 남은 수동 확인

자동 PlayMode가 720×1280 기준 해상도를 사용하는 로비 구조와 텍스트·fill 값을 검증했지만, 실제 Android 기기의 노치/폰트 래스터링과 터치 감각은 기기 빌드에서 최종 육안 확인이 필요하다. 이번 변경에는 Android APK 빌드와 실기기 설치가 포함되지 않았다.
