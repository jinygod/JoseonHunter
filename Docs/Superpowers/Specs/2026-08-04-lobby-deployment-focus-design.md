# 로비 출전 중심 개편 설계

## 목표

로비 첫 화면이 거대한 무기 선택기가 아니라 한연화의 출전 준비 화면으로 읽히게 한다. 재화와 수련 명칭도 짧고 게임다운 표현으로 정돈한다.

## 확정 사항

- 하단 `공통 수련`은 `수련`으로 바꾼다.
- 수련 화면 제목도 `수련`으로 바꾸고 설명은 `수련 효과는 모든 출전에 적용되며, 항목별 최대치는 10%입니다.`로 바꾼다.
- 상단 재화는 기존 `엽전 155` 글자를 제거하고 `엽전 픽셀 아이콘 + 155`만 표시한다. `냥`은 붙이지 않는다.
- 출전 화면 중앙에는 기존 투명 배경 픽셀 한연화를 배치한다.
- 한연화 주변에 직사각형 이미지, 카드, 테두리, 비픽셀 배경을 두지 않는다. 배경 위에 캐릭터만 직접 올리고 발밑에 낮은 투명도의 타원 그림자만 둔다.
- 현재의 좌우 화살표와 거대한 무기 이미지는 메인 화면에서 제거한다.
- 한연화 아래에는 작은 가로형 `시작 무기` 슬롯을 둔다. 슬롯에는 선택 무기 아이콘, 이름, 오른쪽 꺾쇠를 표시한다.
- 시작 무기 슬롯을 누르면 불투명한 조선 판타지 패널 위에 2열 무기 선택 목록을 연다. 선택하면 즉시 저장하고 창을 닫는다.
- 큰 `출전` 버튼은 화면의 최종 행동으로 유지한다.

## 시각 위계

1. 중앙 픽셀 한연화
2. 간결한 시작 무기 슬롯
3. 큰 출전 버튼
4. 하단의 `무기 연구`, `출전`, `수련` 메뉴

픽셀 한연화는 원본 비율을 유지하며 과도하게 확대하지 않는다. 그림자는 검정색 반투명 타원 하나만 사용하고 광택, 흰 테두리, 직사각형 배경은 사용하지 않는다.

## 에셋

새 이미지를 만들지 않는다.

- 한연화: `Assets/JoseonHunter/Art/StaticSprites/Runtime/Heroes/han_yeonhwa.png`
- 엽전: `Assets/JoseonHunter/Art/StaticSprites/Runtime/Pickups/coin.png`
- 무기: 기존 `WeaponCatalogAsset`의 UI 아이콘
- 버튼: 기존 로비 주·보조 9-slice 프레임

## 동작과 안전성

현재 선택 무기는 기존 활성 출전 설정에 즉시 저장한다. 선택 창 바깥을 누르거나 닫기 버튼을 누르면 변경 없이 닫힌다. 출전은 마지막으로 저장된 무기를 사용한다. 저장 실패 시 기존 피드백 영역에 한글 오류를 표시하며 선택 창은 유지한다.

## 검증

- 로비 하단 메뉴가 정확히 `무기 연구`, `출전`, `수련`인지 검사한다.
- 수련 화면의 제목과 설명에서 `공통 수련`이 사라졌는지 검사한다.
- 헤더에 엽전 아이콘이 있고 숫자만 표시되는지 검사한다.
- 출전 화면에 투명 픽셀 한연화, 시작 무기 슬롯, 출전 버튼이 있고 기존 좌우 화살표가 없는지 검사한다.
- 무기 슬롯을 눌러 선택 창을 열고 다른 무기를 고르면 즉시 저장되고 창이 닫히는지 검사한다.
- 720×1280과 1080×2340 로비 캡처로 배경 조화와 겹침을 확인한다.
