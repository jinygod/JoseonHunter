# 감정·경험치 흡수·서리병·벽력탄 피드백 개선 설계

## 목표

감정 결과의 정보 겹침을 없애고, 추가옵션 수치가 빠르게 시작해 마지막 값에서 긴장감을 만드는 연출을 제공한다. 경험치 불꽃은 획득 범위를 바꾸지 않으면서 캐릭터에게 빨려 들어가는 감각을 강화한다. 서리병은 착지 폭발과 지속 서리 지대의 역할을 즉시 알아볼 수 있게 만들고, 과도하게 강한 벽력탄의 피해를 낮춘다.

## 현재 문제와 원인

- 감정 화면의 누적 추가옵션 문구가 주 결과 칸 하단과 첫 잠재능력 칸 사이에 충분한 전용 공간 없이 배치되어 겹친다.
- 추가옵션 수치는 이미 ease-out 곡선을 사용하지만 일반 결과 기준 약 0.75초에 끝나므로 마지막 수치를 기다리는 맛이 약하다.
- 경험치 불꽃은 획득 범위 안에서 직선으로 가속할 뿐, 흡수 시작과 완료를 구분하는 시각 피드백이 없다.
- 서리병은 현재 0.25초 주기 피해, 둔화, 체류 후 빙결을 제공하지만 착지 즉시 피해가 없고 장판과 착지 이펙트가 희미해 효과가 없는 것처럼 보인다.
- 벽력탄은 넓은 범위와 짧아지는 재사용 대기시간을 가지면서 기본 피해가 레벨별 18/22/26/30/34라 다른 광역 무기보다 효율이 지나치게 높다.

## 감정 화면

### 배치

- 누적 추가옵션은 주 결과 칸 바로 아래의 독립된 한 줄로 표시한다.
- 누적 문구와 주 결과 칸, 첫 잠재능력 칸 사이에 각각 최소 6 기준 픽셀의 빈 공간을 둔다.
- 잠재능력 세 칸과 확인 버튼을 함께 아래로 이동해 마지막 잠재능력 칸도 확인 버튼과 겹치지 않게 한다.
- 작은 누적 문구는 한 줄을 유지하고 넘칠 경우 자동 크기 조정을 허용하되, 최소 글자 크기는 가독 가능한 범위로 제한한다.

### 수치 상승 연출

- 전체 상승 시간은 일반 결과 약 1.4초, 고급·최대 결과 약 1.6초로 늘린다.
- 목표값의 약 70%까지는 빠르게 진행하고 이후 증가 속도를 낮춘다.
- 마지막 3개 정수 값은 서로 구분되어 보이도록 별도의 체류 시간을 둔다.
- 최종 값에서 금색 강조와 한 번의 짧은 크기 박동으로 확정을 알린다.
- 음수 옵션도 부호 방향만 반대로 하고 동일한 리듬을 사용한다.
- 기존 건너뛰기 입력은 유지한다.

## 경험치 흡수

- 경험치 불꽃이 일반 획득 범위 또는 자석 강제 회수 상태에 들어오면 흡수 상태로 전환한다.
- 흡수 시작 시 짧게 떠오르고, 이후 캐릭터를 향해 점차 빠르게 이동한다.
- 이동 방향으로 불꽃을 살짝 늘리고 청록색의 짧은 잔상을 보여준다.
- 캐릭터에 닿는 순간 작은 청록색 섬광을 한 번 표시한 뒤 경험치를 지급한다.
- 기존 일반 획득 범위와 최종 획득 거리는 변경하지 않는다.
- 다수의 경험치가 동시에 흡수될 때 프레임별 할당이 발생하지 않도록 상태 데이터와 재사용 가능한 간단한 효과를 사용한다.

## 서리병

### 전투 역할

- 채택안은 `착지 폭발 + 지속 서리 지대`다.
- 병이 착지하면 별도의 1회성 공격 판정으로 기본 피해 100%를 즉시 준다.
- 이후 서리 지대는 0.25초마다 기본 피해 50%를 주고 둔화를 적용한다.
- 서리 지대에 0.75초 이상 머문 적은 기존처럼 짧게 빙결된다.
- 레벨별 서리 지대 지속시간과 최대 동시 지대 수, 진화 및 잠재능력의 기본 구조는 유지한다.

### 시각 피드백

- 착지 순간 밝은 청색 중심 섬광, 단순한 원형 파동, 소수의 얼음 파편을 표시한다.
- 장판은 복잡한 다색 표현 대신 밝은 청색 중심과 진한 청록 외곽의 제한된 색을 사용한다.
- 장판 불투명도를 높여 실제 피해 범위를 한눈에 알아볼 수 있게 한다.
- 착지 피해와 지속 피해는 기존 피해 숫자 시스템을 통해 각각 확인할 수 있어야 한다.
- 무기 설명은 `착지 폭발 후 서리 지대를 남겨 지속 피해와 둔화·빙결을 부여`하는 내용으로 한글화한다.

## 벽력탄

- 범위, 재사용 대기시간, 투척과 폭발 동작은 유지한다.
- 레벨별 기본 피해를 `18/22/26/30/34`에서 `12/15/18/21/24`로 낮춘다.
- 진화와 잠재능력의 배율은 낮아진 기본 피해를 기준으로 계산한다.
- 레벨 5의 추가 충격파 구조는 유지한다.

## 테스트와 검증

- 감정 수치 곡선이 초반보다 후반에 느려지고 최종 값에 정확히 도달하는 EditMode 테스트를 추가한다.
- 누적 문구, 잠재능력 칸, 확인 버튼의 경계가 겹치지 않는 UI 테스트를 추가한다.
- 경험치가 기존 범위 밖에서는 움직이지 않고, 범위 안에서는 가속 흡수되며 정상 지급되는 테스트를 추가한다.
- 서리병이 착지 즉시 1회 피해를 주고 이후 낮은 지속 피해, 둔화, 빙결을 유지하는 무기 동작 테스트를 추가한다.
- 벽력탄 콘텐츠 에셋의 레벨별 피해 수치를 검증한다.
- 관련 EditMode와 PlayMode 테스트, 전체 EditMode 테스트, Android 빌드를 실행한다.

## 범위 밖

- 새 PixelLab 또는 Imagegen 에셋 제작은 하지 않는다.
- 경험치 획득 범위, 적 수, 웨이브 구성은 변경하지 않는다.
- 서리병과 벽력탄 이외 무기의 피해 수치는 변경하지 않는다.
- 사용자가 작업 중인 씬, 프로젝트 설정, 폰트 에셋 변경은 이번 커밋에 포함하지 않는다.
