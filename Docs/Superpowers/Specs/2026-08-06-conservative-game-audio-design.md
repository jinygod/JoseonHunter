# 절제된 기본 사운드 통합 설계

## 1. 목표

현재 무음 상태인 로비와 1장 전투에 누구나 즉시 용도를 알아들을 수 있는 기본 효과음을 연결한다. 많은 소리를 채우기보다 클릭, 획득, 공격, 피격, 우두머리 경고처럼 플레이 판단에 필요한 사건을 우선한다. 조선 민속 판타지 분위기와 맞지 않는 전자음, 과장된 괴물 울음, 서양식 팡파르와 배경 음악은 넣지 않는다.

## 2. 범위

### 포함

- 로비와 인게임의 일반 버튼, 확인, 출전, 취소
- 경험치, 엽전, 자석, 레벨업과 증강 선택
- 현재 구현된 무기별 대표 공격 또는 첫 명중음
- 일반 피격, 치명타, 우두머리 경고·등장·격파
- 볼륨 그룹, 동시 재생 제한, 반복 재생 억제와 미세 피치 변화
- CC0 원본 중 실제 사용하는 클립만 Unity 프로젝트에 편입

### 제외

- 로비·전투·우두머리 배경 음악
- 캐릭터 음성 및 일반 몬스터의 반복 울음
- 발걸음 상시 재생
- 모든 투사체와 모든 적에게 개별 재생되는 고밀도 사운드
- 설정 화면의 사용자 볼륨 슬라이더. 내부 그룹 분리는 이번 작업에 포함하되 사용자 설정 UI는 후속 작업으로 둔다.

## 3. 접근 방식

프로젝트 전역에 하나의 `GameAudioDirector`를 두고 짧은 효과음을 2D `AudioSource.PlayOneShot`으로 재생한다. Director는 씬 이동에도 유지되며 Bootstrap, Lobby, Gameplay 직접 진입 모두에서 중복 없이 자동 준비된다.

사운드 선택은 `GameAudioCueId`와 명시적 카탈로그로 관리한다. 런타임에서 파일명을 추측하거나 폴더 전체를 순회하지 않는다. 카탈로그에 클립이 없으면 해당 소리만 조용히 생략하고 게임 진행은 유지한다.

UI는 런타임 UI 팩토리가 생성하는 버튼에 공통 클릭 피드백을 붙인다. 출전, 구매, 확인처럼 결과를 확정하는 동작은 각 Presenter가 기본 클릭음 대신 확정음을 요청한다. 모바일에 필요 없는 마우스 오버 소리는 사용하지 않는다.

전투는 이미 확정된 `CombatDamageService.DamageConfirmed`를 기준으로 재생한다. 동일 공격 인스턴스가 여러 적을 동시에 맞히더라도 무기 대표음은 한 번만 재생하며, 추가 접촉은 제한된 일반 피격음만 허용한다. 화면 밖 전투와 과도한 동시 재생은 중요도와 시간 제한으로 억제한다.

## 4. 기본 매핑

| 사건 | 기본 음원 성격 | 후보 원본 |
|---|---|---|
| 일반 버튼 | 짧고 마른 클릭 | Kenney UI `click1` |
| 확인·출전 | 조금 단단한 클릭 | Kenney UI `click3` 또는 `switch` |
| 경험치 획득 | 짧고 맑은 보석음 | 80 RPG `item_gem_01` |
| 엽전 획득 | 명확한 동전 소리 | 80 RPG `item_coins_01~03` |
| 자석 획득 | 한 번만 들리는 짧은 주문음 | 80 RPG `spell_01` |
| 레벨업·증강 선택 | 차분한 보상·주문음 | 80 RPG `spell_02`, Kenney UI 확정음 |
| 각궁 | 실제 활 발사음 | Battle SFX `Bow.wav` |
| 환도 비검 | 짧은 무기 휘두름 | Battle SFX `swish_2`, 80 RPG `blade_01` |
| 벽력탄 | 불꽃과 무거운 충격 | 80 RPG `spell_fire_03`, Kenney `impactGeneric` |
| 서리병 | 낮은 주문과 얇은 파열 | 80 RPG `spell_02`, Kenney `impactGlass_light` |
| 풍뢰선 | 가벼운 바람 휘두름 | Battle SFX `swish_3` |
| 주술 부적 | 짧고 절제된 주문 | 80 RPG `spell_01` |
| 장승진 | 무거운 목재 충격 | Kenney `impactWood_heavy` |
| 금줄 | 낮은 금속·종 충격 | Kenney `impactBell_heavy` |
| 신기전 | 활 발사와 작은 화염 | Battle SFX `Bow.wav`, 80 RPG `spell_fire_01` |
| 일반 피격 | 부드러운 충격 | Kenney `impactSoft_medium` |
| 치명타 | 한 단계 무거운 충격 | Kenney `impactPunch_heavy` |
| 우두머리 경고 | 낮은 종 1회 | Kenney `impactBell_heavy` |
| 우두머리 격파 | 짧은 포효와 무거운 충격 | 80 RPG `creature_roar`, Kenney 무거운 충격 |

실제 편입 전에 각 후보의 길이, 피크와 반복감을 확인한다. 어색한 후보는 같은 역할의 다른 변형으로 교체하되 표의 의미와 음원 계열은 유지한다.

## 5. 재생 예산

- 전체 효과음용 AudioSource 풀: 12개
- 같은 UI 클릭: 최소 0.06초 간격
- 경험치 흡수음: 최소 0.09초 간격, 자석 대량 흡수 중에도 이 제한 유지
- 엽전 획득음: 최소 0.10초 간격
- 일반 피격음: 최소 0.05초 간격, 한 프레임에는 대표음 1개
- 무기 대표음: 동일 공격 인스턴스와 무기 조합당 1회
- 우두머리 경고·격파와 플레이어 피격은 일반 피격보다 높은 우선순위
- 미세 피치 변화는 기본음의 정체성을 해치지 않는 `0.96~1.04` 범위만 사용
- 시간 제한과 큐 판정은 일시정지 중에도 안정적인 `Time.unscaledTime` 기준을 사용

풀에 빈 채널이 없으면 낮은 우선순위의 일반 피격이나 경험치 소리를 생략한다. 우두머리 경고나 확정 UI음 때문에 새 GameObject를 생성하지 않는다.

## 6. 에셋과 임포트

원본 전체는 `ExternalAssets/Audio`에 계속 보관하고 Git에서 제외한다. 실제 사용하는 OGG 또는 WAV만 `Assets/JoseonHunter/Audio/CC0` 아래에 역할별로 복사한다. 라이선스 문서와 출처 목록은 함께 커밋한다.

짧은 효과음은 모바일에서 `Decompress On Load`, mono, Vorbis 적정 품질을 기본으로 한다. 긴 음원이 없으므로 이번 작업에서는 Streaming을 사용하지 않는다. 같은 음원의 WAV와 OGG를 동시에 편입하지 않는다.

## 7. 연결 지점

- `RuntimeUiFactory`: 일반 런타임 버튼 클릭음
- 로비 Presenter: 출전, 연구 구매, 수련 구매 같은 확정음
- `FirstPlayableController`: 경험치, 엽전, 자석, 레벨업, 우두머리 상태 사건
- `CombatFeedbackDirector`: 확정 피해, 치명타와 무기별 대표음
- 게임 종료 Presenter: 승전·패배와 로비 복귀 확정음

규칙 계산과 저장 도메인은 오디오를 알지 않는다. 오디오는 Presentation/Runtime 경계에서 이미 확정된 사건만 소비한다.

## 8. 오류와 호환성

- 클립 누락은 경고를 한 번만 남기고 무음으로 진행한다.
- AudioListener가 없는 배치 테스트에서는 재생 요청 기록만 검증하고 예외를 내지 않는다.
- 씬 재진입 시 Director와 AudioSource 풀이 중복 생성되지 않는다.
- 일시정지와 증강 선택 중에도 UI음은 재생할 수 있고 전투음은 멈춘다.
- 기존 세이브 스키마, 전투 수치, 입력과 씬 직렬화는 변경하지 않는다.

## 9. 테스트

### EditMode

- 모든 필수 Cue ID가 실제 편입 클립 경로와 연결되는지 확인
- 쿨다운과 동시 재생 예산이 저우선순위 반복음을 억제하는지 확인
- 동일 공격 인스턴스의 다중 명중이 무기 대표음 한 번으로 합쳐지는지 확인
- 누락된 클립이 게임 흐름을 중단하지 않는지 확인

### PlayMode

- Bootstrap, Lobby, Gameplay 직접 진입에서 Director가 하나만 존재하는지 확인
- 일반 버튼과 확정 버튼이 올바른 Cue를 요청하는지 확인
- 경험치·엽전·자석 획득이 제한된 빈도로 Cue를 요청하는지 확인
- 확정 피해가 무기별 대표음과 피격음을 요청하는지 확인
- 일시정지 중 전투음은 억제되고 UI음은 허용되는지 확인

### 회귀 검증

- Unity EditMode 전체와 PlayMode 전체
- 프로젝트 배치 로드와 Console 오류 확인
- Android 개발 빌드
- Unity Game 뷰에서 로비, 초반 쥐 떼, 레벨업, 각궁, 환도, 벽력탄, 서리병, 우두머리를 육안·청각 확인

## 10. 완료 조건

- 게임 시작부터 승리까지 핵심 입력과 전투 사건에 기본 효과음이 들린다.
- 일반 몬스터가 몰려도 소리가 찢어지거나 수십 겹으로 재생되지 않는다.
- 각궁과 환도처럼 성격이 다른 무기가 소리만으로도 구분된다.
- 경험치와 엽전은 서로 다른 소리로 즉시 구분된다.
- 어울리지 않는 전자음, 장난스러운 소리와 반복 괴물 울음이 없다.
- 새 프레임 할당과 런타임 AudioSource 생성이 없다.
- 실제 사용 음원과 라이선스 기록이 함께 커밋된다.
- 관련 테스트와 Android 개발 빌드가 통과한다.
