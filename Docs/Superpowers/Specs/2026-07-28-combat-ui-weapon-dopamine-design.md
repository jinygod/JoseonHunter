# 전투 UI 및 무기 성장 도파민 디자인

작성일: 2026-07-28
상태: 사용자 방향 승인 완료, 구현 전 최종 명세 검토

## 1. 목표

전투 화면을 조선 민속 판타지의 정체성이 보이는 세로형 모바일 HUD로
개편하고, 레벨업 선택과 무기 성장이 실제 플레이 보상처럼 느껴지게
만든다.

핵심은 화면 전체를 계속 번쩍이게 만드는 것이 아니다. 평상시 전투는
읽기 쉬운 강도 70을 유지하고, 신규 무기 획득·핵심 강화·최종 진화·보스
처치처럼 의미 있는 순간에만 강도를 90~100까지 끌어올린다.

승인된 시각 방향은 **귀살 아케이드**다. 어두운 먹빛 전장, 한지와
부적을 닮은 선택 카드, 금색 보상광, 무기별 속성색을 사용한다.

## 2. 범위

### 포함

- 기존 IMGUI 전투 HUD와 증강 선택 화면을 게임용 프레젠테이션 UI로 교체
- 캐릭터 상태, 경험치, 시간, 처치 수, 연속 처치, 보유 무기 표시
- 레벨업 진입과 선택 완료 연출
- 신규 무기, 무기 강화, 능력 강화 카드의 명확한 구분
- 공격 접촉점 기준 피해 숫자와 치명타 표현
- 8종 무기의 단계별 시청각 성장 피드백
- 각 무기의 정체성을 유지하면서 결이 달라지는 최종 진화
- 화면 흔들림, 히트 스톱, 섬광을 중요도에 따라 조절하는 연출 예산

### 제외

- 로비 화면 전체 개편
- 신규 캐릭터 및 몬스터 원화 제작
- 무기 밸런스 수치의 최종 확정
- 메타 성장 및 상점 시스템

## 3. 디자인 원칙

1. **접촉이 먼저다.** 피해 숫자, 타격광, 파편, 히트 스톱은 확인된
   픽셀 접촉점에서만 발생한다.
2. **강화는 실제 공격에서 보여야 한다.** 카드에 `피해 +10%`만
   표시하지 않고 투사체 수, 궤적, 범위, 리듬, 적 반응 중 하나 이상이
   눈에 띄게 달라진다.
3. **최종 진화는 확대판이 아니다.** 같은 무기의 핵심 동사를 유지하되
   공격의 리듬이나 보상 구조를 바꿔 새로운 손맛을 만든다.
4. **정보와 장식의 층을 분리한다.** 체력·경험치·선택 결과는 항상
   읽혀야 하며 장식이 이를 가리지 않는다.
5. **희소한 순간에 강하게 보상한다.** 모든 공격에 화면 흔들림을 넣지
   않는다. 치명타, 정예 처치, 각성, 보스 처치에서만 단계적으로 쓴다.

## 4. 전투 HUD

### 상단 왼쪽

- 원형 캐릭터 초상
- 체력 막대와 경험치 막대
- 현재 레벨과 다음 레벨까지 남은 비율
- 체력이 위험 구간에 들어오면 붉은 맥동을 낮은 빈도로 표시
- 경험치가 90%를 넘으면 경험치 막대 끝에 영기가 모이는 연출 표시

### 상단 오른쪽

- 생존 시간
- 누적 처치 수
- 연속 처치 수
- 연속 처치는 일정 기준을 넘을 때만 잠깐 확대되며 평상시에는 작게 유지

### 하단 무기 랙

- 현재 보유한 무기만 아이콘으로 표시
- 각 아이콘에 단계 숫자를 붙이고 재사용 대기 상태를 방사형 또는
  하단 게이지로 표현
- 방금 강화한 무기는 한 번 튀어 오르고 변경된 핵심 수치가 짧게 표시
- 최종 진화가 가능한 무기는 금빛 테두리가 느리게 차오름

### 피해 숫자

- 일반 피해: 작고 빠르게 상승
- 치명타: 더 큰 숫자, 짧은 확대, 별도 접두어 없이 형태로 구분
- 속성 피해: 무기 계열색을 보조색으로만 사용
- 보스 피해: 일반 숫자보다 체류 시간이 조금 길고 흔들림은 억제
- 같은 공격 인스턴스가 짧은 시간에 같은 적을 여러 번 때리면 숫자를
  합산해 화면 혼잡을 방지
- 모든 숫자는 실제 접촉점에서 생성

## 5. 레벨업 및 증강 선택 흐름

1. 마지막 경험치 획득 순간에 게임 시간을 0.3초 동안 빠르게 감속한다.
2. 전장의 색을 낮추고 영기가 화면 중앙으로 수렴한다.
3. 0.3초가 끝나면 전투를 완전히 정지한다.
4. `깨달음을 선택하라` 제목과 함께 세 장의 한지 카드가 열린다.
5. 선택한 카드는 부적처럼 접히며 캐릭터 쪽으로 흡수된다.
6. 신규 무기 또는 핵심 강화라면 짧은 전용 공개 연출을 재생한다.
7. UI를 닫고 0.15초의 가속 복귀 후 정상 전투 속도로 돌아간다.

슬로모션은 연출용이며 선택 중 적의 이동·공격·피해 판정은 완전히
멈춘다. 선택 화면 진입과 종료는 중복 입력에 안전해야 한다.

## 6. 증강 카드

세 카드 모두 다음 정보를 같은 위치에 표시한다.

- 분류: `신규 무기`, `무기 강화`, `능력 강화`, `최종 진화`
- 무기 아이콘 또는 능력 문양
- 이름
- 한 문장의 행동 변화 설명
- 현재 값에서 다음 값으로 바뀌는 핵심 수치

카드의 강조 순서는 최종 진화 > 신규 무기 > 핵심 단계 강화 > 일반 강화
순이다. 희귀도는 외곽광과 작은 표식으로 나타내며 카드 전체가 계속
점멸하지 않는다.

지원 능력만 세 장 나오는 상황은 피한다. 아직 얻지 않은 무기가 있으면
최소 한 장은 신규 무기 후보가 되며, 최종 진화 조건을 만족하면 해당
진화 카드를 우선적으로 체감할 수 있게 한다.

## 7. 무기 성장 단계

각 무기는 다음 네 종류의 체감 단계를 가진다.

### 최초 획득

- 무기 이름과 아이콘이 0.6초 이내로 공개
- 첫 공격은 즉시 또는 매우 짧은 시간 안에 발동해 선택 결과를 확인
- 첫 공격에만 약한 카메라 강조와 선명한 전용 음색 적용

### 일반 강화

- 피해, 재사용 대기시간 같은 수치 상승
- 아이콘과 간단한 변화량만 표시
- 화면 전체 연출은 사용하지 않음

### 핵심 강화

- 투사체 추가, 관통, 연쇄, 잔류장, 2차 폭발처럼 동작이 실제로 달라짐
- 강화 후 첫 발동에만 한 단계 강한 피드백 제공

### 최종 진화

- 전투를 짧게 정지하고 무기 문양과 진화명을 공개
- 기존 공격의 핵심 동사는 유지
- 색만 바꾸거나 크기만 키우지 않고 리듬·궤적·적 반응·보상 조건 중
  최소 두 가지를 변경
- 진화 후 첫 발동은 시범 연출로 분명하게 보여주되 이후에는 전투
  가독성 예산 안으로 복귀

## 8. 8종 무기와 최종 진화 방향

진화명은 구현 중 로컬라이징 데이터로 분리하며, 아래 이름은 디자인
기준안이다.

| 기본 무기 | 유지할 정체성 | 최종 진화 기준안 | 달라지는 도파민의 결 |
| --- | --- | --- | --- |
| 환도 비검 | 실제 칼날이 날아가 픽셀 접촉 후 귀환 | **환도·월식**: 여러 칼날이 바깥으로 흩어진 뒤 귀환 경로에서 교차하고, 교차점에 월식 폭발 생성 | 빠른 발사 쾌감에서 `되돌아오는 타이밍을 기다렸다가 한꺼번에 회수하는 쾌감`으로 변화 |
| 각궁 | 정확한 직선 사격과 관통 | **각궁·관일**: 일정 사격마다 조준선이 잠깐 고정되고 거대한 관통 화살 한 발이 전장을 가름 | 연속 타격이 아니라 `한 발의 확실한 관통과 큰 숫자`에 집중 |
| 주술 부적 | 적에게 붙고 옮겨가며 봉인 | **천쇄부진**: 부적이 여러 적을 잇고 일정 수가 연결되면 결계가 닫히며 동시 폭발 | 개별 연쇄에서 `그물을 완성하는 수집·완성 쾌감`으로 변화 |
| 벽력탄 | 투척, 지연 신관, 범위 폭발 | **벽력탄·뇌옥**: 첫 폭발이 적을 중앙으로 끌어당기고 짧은 정적 후 압축된 2차 낙뢰 폭발 | 즉시 폭발에서 `끌어모음 → 침묵 → 압축 폭발`의 대비로 변화 |
| 장승진 | 공간을 점유하고 경계를 넘는 적을 처벌 | **십이지신 장승진**: 장승들이 순서대로 깨어나며 경계를 닫고, 완성된 진 안의 적을 낙인 처리 | 지속 피해에서 `진을 완성하고 안전 구역을 확보하는 지배감`으로 변화 |
| 신기전 | 여러 궤도의 로켓 화살과 일제 사격 | **신기전·화룡포**: 소규모 발사 뒤 표식 지점에 대규모 일제 사격이 뒤늦게 집중 | 산개 화력에서 `예고된 지역을 포격으로 지워버리는 대량 처치 쾌감`으로 변화 |
| 서리병 | 투척 후 잔류 냉기장과 둔화·빙결 | **서리병·빙화원**: 냉기장 안에서 적을 충분히 얼리면 얼음꽃이 피고 장이 끝날 때 가시가 연쇄 파열 | 지속 제어에서 `얼린 적을 저장했다가 한꺼번에 깨뜨리는 파쇄 쾌감`으로 변화 |
| 풍뢰선 | 바람으로 표시한 적에게 뒤늦은 낙뢰 | **풍뢰선·천뢰귀환**: 바람이 적들을 한 방향으로 밀어 표식을 모으고, 잠시 뒤 낙뢰가 표식 사이를 왕복 | 밀치기와 후속 낙뢰에서 `적 배치를 만든 뒤 번개가 되돌아오는 설계 쾌감`으로 변화 |

각 진화는 별도의 무기로 취급하지 않는다. 기존 무기 슬롯과 강화
누적치를 유지하고 실행 상태와 프레젠테이션 프로파일만 진화형으로
전환한다.

## 9. 연출 예산

### 강도 70: 일반 전투

- 작은 접촉광
- 짧은 피해 숫자
- 카메라 흔들림 없음
- 무기별 기본 음색

### 강도 80: 치명타·연속 처치

- 접촉광 확대
- 0.02~0.04초 수준의 국소 히트 스톱
- 작은 카메라 임펄스
- 치명타와 처치음 중복 시 하나로 정리

### 강도 90: 신규 무기·핵심 강화

- 아이콘 공개 및 이름 표시
- 강화 후 첫 공격 강조
- 0.08초 이하의 강한 순간 피드백

### 강도 100: 최종 진화·보스 처치

- 전투 정지
- 전용 문양과 명칭
- 한 번의 큰 음향 피크
- 진화 후 첫 공격의 전용 카메라 임펄스
- 이후 일반 전투 예산으로 즉시 복귀

광과 흔들림 강도는 접근성 옵션에서 낮출 수 있어야 한다. `연출 감소`
옵션에서도 정보 전달과 접촉 피드백은 사라지지 않는다.

## 10. 아트 자산 전략

현재 8종 무기는 대표 이미지, 아이콘, 보조 파츠, 접촉 마스크를 이미
보유하고 있으므로 우선 재사용한다.

- UI 프레임, 게이지, 카드 바탕은 Unity UI의 9-slice 및 셰이더/머티리얼
  조합으로 제작
- 무기 아이콘은 기존 PixelLab 결과물을 사용
- 최종 진화는 기존 무기의 실루엣을 알아볼 수 있도록 보조 파츠와
  색상·잔상·문양을 추가
- PixelLab 신규 생성은 진화 실루엣이나 픽셀 파츠가 기존 자산으로
  표현되지 않을 때만 배치 단위로 요청
- Imagegen은 전투 HUD의 작은 픽셀 자산에 사용하지 않으며, 이후 로비
  배경처럼 큰 회화형 화면이 필요할 때 사용

이 전략으로 PixelLab 횟수를 UI 장식에 낭비하지 않고 실제 게임플레이
차이를 만드는 진화 자산에 집중한다.

## 11. 구현 구조

현재 `FirstPlayableController.OnGUI`에 집중된 표시 책임을 다음의 작은
프레젠테이션 단위로 분리한다.

- `CombatHudPresenter`: 체력, 경험치, 시간, 처치, 연속 처치
- `WeaponRackPresenter`: 보유 무기, 단계, 재사용 대기, 진화 가능 상태
- `UpgradeChoicePresenter`: 레벨업 진입, 카드 표시, 입력 잠금, 종료
- `RewardRevealPresenter`: 신규 획득, 핵심 강화, 최종 진화 공개
- `CombatFeedbackDirector`: 접촉광, 히트 스톱, 카메라 임펄스, 중요도 예산
- 기존 `DamageNumberPool`: 접촉점 기반 숫자 합산 및 무기별 보조색 유지

전투 규칙과 표시를 분리한다. UI와 연출은 `ConfirmedDamageEvent`,
레벨업 이벤트, 무기 단계 변경 이벤트를 구독하며 직접 피해를 만들거나
전투 상태를 임의 변경하지 않는다.

## 12. 상태 및 오류 처리

- 증강 선택 진입 중 추가 레벨업이 발생하면 대기열에 넣고 현재 선택을
  마친 뒤 다음 선택을 연다.
- 일시정지 중 입력은 한 장만 확정되도록 잠근다.
- 무기 아이콘이 누락되면 이름과 공용 문양으로 대체하고 선택 자체는
  가능해야 한다.
- 진화 프레젠테이션 자산이 누락돼도 실행 메커니즘은 동작하며 기본
  무기 시각으로 대체한다.
- 장면 재시작 시 슬로모션, 선택 잠금, 카메라 임펄스 상태를 초기화한다.

## 13. 완료 기준

- 세로형 화면에서 HUD가 플레이어, 적, 투사체의 중심 전투 영역을
  가리지 않는다.
- 레벨업은 0.3초 감속 후 완전 정지하고 한 번의 입력만 수락한다.
- 증강 카드에서 분류, 이름, 행동 변화, 수치 변화가 즉시 읽힌다.
- 피해 숫자는 실제 접촉점에서만 나타나고 짧은 다단 피해는 합산된다.
- 8종 무기가 최초 획득, 일반 강화, 핵심 강화, 최종 진화 피드백을 가진다.
- 8종 최종 진화가 원래 무기의 정체성을 유지하면서 최소 두 가지 감각
  축에서 다른 플레이 보상을 제공한다.
- 연출 감소 옵션에서도 필수 정보와 피격 확인은 유지된다.
- 새 픽셀 자산은 기존 자산으로 표현할 수 없는 진화 파츠에만 사용한다.
