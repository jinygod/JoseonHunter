# 로비·연구·인게임 가독성 개선 설계

## 목표

픽셀 기반 로비의 통일감을 회복하고, 무기 연구 진행 상황과 전투 중 핵심 조작을 한눈에 이해할 수 있게 만든다. 기존 저장 데이터와 전투 성장 로직은 보존하며, 사용자에게 의미가 불분명한 편성 조작만 화면에서 제거한다.

## 범위

이번 작업은 다음 아홉 항목을 포함한다.

1. 로비의 모든 버튼을 출전 버튼과 같은 조선 판타지 계열로 통일
2. 출전 화면의 편성 선택과 편성 저장 제거
3. 무기 연구 아이콘·숙련도 진행 바·순차 해금 표시 추가
4. 로비의 비픽셀 한연화 제거 및 시작/출전 로딩 원화 교체
5. 로비의 장식성 문구 제거
6. 승전 후 로비 복귀 실패 수정
7. 보물·자석 크기와 경험치 흡수 연출 개선
8. 귀환 버튼을 일시정지 아이콘과 메뉴로 교체
9. 무기 HUD를 작은 아이콘 카드로 축소

## 로비 구조

하단 메뉴 `무기 연구`, `출전`, `공통 수련`은 유지한다. `편성`, `편성 저장`은 출전 화면에서 완전히 제거한다. 저장 데이터의 `PatrolLoadouts` 구조는 기존 저장 파일과의 호환을 위해 유지하지만, 화면에서는 하나의 현재 출전 설정처럼 동작한다.

출전 화면에는 다음만 표시한다.

- 현재 선택 무기의 아이콘과 이름
- 이전 무기 / 다음 무기 버튼
- 최고 기록
- 큰 `출전` 버튼

무기를 바꾸면 활성 출전 설정에 즉시 자동 저장한다. 별도의 저장 버튼이나 편성 번호는 표시하지 않는다.

로비 중앙에서는 `Hero Art`, `한연화의 순찰`, `귀곡 야행`, `우두머리 출현`을 제거한다. 픽셀 안뜰 배경을 그대로 노출해 픽셀 게임의 시각 언어를 유지한다.

## 버튼 시각 체계

PixelLab으로 기존 출전 버튼과 같은 팔레트의 보조 버튼 프레임을 제작한다.

- 기본 버튼: 먹색 또는 짙은 적갈색 내부, 얇은 금장 테두리
- 주요 버튼: 황동빛 전면과 짙은 적갈색 하단 그림자
- 활성 메뉴: 짙은 적갈색과 금색 글자
- 비활성 메뉴: 먹색과 한지색 글자
- 모든 버튼: 9-slice, 불투명 배경, 흰 외곽선 없음

로비의 무기 이동, 연구 카드, 수련 선택, 하단 메뉴에 같은 보조 프레임을 적용한다. `출전`과 `수련하기`처럼 결과를 확정하는 행동만 주요 버튼을 사용한다.

## 무기 연구

상단에 선택 무기의 큰 아이콘과 이름을 배치하고 바로 아래에 초록색 숙련도 진행 바를 둔다. 별도의 장문 숙련도 설명은 제거한다.

진행 바는 현재 연구 중인 다음 단계의 요구 숙련도를 기준으로 표시한다.

- 1단계 미완료: 현재 숙련도 / 2,000
- 1단계 완료 후: 현재 숙련도 / 8,000
- 모든 단계 완료: 가득 찬 상태

연구 카드 문구는 카드 안에서 상태와 수치를 함께 보여준다.

- 기본식: `장착 중` 또는 `사용 가능`
- 2단계 운용법: `연구 중 (564/2,000)`, `해금 가능`, `해금 완료`, `장착 중`
- 3단계 운용법: 2단계가 해금되기 전까지 잠금

잠긴 3단계 카드를 누르면 피드백 영역에 정확히 `2단계 연구 완료 시 해금`이라고 표시한다. 도메인 구매 로직도 순차 해금을 강제해 UI 우회로 3단계를 먼저 해금할 수 없게 한다.

## 한연화와 로딩 흐름

새 한연화 원화는 성인 조선 판타지 검객의 얼굴과 상반신을 가까이 잡는다. 양손은 등 뒤에 있거나 프레임 밖에 있어 손가락이 보이지 않게 한다. 관능적이되 노출 자체보다 표정·자세·의상 실루엣으로 분위기를 만든다.

한연화 원화는 다음 두 경우에만 사용한다.

- 앱 시작 시 Bootstrap 로딩
- 로비에서 출전할 때 Gameplay 진입 로딩

출전 시에는 목적지를 `Gameplay`로 지정한 뒤 Bootstrap 로딩 씬을 경유한다. 목적지 지정이 없으면 기존처럼 `Lobby`로 이동한다. 최소 로딩 노출 시간은 약 1.5초로 늘려 원화를 볼 시간을 보장한다. 로비 복귀는 불필요한 로딩 화면 없이 직접 이동한다.

## 로비 복귀 오류

현재 로비에서 Gameplay로 이동하는 코루틴은 Lobby 씬의 Presenter가 소유한다. 씬이 교체되면서 코루틴이 파괴되어 `GameSceneRouter.IsRouting`이 `true`로 남을 수 있고, 이후 승전 화면의 로비 이동 요청이 무시된다.

씬 비동기 작업의 완료 이벤트에서 라우팅 상태를 반드시 해제한다. 테스트는 Lobby에서 출전한 실제 경로로 Gameplay에 들어간 뒤 승전 결과 버튼을 눌러 Lobby로 돌아오는 전 과정을 검증한다.

## 픽업 표현

보물과 자석의 월드 스프라이트 크기를 키워 원거리 카메라에서도 식별되게 한다.

경험치 획득 반경 `StartingPickupRadius`와 수련에 따른 반경 계산은 변경하지 않는다. 경험치가 기존 반경 안에 들어오면 다음 연출을 적용한다.

- 초기 이동 속도를 낮춰 짧은 이동 구간이 눈에 보이게 함
- 캐릭터 방향으로 스프라이트가 늘어남
- 청록색 짧은 꼬리 표시
- 캐릭터 가까이에서 빠르게 가속
- 흡수 시 짧은 섬광

자석은 기존처럼 전체 경험치를 강제 흡수하되 같은 연출을 더 빠르게 사용한다.

## 일시정지 메뉴

전투 화면의 `귀환` 글자 버튼을 제거하고 상단 HUD 오른쪽 안쪽에 둥근 정사각형 일시정지 버튼을 둔다. 아이콘은 두 개의 세로 막대로 표현한다.

버튼을 누르면 전투가 일시정지되고 다음 두 행동을 보여준다.

- `계속하기`
- `로비로 돌아가기`

기존 전투 포기와 정산 로직은 재사용한다. 확인 없이 즉시 로비로 나가지 않으며, 로비 이동 시 그 시점까지의 숙련도와 엽전을 저장한다.

## 무기 HUD

하단의 긴 무기 설명 카드를 작은 둥근 정사각형 카드로 교체한다. 카드에는 무기 아이콘만 크게 표시하고 이름·전승 설명·작은 추가 옵션 문장은 제거한다.

레벨은 카드 테두리색으로 구분한다.

- 1레벨: 한지 회색
- 2레벨: 청록
- 3레벨: 파랑
- 4레벨: 보라
- 5레벨 이상: 금색

잠재 옵션은 카드 하단에 최대 세 개의 작은 아이콘으로 표시한다. 카드 전체는 버튼이며 누르면 기존 무기 상세 정보 화면을 열어 정확한 수치와 운용법을 확인할 수 있다.

## 데이터 호환성

- 저장 스키마 버전은 변경하지 않는다.
- 기존 편성 3개와 활성 편성 번호는 파일에 남겨 구버전 저장을 읽을 수 있게 한다.
- UI에서 무기를 변경하면 현재 활성 편성 하나에 자동 저장한다.
- 기존 해금된 3단계 운용법은 회수하지 않는다. 신규 해금 시에만 순차 조건을 적용한다.

## 검증

기능별 실패 테스트를 먼저 추가하고 다음을 검증한다.

- 로비에 한연화와 편성 버튼이 없고 3개 하단 메뉴는 유지됨
- 모든 로비 버튼이 9-slice 보조 또는 주요 프레임을 사용함
- 연구 진행 바와 순차 잠금 문구가 정확함
- 출전 시 Bootstrap을 경유해 Gameplay로 이동함
- 실제 출전 후 승전 화면에서 Lobby로 복귀함
- 경험치 반경 값은 유지되고 흡수 모션만 강화됨
- 일시정지 버튼과 메뉴가 안전 영역 안에 있음
- 무기 카드가 정사각형이며 클릭 시 상세 정보가 열림
- 720×1280 및 1080×2340 캡처에서 글자 겹침과 잘림이 없음
- 전체 EditMode 및 PlayMode 테스트 실패 0개

Unity 배치 작업은 BelowNormal 우선순위와 4코어 제한으로 순차 실행한다.
