- 작성일: 2026-08-03 KST

- 대상 브랜치: `master`
- 전투 길이: 180초 세로형 프로토타입

## 1. 목표

플레이어가 먼 카메라에서도 몬스터의 역할과 새 적의 등장 시점을 즉시 이해하고, 전승 선택 및 무기 감정 화면에서 현재 선택과 다음 성장 조건을 별도 설명 없이 이해하게 한다.

완료 조건은 다음과 같다.

1. 전승 선택 카드의 내부가 완전히 불투명하고 모든 문장이 한지 배경 위 짙은 먹색으로 읽힌다.
2. 방패 도깨비는 몸 전체 스프라이트가 깜빡이지 않으며, 정면 6회 타격·후방 우회·폭발 우회 규칙이 화면과 전투에서 일치한다.
3. 쥐, 처녀귀신, 도깨비가 순서대로 소개되고 체력·속도·접촉 피해의 차이가 육안으로 드러난다.
4. 특수 적은 한꺼번에 무작위로 섞이지 않고 정해진 시점에 하나씩 소개된다.
5. 감정 화면은 개발 용어 대신 선택한 성장, 현재 상태, 다음 강화 조건을 완전한 문장으로 표시한다.
6. 140개 활성 적 상한과 무할당 이동 틱을 유지한다.

## 2. 확인된 원인

### 전승 선택 카드

`UpgradeCardFrame.png`는 테두리만 있고 중앙 알파가 투명하다. 현재 `WeaponLegacyChoicePresenter`는 이 이미지를 버튼의 유일한 배경으로 사용하므로 전투 화면이 카드 내부로 비친다. 제목과 본문도 밝은 기본색을 일부 유지해 밝은 한지 배경에서 대비가 부족하다.

### 방패 도깨비 깜빡임

`FirstPlayableController.UpdateSpecialEnemyFrame`은 플레이어가 3월드 단위 안으로 들어오면 방패 도깨비의 몸 전체 스프라이트를 0.14초마다 `telegraph_0`과 `telegraph_1`로 교체한다. 두 예고 프레임은 기본 자세와 실루엣이 달라 머리 위 얼굴 또는 검은 덩어리가 번갈아 나타나는 것처럼 보인다.

### 몬스터 역할 불명확

웨이브는 시간별 콘텐츠 ID를 구분하지만 일반 몬스터는 모두 `EnemyArchetype.Normal` 배율 1을 사용한다. 따라서 쥐, 처녀귀신, 일반 도깨비가 이미지 외에는 같은 방식으로 걸어오며, 특수 적도 한 단계 안에서 무작위 가족이 계속 선택되어 학습 순서가 흐려진다.

### 감정 화면 용어와 배치

`전승 경로`, `현재 경지`, `다음 경지`는 내부 성장 모델을 그대로 노출한 용어다. `누적` 문장은 첫 결과 박스 아래 높이에 있으나 X 위치가 왼쪽으로 치우쳐 모달 바깥 가장자리에서 시작한다.

## 3. 선택한 접근법

단계적 학습형 웨이브를 사용한다.

- 기각: 현재 무작위 등장을 유지하고 능력치만 바꾸는 방식은 플레이어가 새 적을 관찰할 시간을 보장하지 못한다.
- 기각: 웨이브마다 한 종류만 끝까지 유지하는 방식은 이해하기 쉽지만 180초 전투가 반복적으로 변한다.
- 채택: 새 적을 짧은 단독 출현으로 소개한 뒤 이미 배운 적과 섞는다. 후반 난이도는 새로운 규칙을 계속 추가하는 대신 배운 역할의 조합으로 만든다.

## 4. 일반 몬스터 역할과 등장 순서

모든 배율은 같은 시각의 기본 체력·속도·접촉 피해에 곱한다. 엘리트 배율은 그 뒤에 기존 방식대로 적용한다.

| 몬스터 | 역할 | 체력 | 이동속도 | 접촉 피해 | 표시 크기 |
|---|---|---:|---:|---:|---:|
| 역병 쥐 | 물량형 기본 적 | 0.75배 | 1.10배 | 0.80배 | 1.00배 |
| 원한 처녀귀신 | 빠른 유리대포 | 0.55배 | 1.65배 | 0.75배 | 1.00배 |
| 일반 도깨비 | 느린 중장갑 | 2.60배 | 0.55배 | 1.35배 | 1.15배 |

일반 출현 시간표는 다음과 같다.

- 0~45초: 역병 쥐만 등장한다.
- 45초: `원한 처녀귀신 출현 · 매우 빠르지만 약합니다`를 2.2초 표시한다.
- 45~53초: 새로 생성되는 일반 적은 처녀귀신만 사용한다. 기존 쥐는 즉시 삭제하지 않는다.
- 53~90초: 쥐 60%, 처녀귀신 40%로 섞는다.
- 90초: `도깨비 출현 · 느리지만 매우 단단합니다`를 2.2초 표시한다.
- 90~100초: 새로 생성되는 일반 적은 도깨비만 사용한다. 기존 적은 유지한다.
- 100~135초: 쥐 25%, 처녀귀신 40%, 도깨비 35%로 섞는다.
- 135~165초: 쥐 20%, 처녀귀신 40%, 도깨비 40%로 최종 공세를 구성한다.
- 165초 이후: 기존 보스 경고 및 보스 규칙을 유지하고 새 일반 무리를 만들지 않는다.

삿갓귀신과 산적은 에셋과 콘텐츠 ID를 삭제하지 않지만 이번 180초 일반 출현 표에서는 제외한다. 이후 별도 행동이 생겼을 때 다시 도입한다.

첫 소개 구간도 기존 활성 적을 제거하지 않으므로 화면이 인위적으로 비지 않는다. 대신 새 스폰 종류와 안내 문구로 학습 구간을 만든다.

## 5. 특수 적 소개 규칙

특수 적의 첫 등장은 시드 무작위 선택이 아니라 고정 시각을 사용한다.

| 시각 | 특수 적 | 최초 안내 |
|---:|---|---|
| 102초 | 방패 도깨비 | `방패 도깨비 · 정면을 여러 번 치거나 뒤를 노리세요` |
| 120초 | 돌진 쇠뿔귀 | `돌진 쇠뿔귀 · 붉은 예고선에서 벗어나세요` |
| 138초 | 원혼 무당 | `원혼 무당 · 주변 적을 강화하니 먼저 처치하세요` |
| 150초 | 분열 쥐 | `분열 쥐 · 쓰러지면 둘로 갈라집니다` |

최초 소개 뒤에는 이미 소개된 특수 적만 재등장할 수 있다. 특수 적 총수는 일반 적 8명당 1명 이하로 제한하고, 같은 특수 적의 연속 생성에는 최소 8초 간격을 둔다. 첫 등장 안내는 콘텐츠 ID별 한 번만 표시한다.

이 규칙은 특수 적을 제거하지 않는다. 한 화면에 너무 많은 규칙이 동시에 처음 등장하는 상황만 막는다.

## 6. 방패 도깨비 전투 규칙과 시각 표현

### 전투 규칙

- 생성 시 방패 내구도는 6이다.
- 방패가 남은 동안 정면의 직접 공격은 내구도를 1 소모하고 피해량의 15%만 적용한다.
- 여섯 번째 정면 직접 공격도 감소 피해를 적용한 뒤 방패를 파괴한다.
- 공격 방향이 후방이면 방패 내구도를 소모하지 않고 피해량 100%를 적용한다.
- `Explosion`, `Pull`, `Reaction` 특성 공격은 방향과 관계없이 방패 내구도를 소모하지 않고 피해량 100%를 적용한다.
- 방패가 파괴되면 해당 개체가 죽을 때까지 모든 공격이 정상 피해를 준다.
- 방패는 면역이 아니므로 어떤 시작 무기 조합도 진행 불가능 상태가 되지 않는다.

### 시각 표현

- 몸 전체 렌더러에는 항상 `shield_dokkaebi/base.png`를 사용한다.
- `telegraph_0/1`을 몸 전체 애니메이션으로 교체하는 현재 동작을 제거한다.
- 체력 막대 아래에 같은 폭의 단색 청동 방패 막대를 하나 둔다. 내구도 6에서 가득 차고 0에서 사라진다.
- 정면 방어 성공 시 몸 전체에 0.08초의 옅은 청동색 틴트만 적용한다.
- 방패 파괴 시 한 번의 짧은 확대·복귀 펄스를 사용한다. 머리 위 얼굴, 아이콘, 흰 테두리, 반복 점멸은 사용하지 않는다.
- 새 PixelLab 또는 Imagegen 이미지는 만들지 않는다.

## 7. 전승 선택 UI

- 기존 검은 목재 테두리 이미지는 유지한다.
- 각 카드 버튼 내부에 사방 12픽셀 여백의 불투명 `JoseonUiPalette.Hanji` 배경 이미지를 테두리보다 뒤에 추가한다.
- 카드 이름, 전투 방식, 강점은 `HanjiInk`, 보완점은 `SealCrimson`을 사용한다.
- 모달 제목도 `HanjiInk`로 바꾼다.
- 카드 구조는 `이름 / 전투 방식 / 강점 / 보완점`을 유지해 선택 정보량은 늘리지 않는다.
- 배경, 아이콘, 글자는 모두 테두리 내부에서만 보이도록 현재 안전 여백을 유지한다.

## 8. 무기 감정·상세 UI

전승 관련 세 줄을 다음 사용자 문구로 바꾼다.

- 선택 전: `성장 선택 · 무기 3레벨에서 두 방식 중 하나 선택`
- 선택 후 첫 줄: `선택한 성장 · {전승 이름}`
- 선택 직후 둘째 줄: `현재 상태 · 성장 방향 선택 완료`
- 4레벨 전 셋째 줄: `다음 강화 · 무기 4레벨 달성 시 효과 강화`
- 5레벨 전 셋째 줄: `다음 강화 · 무기 5레벨 달성 시 최종 효과 완성`
- 최종 단계: `성장 완료 · 최종 효과 적용 중`

감정 화면 상단 무기 설명 아래에 다음 안내를 한 번 표시한다.

`무기 3레벨에 성장 방식을 선택하고, 4·5레벨에 선택한 효과가 강화됩니다.`

누적 옵션 문구는 다음처럼 바꾼다.

`지금까지 적용된 효과 · 피해량 +25% / 공격 범위 +10% / 지속 시간 +24%`

누적 옵션 라벨의 X 위치를 첫 추가옵션 결과 박스 내부 왼쪽 여백과 맞추고, 첫 박스 바로 아래의 전용 한 줄 영역에 배치한다. 세 성장 행은 누적 옵션과 겹치지 않도록 아래로 이동하며 확인 버튼의 44픽셀 이상 안전 간격을 유지한다. 720×1280과 1080×1920 기준에서 잘림과 겹침이 없어야 한다.

## 9. 구조와 데이터 흐름

- `WaveSchedule`은 시간 구간별 일반 적 가중치와 소개 구간을 소유한다.
- `WaveSpawnDirector`는 현재 경과 시간에 맞는 일반 적 선택, 고정 특수 적 최초 소개, 재등장 간격과 특수 적 비율 제한을 소유한다.
- `EnemyArchetypeProfile`은 일반·특수 콘텐츠 ID별 정적 능력치 배율과 방패 판정 규칙을 제공한다.
- `FirstPlayableController`는 프로필을 스폰 상태에 적용하고, 방패 내구도와 시각 막대의 생명주기를 해당 `EnemyState` 안에서 소유한다.
- `CombatHudPresenter`는 기존 웨이브 안내 경로를 재사용한다. 별도 알림 관리자나 싱글턴을 추가하지 않는다.
- `WeaponLegacyChoicePresenter`와 `WeaponAffixRevealPresenter`만 각자의 런타임 UI 배치와 문구를 변경한다.

씬과 프리팹 직렬화 구조는 변경하지 않는다. 런타임 생성 방식을 유지하고 새 패키지를 추가하지 않는다.

## 10. 성능과 안전

- 시간 구간과 프로필은 정적 값 또는 재사용 배열로 표현해 프레임별 할당을 만들지 않는다.
- 특수 적 소개 확인은 기존 작은 상태 집합과 정수 타이머를 재사용한다.
- 방패 막대는 방패 도깨비 생성 시 한 번 만들고 피격 시에만 갱신한다.
- 몸 전체 스프라이트 교체를 제거하므로 방패 도깨비의 프레임별 스프라이트 변경 비용은 감소한다.
- 전체 활성 적 상한 140을 유지한다.
- Unity 자동 검증과 Android 빌드는 동시에 돌리지 않으며, Unity 및 자식 프로세스는 `BelowNormal`, 6/16 논리 코어 제한으로 실행한다.

## 11. 테스트와 검증

테스트 우선으로 다음 실패 계약을 먼저 추가한다.

### EditMode

- 시간 0~45초에는 쥐만 선택된다.
- 처녀귀신과 도깨비 소개 구간에는 각각 해당 새 적만 새로 선택된다.
- 혼합 구간은 승인된 콘텐츠 ID와 가중치만 사용한다.
- 특수 적 최초 소개 순서는 102/120/138/150초와 일치한다.
- 특수 적 수가 일반 적의 1/8을 넘지 않고 같은 가족 재등장 간격이 8초보다 짧지 않다.
- 일반 적 프로필 배율이 표와 일치한다.
- 방패 정면 직접 공격 6회, 후방 우회, 폭발·끌어당김·조합 반응 우회가 각각 계약대로 동작한다.

### PlayMode

- 전승 카드마다 불투명 배경이 존재하고 테두리 뒤에 배치된다.
- 전승 카드와 제목의 글자색이 한지용 먹색 계열이다.
- 방패 도깨비가 가까이 있을 때도 몸 전체 스프라이트가 기본 프레임에서 바뀌지 않는다.
- 방패 내구도 막대가 6회 정면 타격에 따라 감소하고 파괴 뒤 사라진다.
- 각 일반·특수 적의 첫 등장 안내가 정확한 한글 문구로 한 번 표시된다.
- 감정 화면 세 줄과 누적 옵션 문구가 승인된 사용자 문구를 사용한다.
- 누적 옵션과 성장 행, 확인 버튼이 720×1280 및 1080×1920 레이아웃에서 겹치지 않는다.

### 회귀 및 빌드

- 관련 EditMode 및 PlayMode 테스트를 먼저 통과시킨다.
- 전체 EditMode와 전체 PlayMode를 순차 실행한다.
- 140개 대상 30초 성능 검증에서 이동 틱 0 B 할당과 기존 시간 예산을 유지한다.
- Android ARM64 IL2CPP 개발 APK를 다시 빌드한다.
