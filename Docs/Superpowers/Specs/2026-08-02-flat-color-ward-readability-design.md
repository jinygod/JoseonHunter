# 금줄·장승진 원거리 시인성 개선 설계

## 목표

먼 카메라에서 금줄과 장승진이 장식 PNG의 집합이 아니라 하나의 공격 범위로 즉시 읽히게 한다. 전투 판정과 성장 규칙은 보존하고, 선과 반응 효과를 절제된 두 색 중심의 표현으로 교체한다.

## 확정된 시각 원칙

- 기본 팔레트는 먹갈색 외곽선과 탁한 황토색 본선 두 색만 사용한다.
- 흰색 테두리, 흰색 림라이트, 무지개색, 다색 그라데이션은 사용하지 않는다.
- 피격과 완성 강조는 새로운 색을 추가하지 않고 황토색 본선의 밝기와 알파만 짧게 올린다.
- 작은 무늬보다 멀리서 남는 굵은 실루엣을 우선한다.
- 반복 텍스처의 절단면, 과도한 매듭, 선 위에 늘여 붙인 PNG를 제거한다.
- 동시에 여러 결계가 보이면 최신·반응 중인 결계를 우선하고 오래된 결계는 낮은 알파로 정리한다.

## 금줄

### 이동 중

- 현재의 반복 밧줄 텍스처를 제거한다.
- 먹갈색 외곽선 위에 황토색 본선을 겹친 연속 선으로 표현한다.
- 외곽선은 본선보다 조금만 굵게 하며 흰 테두리는 만들지 않는다.
- 중간 매듭 PNG는 제거한다. 시작점 표식이 필요할 때도 동일 팔레트의 작은 단색 표식만 사용한다.
- 선의 끝과 꺾이는 지점은 둥글게 연결해 끊어진 픽셀 조각처럼 보이지 않게 한다.

### 폐쇄 성공

- 영역 전체를 덮는 대형 도장·봉인 PNG를 제거한다.
- 닫힌 외곽선의 밝기가 한 번 차오른 뒤 원래 색으로 돌아온다.
- 내부에는 낮은 알파의 황토색 면이 짧게 나타났다 사라진다.
- 내부 반짝임은 6~8개의 작은 마름모로 제한하고, 동일 황토색의 밝기와 크기만 변화시킨다.
- 반짝임과 내부 면은 풀링하거나 재사용하며 폐쇄 때마다 오브젝트와 머티리얼을 새로 만들지 않는다.

## 장승진

### 장승과 경계

- 장승은 결계 꼭짓점을 표시하는 단순한 저색상 실루엣으로 축소한다.
- 중앙 봉인 PNG, 반복 매듭, 선을 따라 늘인 필드 PNG를 제거한다.
- 경계는 금줄과 같은 먹갈색 외곽선과 황토색 본선의 연속 선을 사용한다.
- 장승이 솟는 기존 단계와 경계가 순차적으로 열리는 타이밍은 유지한다.

### 통과 반응

- 적이 통과한 구간만 본선 밝기가 잠깐 상승한다.
- 접촉 지점에는 같은 황토색의 작은 마름모 불꽃 세 개만 발생한다.
- 별도 교차 PNG, 흰 섬광, 다색 충격파는 사용하지 않는다.

### 5레벨 재배치

- 5레벨 장승진이 플레이어를 따라 재배치되는 기능은 유지한다.
- 진 전체가 PNG 스티커처럼 미끄러져 보이지 않도록 기존 위치를 짧게 낮은 알파로 전환하고 새 위치의 장승과 선을 다시 또렷하게 세운다.
- 공격 판정 위치와 시각 위치가 어긋나지 않도록 현재 이동 좌표를 그대로 사용한다.

## 다른 무기와 몬스터에 적용할 공통 기준

이번 구현의 직접 수정 범위는 금줄과 장승진이다. 다만 같은 렌더링 경로에서 재사용되는 장식 효과를 점검해 다음 기준을 위반하는 공통 요소는 함께 정리한다.

- 원거리에서 한 픽셀 단위로 끊겨 보이는 반복선
- 흰 외곽선 때문에 가장자리가 지저분해지는 스프라이트
- 한 효과에 네 가지 이상 강조색을 사용하는 경우
- 공격 범위보다 장식 이미지가 더 크게 보이는 경우

몬스터 원본과 다른 무기의 개별 아트 전체를 이번 변경에서 일괄 재제작하지는 않는다. 별도 캡처에서 문제가 확인된 항목은 같은 원칙으로 후속 교체할 수 있게 팔레트와 선 표현을 재사용 가능한 구조로 둔다.

## 구현 경계

- 금줄 폐쇄 판정, 피해량, 지속시간, 성장 분기와 최대 기록점은 변경하지 않는다.
- 장승진의 배치 수, 경계 통과 판정, 피해량, 재진입 규칙, 진화 및 5레벨 이동 규칙은 변경하지 않는다.
- 프레젠터가 전투 판정을 소유하지 않으며 실행기는 시각 상태와 사건만 전달한다.
- 매 프레임 배열·리스트·머티리얼을 새로 생성하지 않는다.
- 사용하지 않게 된 에셋은 즉시 삭제하지 않고 참조 해제 여부를 검증한 뒤 별도 정리 대상으로 남긴다.

## 검증 기준

- 금줄 이동 중 반복 밧줄 텍스처와 매듭 PNG가 보이지 않는다.
- 금줄 폐쇄 때 대형 도장 PNG가 보이지 않고 내부 면과 제한된 반짝임만 나타난다.
- 장승진 중앙 봉인과 구간별 늘인 PNG가 보이지 않는다.
- 두 효과의 기본 표현에 흰색 외곽선이나 세 번째 강조색이 없다.
- 장승진 통과 시 실제로 맞은 구간 하나만 반응한다.
- 여러 장승진이 겹칠 때 오래된 진의 존재는 알 수 있지만 최신 진보다 강하게 보이지 않는다.
- 기존 금줄·장승진 EditMode 및 PlayMode 전투 테스트가 유지된다.
- 새 프레젠테이션 테스트가 색 제한, 장식 PNG 미사용, 풀 회수와 반응 구간 수를 검증한다.
- Unity 콘솔 오류 없이 플레이 모드 캡처에서 먼 카메라 기준으로 선이 연속된 형태로 읽힌다.
