# 사운드 보강 및 인게임 무기 액자 설계

## 1. 목표

현재 24개 사운드 큐와 18개 실제 클립으로 구성된 기본 오디오를 확장한다. 소리를 많이 겹치는 방향이 아니라 플레이어가 상태 변화를 즉시 알아야 하는 순간에 전용 효과음을 배치한다. 동시에 인게임 하단 무기 칸의 추가옵션 등급을 구슬처럼 보이는 작은 표식이 아니라, 무기 전체를 감싸는 선명한 액자 테두리로 표시한다.

## 2. 확정 범위

### 사운드

- Unity Asset Store의 `FREE Casual Game SFX Pack`을 사용자 계정에 추가하고 내려받는다.
- 이 팩은 50개, 8.6MB, CC0이며 UI·보상·감정·상자 연출에 필요한 짧은 효과음 후보로만 사용한다.
- 기존 `ExternalAssets/Audio`의 CC0 RPG·Impact 원본은 전투·몬스터 효과음 후보로 재사용한다.
- 전체 팩을 런타임에 넣지 않고 실제 사용하는 10~15개 클립만 `Resources/Audio/CC0` 아래에 선별 복사한다.
- 새 클립은 출처, 원본 파일명, 라이선스, 게임 내 용도를 오디오 권리 장부와 소스 목록에 기록한다.
- 짧은 모바일 효과음은 mono, Vorbis, preload, Decompress On Load 정책을 유지한다.

### 무기 액자

- 슬롯 가운데 배경은 투명하게 유지한다.
- 기존 `compact_weapon_slot` 단일 이미지에 의존하는 등급 표현을 제거한다.
- 바깥 짙은 그림자, 안쪽 등급 색상, 네 모서리 장식으로 구성된 빈 액자를 코드로 조립한다.
- 등급 색상은 회색, 초록, 파랑, 진홍, 금색 순서를 유지한다.
- 별은 슬롯 하단 중앙에 유지한다.
- 잠재 능력 아이콘은 액자와 혼동되지 않도록 우측 상단 작은 배지 영역으로 옮긴다.
- 버튼 판정 영역은 124×124 슬롯 전체를 유지한다.

## 3. 사운드 우선순위

### 1차 필수

- 플레이어 피격과 사망
- 정예 몬스터 사망
- 웨이브 전환과 정예 등장
- 보스 공격 경고, 돌진, 투사체, 장판 충돌
- 보물상자 등장과 개봉
- 일시정지와 재개
- 무기 감정 수치 상승, 등급 결정
- 전용 부적, 승리, 패배

### 1차에서 제외

- 로비·전투·보스 배경음악
- 모든 몬스터의 반복 울음소리
- 일반 몬스터 사망음
- 발걸음과 이동 반복음
- 모든 타격마다 별도 상태 효과음을 동시에 재생하는 방식

배경음악은 게임의 조선 민속 판타지 정체성에 미치는 영향이 커서, 일반 무료 판타지 음악을 임시로 넣지 않고 별도 선정 작업으로 남긴다.

## 4. 연결 구조

- `GameAudioCueId`에는 실제로 분리할 사건만 추가한다.
- `GameAudioClipCatalog`는 각 큐를 1~3개 짧은 변형 클립에 연결한다.
- `GameAudioDirector`의 기존 12채널 풀, 우선순위, 시간 제한 구조는 유지한다.
- 반복 빈도가 높은 일반 타격은 시간 제한과 변형 순환을 사용한다.
- 일반 몬스터 사망은 별도 소리를 재생하지 않고 정예 사망만 높은 우선순위로 구분한다.
- 보스 공격과 플레이어 사망은 높은 우선순위로 처리한다.
- 이벤트 소유자는 기존 Controller, CombatFeedbackDirector, UI Presenter를 유지하며 새 오디오 전용 매니저를 만들지 않는다.

## 5. 액자 시각 규격

- 슬롯 크기: 124×124
- 바깥 그림자: 6px, 짙은 갈색 또는 흑갈색
- 등급 띠: 4px, `WeaponAffixQualityBand` 색상
- 안쪽 하이라이트: 1~2px, 낮은 알파의 한지색
- 모서리 장식: 10~12px 사각 장식, 과도한 색상과 흰 외곽선 금지
- 무기 아이콘: 현재 68×68 유지, 액자 중앙 배치
- 별: 하단 22px 영역
- 잠재 배지: 우측 상단에서 세로 또는 작은 묶음으로 최대 3개

액자는 4면과 모서리를 별도 `Image`로 구성하여 어떤 화면 비율에서도 속이 채워지지 않고 선명하게 보이게 한다.

## 6. 실패 처리와 용량 관리

- 후보 클립이 게임 분위기와 맞지 않으면 가져오지 않고 기존 CC0 후보로 대체한다.
- 클립 누락 시 게임을 중단하지 않고 해당 큐만 무음 처리하며 경고는 한 번만 남긴다.
- Asset Store 전체 샘플 폴더, 데모 씬, 스크립트는 런타임 프로젝트에 포함하지 않는다.
- 원본 팩을 Git에 통째로 추가하지 않고, 선택된 CC0 클립과 라이선스 기록만 커밋한다.
- 반복 효과음이 12채널을 점유해 중요 효과음을 밀어내지 않도록 기존 재생 예산 테스트를 확장한다.

## 7. 검증

### 자동 검증

- 모든 새 큐에 실제 클립이 연결되는지 확인한다.
- 새 클립이 모바일 짧은 효과음 임포트 정책을 따르는지 확인한다.
- 플레이어 피격·사망, 정예 사망, 웨이브, 보스 공격, 상자, 감정 이벤트가 올바른 큐를 요청하는지 확인한다.
- 무기 슬롯에 외곽 액자 4면과 모서리가 존재하고 중앙이 투명한지 확인한다.
- 등급 변경 시 액자 전체 색상이 변경되고 별·잠재 배지가 유지되는지 확인한다.
- 전체 EditMode와 PlayMode 테스트를 실행한다.

### 런타임 검증

- 로비에서 출전하고 초반 웨이브, 레벨업, 상자, 정예, 보스, 승패까지 플레이한다.
- 사운드가 과도하게 겹치거나 분위기와 어긋나지 않는지 확인한다.
- 720×1280과 1080×2340에서 무기 액자가 잘리지 않고 품질 색상이 한눈에 보이는지 확인한다.
- Android 개발 APK를 빌드한다.

## 8. 완료 조건

- 기존 재사용 사운드 중 부적, 보스 경고·등장, 승리, 패배가 전용 음색으로 분리된다.
- 필수 전투·상자·감정 사건에 소리 피드백이 생긴다.
- 불필요한 전체 에셋 팩과 데모 콘텐츠가 프로젝트에 남지 않는다.
- 인게임 무기 슬롯이 투명 중앙부와 명확한 등급 액자를 가진다.
- 별과 잠재 배지가 액자와 충돌하지 않는다.
- 관련 테스트와 Android 개발 빌드가 통과하고 변경 사항이 `master`에 커밋·푸시된다.
