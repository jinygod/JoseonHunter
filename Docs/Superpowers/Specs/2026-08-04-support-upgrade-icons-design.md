# 패시브 강화 전용 픽셀 아이콘 설계

## 목표

레벨업 선택 카드의 패시브 강화가 공통 `福` 글자 대신 효과를 즉시 알아볼 수 있는 전용 픽셀 아이콘을 표시하도록 한다.

## 현재 범위

현재 실제 패시브 목록은 다음 세 가지뿐이다.

- `talisman` / 호신부적: 최대 체력 증가
- `boots` / 경쾌한 버선: 이동 속도 증가
- `warding_bell` / 수호 방울: 경험치 획득 범위 증가

이번 작업은 새로운 패시브 능력을 추가하지 않는다. 향후 패시브를 추가할 때 ID와 아이콘을 한 곳에 등록할 수 있는 연결 구조만 마련한다.

## 시각 설계

- 호신부적: 붉은 부적과 생명력을 뜻하는 따뜻한 금빛 문양
- 경쾌한 버선: 남색 버선 한 쌍과 짧은 바람결
- 수호 방울: 청동 방울과 청록색 흡인 파동
- 96×96 픽셀 아트, 투명 배경
- 흰색 외곽선을 사용하지 않고 짙은 먹색 외곽선 사용
- 각 아이콘은 먹색·적갈색/남색·고동색·청록/금색 가운데 3~4색만 사용
- 작은 카드에서도 형태가 읽히도록 넓은 면과 단순한 실루엣을 우선한다.

## Unity 연결

패시브 ID에서 전용 `Sprite`를 반환하는 런타임 카탈로그를 둔다. `FirstPlayableController`가 패시브 선택용 `UpgradeChoiceView`를 만들 때 이 카탈로그로 아이콘을 해결한다. 알 수 없는 ID나 누락된 에셋은 기존 글자 표식으로 안전하게 폴백한다.

아이콘은 `Resources/UI/SupportIcons` 아래에 저장하여 런타임 생성형 UI에서도 안정적으로 불러온다. 임포터는 Sprite, Point 필터, 밉맵 비활성화, 무손실 압축 규칙을 사용한다.

## 검증

- 세 패시브 ID가 서로 다른 비어 있지 않은 Sprite를 반환하는 EditMode 테스트
- 각 이미지가 픽셀 아트 임포트 규칙을 지키는 EditMode 테스트
- 실제 패시브 선택 카드에서 이미지가 활성화되고 공통 `福` 글자가 숨겨지는 PlayMode 테스트
- 관련 테스트 후 전체 EditMode/PlayMode 회귀 검증
