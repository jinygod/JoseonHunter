# 로비 헤더·풍뢰선 가독성 개선 설계

## 목표

- 로비 상단에서 계정 레벨, 계정명, 경험치, 엽전, 설정을 한눈에 구분할 수 있게 한다.
- 풍뢰선의 UI 아이콘과 전투 효과를 작은 모바일 화면에서도 즉시 알아볼 수 있게 한다.
- 무기 상세 정보에 `등급 미상`이 노출되지 않고 실제 추가옵션 등급이 표시되게 한다.
- 기존의 조선 민속 판타지 색감과 저해상도 픽셀 스타일은 유지하되, 불필요하게 자글거리는 묘사를 줄인다.

## 확인된 원인

1. 풍뢰선에는 전용 `uiIcon`이 지정되지 않아 96×96 전투용 바람 프레임 첫 장이 무기 아이콘으로 재사용된다.
2. 풍뢰선 전투 효과는 실행기에서 작성 크기를 줄인 뒤 공통 `WeaponPresentationScale`에서 다시 축소되어 실제 화면에서 지나치게 작다.
3. 로비 헤더는 계정 배지, 경험치 바, 엽전, 설정 버튼이 짧은 가로 폭에 각각 배치되어 서로 밀리고 통화 수치가 묻힌다.
4. 무기 상세창은 구조화된 추가옵션 굴림 목록이 없을 때 요약 문자열을 사용하지만, 이미 전달된 등급 목록을 활용하지 않고 `등급 미상`을 붙인다.

## 선택한 방향: B안

### 1. 로비 계정 헤더

- 왼쪽을 하나의 계정 프로필 영역으로 묶는다.
  - 작은 원형 또는 팔각형 레벨 문장에 `20` 표시
  - 오른쪽 첫 줄에 `요괴 사냥꾼`
  - 둘째 줄에 짙은 빈 바와 선명한 녹색 경험치 채움
  - 경험치 숫자는 바 중앙에 작고 또렷하게 표시
- 오른쪽은 통화와 설정 영역으로 분리한다.
  - 밝은 금색 엽전 픽셀 아이콘과 보유 수치를 같은 통화 캡슐 안에 배치
  - 설정 버튼은 별도 정사각 버튼으로 두고, 현재 코드 조각으로 만든 톱니바퀴 대신 전용 UI 스프라이트 사용
- 배경은 검은 먹색, 강조는 금색과 녹색만 사용해 색 수를 제한한다.
- 기존 직렬화 프리팹에서도 레이아웃이 갱신되도록 생성 시점뿐 아니라 바인딩 시점에도 헤더 배치를 적용한다.

### 2. 풍뢰선 전용 UI 아이콘

- PixelLab으로 별도 UI 아이콘을 제작한다.
- 형태는 펼친 접부채 실루엣으로 고정한다.
- 팔레트는 짙은 남색, 청록, 밝은 하늘색, 소량의 금색으로 제한한다.
- 외곽은 한두 픽셀의 짙은 테두리를 사용하고 흰색 외곽선과 미세한 내부 문양은 사용하지 않는다.
- 무기 정의의 `uiIcon`에 새 아이콘을 직접 연결해 전투 애니메이션 프레임 재사용을 제거한다.

### 3. 풍뢰선 전투 효과

- 기존의 작은 소용돌이 형태 대신 다음 세 단계가 구분되게 한다.
  1. 부채질: 넓고 굵은 청록색 바람 부채꼴
  2. 표식: 대상 아래 짧게 남는 단순한 원형 바람 문양
  3. 낙뢰: 밝은 하늘색 중심과 짙은 남색 외곽을 가진 굵은 번개 섬광
- 효과 프레임도 UI 아이콘과 동일한 제한 팔레트를 사용한다.
- 실행기와 공통 크기 보정의 중복 축소를 제거하고, 초기 레벨에서도 캐릭터 몸체보다 확실히 큰 바람 궤적이 보이게 한다.
- 공격 판정은 기존 픽셀 마스크와 게임 밸런스를 유지하고 표시 크기만 과장되지 않게 맞춘다.
- 다른 무기 전체를 동시에 재작업하지는 않지만, 새 에셋의 임포트 설정을 선명한 픽셀 기준으로 삼는다.

### 4. 추가옵션 등급 표시

- 상세창은 구조화된 굴림 목록이 있으면 현재와 같이 각 굴림의 실제 등급을 표시한다.
- 굴림 목록이 비어 있고 요약 수치와 등급 목록만 남아 있으면 두 목록을 순서대로 결합한다.
- 등급 목록까지 없을 경우 임의로 `등급 미상`을 보여주지 않고 중립적인 `추가옵션` 표기로 처리한다.
- 현재 스크린샷처럼 최대 옵션이 저장되어 있으면 `[최대] 재사용 대기시간 -12%`처럼 출력한다.

## 오디오 설정 패널 보정

- 이번 헤더 수정 범위에서 설정 버튼과 함께 슬라이더 손잡이도 작은 금색 손잡이로 정리한다.
- 손잡이가 트랙 바깥으로 크게 튀어나오는 현재 레이아웃을 수정하되 저장 및 실시간 음량 적용 동작은 변경하지 않는다.

## 검증

- 로비 PlayMode 테스트에서 엽전 아이콘·보유량·계정 레벨·설정 버튼이 존재하고 서로 겹치지 않는지 확인한다.
- 풍뢰선 무기 정의에 전용 `uiIcon`이 연결됐는지 EditMode 테스트로 확인한다.
- 풍뢰선 전투 프레임 인덱스와 공격 판정 관련 기존 테스트를 유지하고, 최소 표시 크기와 전용 프레임 연결을 검증한다.
- 상세창 테스트에 `굴림 없음 + 등급 목록 있음` 사례를 추가해 `등급 미상`이 다시 나타나지 않게 한다.
- 전체 EditMode·PlayMode 테스트를 실행하고 로비 및 전투 캡처를 육안 확인한다.

## 제외 범위

- 모든 무기·캐릭터 에셋의 전면 리뉴얼
- 풍뢰선의 공격력, 재사용 대기시간, 타격 판정 변경
- 계정 성장 및 엽전 경제 밸런스 변경
