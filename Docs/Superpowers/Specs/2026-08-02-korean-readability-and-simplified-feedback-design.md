# 한글 전용 UI와 원거리 전투 피드백 개선 설계

## 목표

무기 감정 화면, 각궁 아이콘, 경험치 획득물, 피해 숫자, 장승 수호신 강림, 전투 종료 화면을 같은 원거리 시인성 기준으로 정리한다. 한지·먹색·황토색 중심의 조선 민속 판타지 분위기를 유지하면서도 장식보다 정보와 실루엣이 먼저 읽혀야 한다.

## 확정된 공통 원칙

- 흰 외곽선과 미세한 금속 장식은 사용하지 않는다.
- 작은 화면에서 사라지는 한 픽셀 장식보다 굵고 단순한 실루엣을 우선한다.
- UI는 한지, 먹갈색, 황토색, 주홍색 도장 포인트 안에서 구성한다.
- 월드 스프라이트는 한 자산에 3~5색만 사용하며 배경과 겹치는 저대비 색을 피한다.
- UI 아이콘, 잠재능력 설명 아이콘, 전투 애니메이션 프레임을 서로 대신 사용하지 않는다.
- 플레이어에게 노출되는 실행 중 문구는 한글만 사용한다.

## 무기 감정 화면

### 행과 등급 표식

- 현재 검보라색 슬롯머신 창과 청록색 보석 장식을 감정 결과 화면에서 제거한다.
- 추가옵션 결과 행은 짙은 먹갈색 바탕과 황토색 글자로 강조한다.
- 잠재능력 행은 본문 한지보다 한 단계 어두운 옅은 황토색 면과 먹갈색 글자를 사용한다.
- 행 테두리는 단순한 먹갈색 2단 선으로 제한한다. 반복 장식, 보석, 금속 모서리는 사용하지 않는다.
- `일반`, `고급`, `최대`는 별도 네모 칸이 아니라 결과 제목 옆의 작은 주홍·먹갈색 도장으로 표시한다.
- 잠긴 슬롯은 `잠재 능력 1 · 잠김`처럼 짧은 한글 문구와 낮은 명도로 표시한다.
- 확인 버튼도 같은 한지·먹갈색 버튼 규칙을 사용한다.

### 대비

- 밝은 한지 위 본문은 먹갈색을 사용한다.
- 짙은 결과 행 위 글자는 황토색을 사용한다.
- 텍스트와 배경 사이의 명도 차이는 유지하되 순수 흰색은 사용하지 않는다.

## 각궁 UI 아이콘

### 문제 원인

현재 `ResolveWeaponSprite`가 각궁의 전용 UI 아이콘이 아니라 전투용 조준 애니메이션의 첫 프레임을 반환한다. 원형 조준 장식과 가는 금색 픽셀이 감정 화면의 한지 배경과 겹쳐 각궁의 실루엣이 흐려진다.

### 변경

- 무기 정의에 전용 UI 아이콘 참조를 분리하고 전투 프레임 인덱스는 변경하지 않는다.
- 각궁 UI 아이콘은 C자형 활대가 먼저 보이는 3~5색 픽셀 아트로 제작한다.
- 짙은 먹갈색 외곽, 황토색 활대, 주홍색 손잡이와 시위만 사용한다.
- 원형 조준 장식, 미세한 금속 반짝임, 흰 외곽선을 사용하지 않는다.
- 아이콘은 감정 화면, 강화 선택지, 무기 랙에서 동일하게 사용한다.
- 전투 투사체와 판정 마스크는 변경하지 않는다.

## 경험치 획득물과 피해 숫자

### 경험치 불꽃

- 시작 표시 배율을 `0.14`에서 약 `0.30`으로 확대한다.
- 실제 획득 범위 `0.58`과 최종 습득 거리 `0.42`는 변경하지 않는다.
- 짙은 남색 외곽과 청록색 중심의 3색 실루엣을 유지하고, 크기만 약하게 맥동시킨다.
- 맥동은 오브젝트별 위상만 달리하며 매 프레임 할당을 만들지 않는다.

### 피해 숫자

- 일반 피해 숫자는 현재 크기의 약 1.8배, 우두머리 피해 숫자는 약 1.9배로 확대한다.
- 숫자는 굵은 피해 전용 서체를 사용한다.
- 흰 테두리 대신 짙은 먹색 그림자 또는 언더레이를 사용한다.
- 일반 표시 시간은 약 `0.62`초로 늘리고, 기존 누적 표시와 풀링은 유지한다.
- 치명타는 크기 펀치와 황토색 강조로 구분하되 새로운 강조색을 추가하지 않는다.

## 장승 수호신 강림

### 문제 원인

현재 잠재능력 설명용 `jangseung_guardian_descent` 아이콘을 월드 오브젝트로 직접 생성한다. 설명용으로 나뉜 작은 도상이 전투 화면에서는 잘린 PNG 조각처럼 보인다.

### 변경

- 잠재능력 설명 아이콘을 월드 시각물로 사용하는 연결을 제거한다.
- 하나의 온전한 저색상 장승 수호신 스프라이트를 전투 전용 자산으로 사용한다.
- 연출은 `바닥 그림자 표시 → 위에서 수직 낙하 → 짧은 눌림 → 황토색 먼지 고리 → 소멸` 순서로 구성한다.
- 장승 몸체는 3~5색, 먼지와 그림자는 기존 먹갈색·황토색 팔레트만 사용한다.
- 여러 잘린 이미지나 흰 섬광을 겹치지 않는다.
- 피해 시점, 대상 선택, 피해량, 잠재능력 지속시간과 판정 마스크는 유지한다.

## 한글 전용 HUD와 전투 종료 화면

### HUD

- `HP`는 `체력`, `XP`는 `경험치`, `COIN`은 `엽전`, `KILLS`는 `처치`, `BOSS`는 `우두머리`로 바꾼다.
- 영문 우두머리 경고는 `강한 기운이 다가옵니다`로 바꾼다.
- 남은 시간 숫자는 그대로 사용한다.

### 전투 종료

- 임시 IMGUI `OnGUI` 결과창을 제거하고 기존 화면 Canvas에 전용 결과 프레젠터를 추가한다.
- 결과판은 불투명한 한지 면과 먹갈색 테두리를 사용하며 뒤 전투 화면과 글자가 섞이지 않게 한다.
- 패배 제목은 `전투 종료`, 승리 제목은 `토벌 완료`로 표시한다.
- 결과에는 `생존 시간`, `처치`, `도달 레벨`, `획득 엽전`을 한글로 표시한다.
- 버튼 문구는 `다시 시작`만 표시한다. R키 재시작 입력은 유지하되 영문 키 안내는 노출하지 않는다.
- 결과창이 열린 동안 배경 조작과 무기 상세 열기를 막는다.

## 구조와 데이터 흐름

- `WeaponDefinitionAsset`이 전투 프레임과 별도로 UI 아이콘을 소유한다.
- `FirstPlayableController`는 전투 결과 상태와 다시 시작 진입점을 제공하고 화면 구성은 소유하지 않는다.
- `FirstPlayableUiBootstrap`이 HUD, 무기 랙, 모달과 함께 전투 종료 프레젠터를 구성하고 상태를 전달한다.
- `FirstPlayableUiState`는 종료 여부, 승패, 결과 수치를 읽기 전용으로 전달한다.
- `DamageNumberPresenter`와 픽업 프레젠테이션은 기존 풀·런타임 오브젝트 소유권을 유지한다.
- `JangseungWardExecutor`는 전투 규칙을 유지하고 전용 강림 프레젠테이션 상태만 갱신한다.

## 성능과 호환성

- 경험치 맥동, 피해 숫자, 수호신 애니메이션은 기존 오브젝트 또는 풀에서 Transform과 색만 갱신한다.
- 매 프레임 새 머티리얼, 배열, 리스트를 만들지 않는다.
- 새 UI 아이콘 필드는 비어 있을 때 기존 첫 프레임으로 되돌아가는 호환 경로를 둔다.
- 현재 사용자 수정 상태인 Gameplay 씬, 프로젝트 설정, 동적 폰트 에셋은 작업 커밋에 포함하지 않는다.

## 검증 기준

- 감정 화면에서 검보라색 슬롯창, 청록 보석, 분리된 네모 등급 칸이 보이지 않는다.
- 각궁이 원형 조준 장치가 아니라 단순한 활 실루엣으로 보인다.
- 경험치 불꽃의 월드 표시는 이전보다 2배 이상 크지만 획득 범위는 변하지 않는다.
- 일반·우두머리 피해 숫자가 원거리 카메라에서도 읽히며 흰 외곽선이 없다.
- 수호신 강림이 한 몸체의 수직 낙하로 보이고 설명 아이콘 조각이 월드에 나타나지 않는다.
- 전투 종료 결과판이 불투명하며 모든 안내가 한글이다.
- HUD와 우두머리 경고에 영문 레이블이 남지 않는다.
- 관련 EditMode와 PlayMode 테스트가 통과하고 Unity 콘솔에 새 오류가 없다.
- 720×1280과 1080×2340 캡처에서 감정 화면, 일반 전투, 수호신 강림, 전투 종료를 육안 확인한다.
