# 로비 선택 상태 및 잠금 표현 개선 설계

## 목표

- 출전 준비 화면에서 현재 선택한 난이도를 한눈에 구분한다.
- 하단 내비게이션의 현재 `출전` 탭과 실제 출전 버튼이 눌러야 하는 요소로 명확히 보이게 한다.
- 잠긴 난이도는 `잠김`이라는 보조 문구 없이 시각적 봉인과 자물쇠로 전달한다.
- 화면 상단의 중복 상태 문구를 제거해 핵심 선택 요소에 시선을 집중한다.

## 범위

대상은 `PatrolPresenter`가 소유하는 난이도 버튼, 출전 버튼, 단계 상태 문구와 `LobbyNavigationPresenter`가 소유하는 하단 내비게이션 선택 표현이다. 스테이지 해금 규칙, 난이도 수치, 저장 데이터, 출전 라우팅은 변경하지 않는다.

## 시각 규칙

### 난이도 선택

- 선택된 난이도 버튼은 밝은 금색 5픽셀 외곽선과 얇은 청록색 안쪽 강조선을 사용한다.
- 선택된 버튼 내부는 어두운 적갈색으로 유지해 밝은 테두리와 글자가 분리되게 한다.
- 선택되지 않았지만 해금된 버튼은 검은 먹색 배경과 가는 갈색 테두리를 사용한다.
- 선택 상태가 바뀌면 동일한 강조 테두리가 새 버튼으로 즉시 이동한다.
- 색만 바꾸는 방식에 의존하지 않고 실제 별도 테두리 `Image` 계층으로 상태를 표현한다.

### 대흉 잠금

- 버튼 글자는 항상 `대흉`으로 표시하고 `· 잠김` 문자열은 사용하지 않는다.
- 잠긴 버튼에는 왼쪽 아래에서 오른쪽 위로 지나가는 대각선 봉인선을 표시한다.
- 봉인선 중앙에는 24×24 크기의 단순한 금색 픽셀 자물쇠를 배치한다.
- 자물쇠 아이콘은 PixelLab으로 제작하며, 투명 배경·짙은 남색 외곽선·금색 몸체·흰 테두리 없음 규칙을 따른다.
- 잠금 상태에서도 버튼은 클릭 입력을 받아 기존 해금 조건 안내를 계속 보여준다.

### 출전 표현

- 큰 `출전` 버튼에는 밝은 금색 외곽선과 안쪽 밝은 금갈색 선을 적용한다.
- 출전 불가능 상태에서는 기존 비활성 동작을 유지하면서 강조선의 채도와 알파를 낮춘다.
- 하단 내비게이션에서 현재 선택된 `출전` 탭에도 같은 밝은 금색 테두리를 사용한다.
- 선택되지 않은 `무기 연구`, `수련` 탭은 어두운 배경과 가는 갈색 테두리만 유지한다.

## 문구 정리

- `Stage Status`의 `15분 생존 · 흉조` 문구는 표시하지 않는다.
- 난이도 이름은 세 난이도 버튼에서만 전달한다.
- 스테이지 이름과 실제 잠금 조건 안내용 `Patrol Feedback`은 유지한다.

## 구현 구조

- 기존 런타임 uGUI 생성 방식을 유지한다.
- `PatrolPresenter`에 난이도·출전 버튼용 장식 계층을 멱등적으로 생성하거나 재사용하는 작은 스타일 메서드를 둔다.
- `LobbyNavigationPresenter`는 현재 선택된 탭의 장식 상태를 함께 갱신한다.
- 테두리와 봉인선은 기본 `Image`를 사용해 해상도 변화에 대응한다.
- 자물쇠만 별도 PNG 스프라이트로 만들고 `Resources/Lobby` 경로에서 불러온다.
- 씬과 프리팹을 통째로 재생성하지 않고 런타임 보강 코드가 기존 직렬화 계층에도 동일하게 작동하도록 한다.

## 테스트

- 선택된 난이도에만 밝은 외곽선과 내부 강조선이 활성화되는지 PlayMode 테스트로 검증한다.
- 난이도 변경 후 강조 테두리가 이동하는지 검증한다.
- 잠긴 대흉 버튼이 `대흉`만 표시하며 봉인선과 자물쇠를 가지는지 검증한다.
- `Stage Status`가 빈 문자열인지 검증한다.
- 하단 `출전` 탭과 큰 출전 버튼의 강조 테두리가 존재하고 활성 상태를 반영하는지 검증한다.
- 기존 로비 전체 테스트와 전체 PlayMode 테스트를 실행한다.
- 720×1280 모바일 비율 캡처로 선택·잠금·출전 상태를 육안 확인한다.

## 제외 범위

- 스테이지 난이도 해금 순서 변경
- 스테이지 전투 밸런스 변경
- 새 난이도 추가
- 버튼 전체를 고정 크기 이미지로 교체
- 저장 형식 또는 계정 진행도 변경
