# 프리미엄 모바일 로비 개편 설계

## 목표

현재 기능 위주의 로비를 실제 출시 모바일게임처럼 보이는 한 화면 홈으로 개편한다. 탕탕특공대의 명확한 정보 위계와 큰 출전 버튼을 참고하되, 조선 민속 판타지의 고유 색과 한연화를 게임의 얼굴로 살린다.

## 확정 방향

비교안 C인 혼합형을 사용한다. 상단에는 한연화의 고품질 비픽셀 일러스트를 크게 보여주고, 하단에는 현재 출전 정보를 담은 간결한 카드와 큰 출전 버튼을 배치한다. 기능이 없는 메뉴와 재화는 추가하지 않는다.

## 로비 화면 구성

### 상단 상태 영역

- 왼쪽: `순찰 준비`
- 오른쪽: 실제 저장 데이터의 `엽전` 수량
- 에너지, 보석, 우편, 상점, 이벤트 등 미구현 요소는 표시하지 않는다.

### 한연화 영웅 영역

- 화면 상단 약 55%를 사용한다.
- 한연화는 성인 여성인 조선 판타지 퇴마 검사로 표현한다.
- 사람처럼 자연스러운 고품질 게임 일러스트이며 픽셀 아트가 아니다.
- 검붉은 개량 한복, 제한된 금색 장식, 긴 흑발, 자신감 있는 표정을 사용한다.
- 아름답고 관능적이되 노출이나 선정성 자체가 목적이 아닌 고급스럽고 강한 인상을 우선한다.
- 달빛, 기와지붕, 안개가 있는 야간 도성 배경을 사용해 게임 세계관을 전달한다.
- 로비에서는 전신 또는 허벅지 위까지 보이는 크롭을 사용한다.

### 출전 카드

- 현재 스테이지와 난이도
- 시작 무기와 선택된 운용법
- 최고 기록 또는 기록 없음
- 가장 강한 시각 요소인 금색 `출전` 버튼
- 기존 편성 전환과 저장 기능은 카드 내부의 작은 보조 조작으로 유지한다.

### 하단 내비게이션

실제로 작동하는 세 메뉴만 표시한다.

1. `무기 연구`
2. `출전`
3. `공통 수련`

현재 선택 메뉴는 검붉은 바탕과 금색 발광으로 명확히 구분한다.

## 무기 연구와 공통 수련

기존 기능과 데이터 흐름은 유지하되 같은 로비 셸 안에서 패널만 전환한다. 한지색 전면 전체 박스는 제거하고, 불투명한 먹색 카드와 금색 구분선, 넓은 여백으로 읽기 쉽게 만든다. 모든 버튼은 최소 터치 영역을 확보하며 한글만 사용한다.

## 로딩 화면 활용

같은 한연화 원화를 중복 저장하지 않고 로비와 로딩에서 공유한다.

- 로비: 전신 중심 크롭
- 로딩: 얼굴과 상반신 확대 크롭
- 로딩에는 어두운 오버레이, 게임 제목, 상태 문구, 진행 막대를 올린다.
- 빠른 기기에서도 인지할 수 있도록 기존 최소 노출 시간은 유지한다.

## 시각 자산

### 비픽셀 AI 일러스트

- 한연화 영웅 원화 1장
- 투명 배경 캐릭터 레이어와 야간 도성 배경을 분리할 수 있으면 분리한다.
- 모바일 텍스처 크기와 메모리를 고려해 Unity 임포트 최대 크기는 2048로 제한한다.

### PixelLab UI 자산

- 9-slice 가능한 출전 카드 프레임
- 금색 출전 버튼의 기본·눌림 상태
- 하단 탭의 기본·선택 상태
- 소형 엽전 장식과 메뉴 상징

팔레트는 먹색, 검붉은색, 탁한 금색, 따뜻한 한지색으로 제한한다. 흰 외곽선, 과도한 색 수, 작은 화면에서 뭉개지는 잔픽셀 장식은 사용하지 않는다.

## 움직임

- 한연화 영웅 영역에는 매우 느린 호흡 또는 1~2% 크기 변화와 약한 배경 시차만 적용한다.
- 출전 버튼은 과하지 않은 금색 광택 이동 또는 약한 맥동을 사용한다.
- 탭 전환은 0.15~0.2초 색상 전환을 사용한다.
- 지속적으로 큰 텍스처를 재생성하거나 비싼 블러를 사용하지 않는다.

## 구현 구조

- 기존 `LobbyBootstrap`, `LobbyNavigationPresenter`, `PatrolPresenter`, `WeaponResearchPresenter`, `CommonTrainingPresenter`가 가진 기능 소유권은 유지한다.
- 로비 셸과 스타일 팩토리를 개편하고 각 프레젠터의 배치만 새 구조에 맞춘다.
- 런타임에 모든 UI를 중복 생성하지 않도록 기존 프리팹 빌드 흐름을 따른다.
- 한연화 원화는 `Resources/Lobby`에서 로비와 Bootstrap 로딩이 함께 참조한다.
- 저장 데이터 형식과 게임플레이 씬은 변경하지 않는다.

## 오류와 대체 표시

- 한연화 또는 UI 스프라이트가 누락되면 단색 먹색·금색 기본 UI로 기능은 계속 사용할 수 있어야 한다.
- 세션 데이터가 아직 준비되지 않았으면 기존 `MetaGameSession.EnsureExists()` 흐름으로 초기화한다.
- Safe Area를 계속 적용해 노치와 홈 인디케이터 영역을 침범하지 않는다.

## 검증 기준

- 720×1280과 1080×2340 세로 화면 캡처에서 텍스트가 겹치거나 잘리지 않는다.
- 기본 출전, 무기 연구, 공통 수련 화면을 각각 캡처한다.
- 실제 세 메뉴와 기존 편성·구매·저장 기능이 계속 작동한다.
- Bootstrap 로딩에서 한연화 확대 크롭과 진행 막대가 보이고 로비로 전환된다.
- EditMode와 Lobby/Bootstrap 관련 PlayMode 테스트가 통과한다.
- 모바일 텍스처 임포트 설정과 메모리 사용이 과도하지 않다.

## 범위 밖

- 상점, 우편, 임무, 에너지, 보석 등 새 메타 시스템
- 로비에서의 대화·호감도 시스템
- 여러 캐릭터 선택 기능
- 게임플레이 전투 화면의 재설계
