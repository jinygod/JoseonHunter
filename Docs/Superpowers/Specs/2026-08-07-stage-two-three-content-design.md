# 2·3장 전용 콘텐츠 설계

작성일: 2026-08-07

상태: 사용자 승인 완료

## 1. 목표

현재 해금 구조만 존재하는 `2장 도깨비 고개`와 `3장 월식 왕릉`에 서로 다른
15분 전투, 유한 전장, 신규 몬스터, 신규 중간보스·최종보스, 전용 픽셀 아트를
구현한다. 1장 전투와 몬스터를 색만 바꾸어 재사용하지 않고, 멀리 잡힌 모바일
카메라에서도 공격 역할과 위험 표시가 즉시 읽히게 한다.

핵심 경험은 다음과 같다.

- 2장은 좁혀 오는 단단한 도깨비와 방패·돌진을 뚫는 전투다.
- 3장은 원거리 투사체와 저주 장판 사이의 안전지대를 관리하는 전투다.
- 각 장의 보통은 새 규칙을 순서대로 소개하고, 흉조·대흉은 새 조합과 보스
  연계로 어려워진다.
- 난이도가 높은 장과 모드는 엽전·계정 경험치·무기 숙련도를 더 많이 준다.
- 물리 장애물 길찾기를 추가하지 않고도 유한 전장의 압박과 장소 정체성을 만든다.

- 신규 일반·정예 몬스터 10종

- 장별 기본 전투·경험치·보상 배율
- PixelLab 기반 캐릭터·타일·장식물 제작과 Unity 임포트 계약
- 로비 출전 활성화, 해금·정산·결과 화면 연결
- 관련 자동 테스트, 성능 검증, Android 개발 빌드

### 제외

- 신규 플레이어 무기나 패시브

## 3. 기술 구조

현재 `WaveSchedule`과 일부 보스 처리가 1장 전역 정적 데이터에 결합되어 있다.
컨트롤러에 장 ID 조건문을 늘리지 않고 다음 데이터 경계로 분리한다.

### 3.1 StageCombatDefinition

각 장은 다음 정보를 하나의 읽기 전용 정의로 제공한다.

- 안정적인 `StageId`
- 전장 크기와 경계 표현
- 바닥·외곽·장식물 시각 프로필
- 시간 구간별 적 가중치, 활성 상한, 무리 생성 규칙
- 특별 적 소개 시점
- 5분·10분 중간보스와 15분 최종보스
- 장 기본 체력·공격력·경험치·보상 배율
- 장별 음악 역할

`StageCombatCatalog`가 선택된 `StageId`를 정의로 변환한다. 정의가 누락되면 전투
씬으로 진입하지 않고 기존의 `출전 정보를 불러오지 못했습니다` 처리를 사용한다.

### 3.2 WaveSpawnDirector

`WaveSpawnDirector`는 더 이상 전역 `WaveSchedule`을 직접 읽지 않는다. 선택된 장의
웨이브 프로필을 생성 시 주입받고, 같은 시드에 같은 생성 순서를 보장한다. 1장
데이터는 새 형식으로 그대로 옮겨 기존 전투 회귀를 막는다.

### 3.3 BossCombatProfile

보스별로 다음 값을 데이터화한다.

- 표시 이름, 스프라이트와 크기
- 체력·공격력·이동 속도
- 체력 구간별 패턴 순서
- 경고·실행·회복 시간
- 공격 범위와 안전 통로 조건

원형 강타, 직선 돌진, 부채꼴 휘두르기, 낙석, 방사 투사체, 초승달 베기,
저주 장판, 위치 지정 솟아오르기를 재사용 가능한 공격 원형으로 만든다. 장별 보스는
원형을 조합하되 개별 Update 구현을 복제하지 않는다.

## 4. 공통 전장 규칙

2장과 3장은 외곽만 막힌 넓은 유한 전장을 사용한다.

- 플레이어 위치는 전장 사각형 안으로 제한한다.
- 적은 실제 카메라 밖이면서 전장 안인 지점에서 생성한다.
- 플레이어가 외곽에 붙어도 적 생성 후보가 고갈되지 않도록 반대편·측면 후보를
  순서대로 검사한다.
- 외곽 절벽·담장만 충돌하며 내부 소나무·장승·봉분·석등·비석은 통과 가능하다.
- 검은 화면 바깥이 보이지 않도록 카메라 가시 범위보다 넓은 장식 테두리를 둔다.
- 내부 장식은 결정적 시드로 배치하고 카메라 이동마다 새로 생성하지 않는다.
- 기존 무한 전장 시스템은 1장에 그대로 유지한다.

유한 경계는 길찾기를 요구하는 미로가 아니다. 적은 계속 플레이어를 직선 추적할 수
있으며, 외곽에서만 좌표가 제한된다.

## 5. 2장 도깨비 고개

### 5.1 전장

- 크기: 약 `72 x 112` 월드 단위
- 형태: 세로로 긴 산길
- 주색: 황토, 탁한 이끼색, 짙은 청록, 벽돌색 경고, 작은 금색 강조
- 외곽: 절벽과 어두운 수풀
- 통과 장식: 소나무, 장승, 바위, 낡은 문, 작은 제단

바닥은 작은 잡티를 반복하지 않고 큰 흙길 덩어리와 단순한 돌 패턴으로 구성한다.
절벽은 길처럼 보이게 유도하지만 내부에 충돌 벽을 만들지 않는다.

### 5.2 신규 적

| 적 | 역할 | 핵심 규칙 |
|---|---|---|
| 몽둥이 깨비 | 단단한 기본병 | 느린 이동, 높은 체력, 짧고 굵은 피격 반응 |
| 방패 깨비 | 정면 방어 | 정면 피해 감소, 난이도별 타격 수 후 방패 파괴와 경직 |
| 쇠뿔 깨비 | 돌진 | 붉은 직선 경고 후 장거리 돌진, 빗나가면 회복 시간 |
| 돌팔매 깨비 | 원거리 압박 | 큰 투사체 하나를 예고 후 투척, 낮은 연사 빈도 |
| 붉은 뿔 정예 | 연계 공격 | 돌진 후 짧은 회전 공격, 정예 체력바 표시 |

방패는 무제한 방어가 아니다. 보통·흉조·대흉에 따라 내구 타격 수를 높이고,
관통·후방 공격·강한 단발 무기가 각기 다른 방식으로 유리하게 한다.

### 5.3 15분 웨이브

| 시간 | 구성 |
|---|---|
| 0:00~2:00 | 몽둥이 깨비만 등장해 높은 체력을 학습 |
| 2:00~5:00 | 방패 깨비를 섞고 첫 방패 무리를 명시적으로 소개 |
| 5:00 | 중간보스 `외뿔 대장` |
| 5:00~7:00 | 쇠뿔 깨비를 소수 소개 |
| 7:00 | 돌진 급습 |
| 7:00~10:00 | 몽둥이·방패·쇠뿔·돌팔매 혼합 |
| 10:00 | 중간보스 `철방패 장군` |
| 10:00~12:00 | 정예 비중 상승과 측면 포위 |
| 12:00 | 전체 도깨비 혼합 급습 |
| 12:00~14:00 | 최대 압박 구간 |
| 14:00 | 최종보스 경고와 일반 생성 감속 |
| 15:00 | 최종보스 `도깨비 대왕`, 처치까지 제한 시간 없음 |

### 5.4 보스

`외뿔 대장`은 직선 돌진과 부채꼴 휘두르기를 번갈아 사용한다. 돌진 실패 후
명확한 공격 기회가 생긴다.

`철방패 장군`은 정면 방어, 방패 찍기, 짧은 밀어내기를 사용한다. 방패 찍기 후
등을 보이는 회복 시간이 핵심 약점이다.

`도깨비 대왕`은 일반몹 기준 약 2.8배 크기다.

- 원형 경고 후 거대한 몽둥이 강타
- 세 줄 직선 경고 후 연속 돌진
- 여러 원형 경고 후 낙석
- 체력 50% 이하에서 두 공격을 순차 연계

연계 단계에서도 각 경고 시간은 생략하지 않는다.

## 6. 3장 월식 왕릉

### 6.1 전장

- 크기: 약 `84 x 84` 월드 단위
- 형태: 정사각형 왕릉 뜰
- 주색: 짙은 남색, 옅은 월석색, 탁한 보라, 청록 혼불, 진홍색 경고
- 외곽: 왕릉 담장과 어두운 수목
- 통과 장식: 봉분, 석등, 비석, 제례 기둥, 무너진 돌

바닥 명암은 낮게 유지해 보라색 투사체와 붉은 위험지역이 항상 우선해서 보이게
한다.

### 6.2 신규 적

| 적 | 역할 | 핵심 규칙 |
|---|---|---|
| 묘지 시종 | 기본 포위병 | 느린 근접 추적, 단순한 큰 실루엣 |
| 능지기 궁귀 | 직선 투사체 | 보라색 직선 경고 후 화살 발사 |
| 홍등귀 | 지속 위험지역 | 작은 저주 지대를 만들고 일정 시간 뒤 소멸 |
| 저주 무당 | 위치 예측 장판 | 이동 방향 앞에 붉은 원형 장판 생성 |
| 묘혈귀 정예 | 매복 | 잠복 후 표시 위치에서 솟아오르고 회복 시간 발생 |

원거리 적은 화면 밖에서 공격하지 않는다. 카메라 여유 범위 안에 들어온 뒤에만
조준을 시작하며, 모든 투사체는 화면 안에서 반응 가능한 최소 경고 시간을 가진다.

### 6.3 15분 웨이브

| 시간 | 구성 |
|---|---|
| 0:00~2:00 | 묘지 시종만 등장 |
| 2:00~5:00 | 능지기 궁귀를 소수 소개하고 직선 경고 학습 |
| 5:00 | 중간보스 `금위군 원혼` |
| 5:00~7:00 | 홍등귀 소개 |
| 7:00 | 투사체 급습, 겹치지 않는 안전 통로 보장 |
| 7:00~10:00 | 저주 무당 추가, 장판과 투사체 교차 |
| 10:00 | 중간보스 `월식 제관` |
| 10:00~12:00 | 묘혈귀 정예 소개 |
| 12:00 | 전체 원귀 혼합 급습 |
| 12:00~14:00 | 최대 투사체·장판 압박 구간 |
| 14:00 | 최종보스 경고와 일반 생성 감속 |
| 15:00 | 최종보스 `월식 왕비`, 처치까지 제한 시간 없음 |

### 6.4 보스

`금위군 원혼`은 초승달 베기와 직선 돌진을 사용해 원거리 중심 장에 근접 압박을
준다.

`월식 제관`은 회전 투사체와 순차 저주 장판을 사용한다. 장판 사이에는 항상 다음
안전지대로 이동할 폭을 남긴다.

`월식 왕비`는 일반몹 기준 약 3배 크기다.

- 회피 틈이 있는 방사형 영혼탄
- 붉은 초승달 경고 후 넓은 횡베기
- 왕릉 일부를 순서대로 잠식하는 저주 장판
- 플레이어 주변 원형 경고 후 솟아오르는 혼령 손
- 체력 50% 이하에서 두 공격을 순차 연계

대흉에서도 화면 전체를 동시에 막지 않는다. 패턴 생성기는 최소 안전 각도 또는
안전 셀 수를 검증한 뒤 공격을 확정한다.

## 7. 난이도와 성장 곡선

장 기본 배율과 기존 `보통·흉조·대흉` 배율을 곱한다.

| 장 | 기본 체력 | 기본 공격력 | 전투 성격 |
|---|---:|---:|---|
| 1장 | 1.00 | 1.00 | 다수의 약한 적과 광역 학습 |
| 2장 | 1.35 | 1.12 | 단단한 적, 방패, 돌진 |
| 3장 | 1.70 | 1.25 | 원거리, 장판, 복합 회피 |

흉조와 대흉은 수치 외에도 다음을 추가한다.

- 흉조: 정예 확률 상승, 장 전용 강화 규칙 하나, 보스 연계 한 단계
- 대흉: 정예 혼합 웨이브, 장 전용 강화 규칙 두 개, 보스 2단계

최대 인게임 레벨은 35를 유지한다. 강한 적은 역할과 체력에 비례해 더 높은 경험치를
지급한다. 후반 경험치는 기존 고가치 구슬 병합 정책을 사용해 구슬 개체 수가 계속
늘지 않게 한다. 15분 최종보스 시점의 목표 레벨은 일반적인 플레이에서 30~35다.

## 8. 보상과 해금

기존 해금 규칙을 그대로 사용한다.

- 1장 보통 승리: 2장 보통과 1장 흉조 해금
- 2장 보통 승리: 3장 보통과 2장 흉조 해금
- 각 장 흉조 승리: 같은 장 대흉 해금

장 기본 보상 배율을 추가하고 기존 난이도 배율과 곱한다.

| 장 | 엽전 | 계정 경험치 | 무기 숙련도 |
|---|---:|---:|---:|
| 1장 | 1.00 | 1.00 | 1.00 |
| 2장 | 1.25 | 1.25 | 1.25 |
| 3장 | 1.55 | 1.55 | 1.55 |

정산은 기존 복사본 기반 원자적 저장 흐름 안에서 장·난이도 배율을 한 번씩만
적용한다. 저장 실패 시 보상과 클리어 기록을 모두 롤백한다.

- 일반몹 기준 캔버스 48px, 정예 56~64px, 중간보스 80px, 최종보스 96~112px

- 캐릭터당 중심색 5~7개
- 작은 장식, 점 노이즈, 과도한 명암 단계 금지
- 무기·뿔·방패·등불·지팡이를 몸통에서 분리된 큰 덩어리로 표현
- 원거리 카메라에서 축소해도 역할이 구분되는 실루엣 우선
- 배경은 캐릭터보다 낮은 대비와 채도 사용

생성 결과는 원본 크기와 실제 게임 표시 크기 양쪽에서 검수한다. 조건을 만족하지
못한 후보는 게임에 넣기 위해 억지로 보정하지 않고 재생성한다.

### 9.3 Unity 임포트

- Sprite, Point 필터, mipmap 비활성
- 무손실 또는 무압축
- 스프라이트 묶음별 동일 PPU와 피벗
- 투명 여백 최소화
- 새 에셋과 `.meta`를 같은 기능 커밋에 포함
- PixelLab 작업 ID, 프롬프트, 사용 크레딧과 채택 여부를 생성 원장에 기록

## 10. 오디오

기존 보스 음악은 재사용할 수 있지만 일반 전투 음악은 장별 한 곡 이상을 사용한다.

- 도깨비 고개: 낮은 북과 목재 타격 중심, 무겁고 익살스럽지 않은 전투 분위기
- 월식 왕릉: 낮은 현과 의식 타악, 넓은 잔향보다 투사체 효과음 공간을 남김

새 음원을 받을 경우 기존 오디오 권리 원장에 출처·라이선스·해시를 추가한다. 적
일반 사망음은 계속 억제하며 돌진 시작, 방패 파괴, 보스 공격 경고처럼 정보 가치가
높은 사건만 새 효과음을 사용한다.

## 11. 성능 예산

- 2장 보통 기본 활성 상한: 최대 약 130
- 3장 보통 기본 활성 상한: 최대 약 110~120
- 난이도 밀도 배율 적용 후에도 모바일 전역 상한 140을 넘지 않음
- 투사체, 장판, 경고, 피해 숫자, 타격 효과는 풀링
- 보스 패턴 Update에서 LINQ, 새 리스트, 매 프레임 Instantiate 금지
- 원거리 적은 화면 밖 공격 계산을 하지 않음
- 정적 전장 장식은 초기 구성 후 재생성하지 않음
- 안전 통로 검사는 고정 크기 버퍼 또는 값 형식으로 처리

검증 기준은 기존 140적 성능 회귀보다 느려지지 않는 것이며, 실제 Android 기기에서는
15분 연속 플레이의 프레임 페이싱·메모리·발열을 별도로 확인한다.

## 12. 오류와 안전 처리

- 스테이지 정의 또는 필수 시각 에셋이 누락되면 해당 장 출전을 막는다.
- 개별 장식 에셋 누락은 안전한 무장식 타일로 대체하되 다른 장 배경을 사용하지 않는다.
- 보스 공격 정의가 잘못되어 안전 통로를 만들 수 없으면 그 패턴을 건너뛰고 다음
  패턴으로 진행한다.
- 전장보다 카메라 가시 범위가 커지는 해상도에서는 카메라 중심 제한을 우선 적용해
  검은 외부가 보이지 않게 한다.
- 알 수 없는 과거 저장 선택은 기존 규칙대로 1장 보통으로 복구한다.

## 13. 테스트와 검증

### EditMode

- 세 장의 전투 정의와 장별 웨이브가 모두 존재하는지 확인
- 1장 웨이브 데이터가 이전 값과 동일한지 확인
- 2·3장 각 시간 경계의 적 구성과 보스 사건 확인
- 장 기본 배율과 난이도 배율이 정확히 한 번 곱해지는지 확인
- 장별 경험치 가치와 최대 레벨 목표 확인
- 유한 전장 경계, 카메라 제한, 생성 후보 계산 확인
- 보스 패턴의 경고·실행·회복과 최소 안전 통로 확인
- 신규 에셋 수, 크기, 필터, 밉맵, 투명 여백 계약 확인

### PlayMode

- 1장 보통 승리 후 2장, 2장 보통 승리 후 3장 출전 가능 확인
- 각 장이 자기 배경·적·보스를 사용하고 1장 시각으로 대체되지 않는지 확인
- 5분·10분 중간보스 처치가 런을 끝내지 않는지 확인
- 15분 최종보스 처치만 승리로 처리되는지 확인
- 방패 파괴, 돌진 실패 회복, 화면 안 원거리 조준, 장판 소멸 확인
- 결과 화면과 로비 재진입 후 장·난이도 기록과 보상 확인
- 저장 실패 시 보상·해금 롤백 확인

### 최종 검증

- 전체 EditMode와 PlayMode
- 2·3장 15분 가속 전투
- 최대 몬스터·투사체 부하의 CPU·할당 측정
- 대표 세로 해상도 로비·전투·보스 캡처
- Android ARM64 IL2CPP 개발 빌드
- 실제 Android 기기에서 가독성·입력·발열·음량 확인 항목 기록

## 14. 완료 조건

- 2장과 3장이 로비에서 승인된 해금 규칙에 따라 실제 출전 가능하다.
- 각 장은 서로 다른 유한 전장, 신규 적 5종, 중간보스 2종, 최종보스 1종을 사용한다.
- 2장은 방패·돌진·높은 체력, 3장은 투사체·저주·안전지대 관리가 체감된다.
- 흉조와 대흉은 수치 외의 정예·조합·보스 강화 규칙을 사용한다.
- 신규 픽셀 아트는 굵은 어두운 외곽선, 제한된 팔레트, 단순한 큰 덩어리 규칙을
  만족하며 흰 외곽선과 자글거리는 세부 묘사를 사용하지 않는다.
- 모든 보스 공격은 사전 경고와 회피 가능한 안전 통로를 가진다.
- 장·난이도 보상은 한 번만 적용되고 저장 실패 시 부분 지급되지 않는다.
- 모바일 상한과 풀링 규칙을 지키며 전체 테스트와 Android 빌드가 통과한다.
