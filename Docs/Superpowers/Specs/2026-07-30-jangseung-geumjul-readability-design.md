# 장승진·금줄 전투 가독성 개선 설계

## 목표

장승진과 금줄이 전투 중 처음 보이는 순간에도 각각의 공격 조건을 이해할 수 있게 한다.
두 기술의 기존 판정 규칙은 유지하고, 설치·대기·발동 상태를 시각적으로 분리한다.

## 현재 문제

- 장승진은 장승과 옅은 금색 경계가 짧게 반복 표시되어 설치형 결계인지 지속 장판인지 구분하기 어렵다.
- 장승진의 실제 피해 조건은 적이 장승 사이의 경계를 통과하는 순간이지만, 해당 구간의 반응이 약하다.
- 금줄은 단색 `LineRenderer`로 그려져 새끼줄이나 부적의 형태가 없고 단순한 노란 궤적으로 보인다.
- 금줄의 시작점, 닫을 수 있는 상태, 봉인 완성 결과가 서로 다른 시각 상태로 표현되지 않는다.

## 확정된 기능

### 장승진

- 플레이어 주변에 2~4개의 장승을 설치해 경계 구간을 만든다.
- 적의 이동 선분이 보이는 경계를 통과하고 픽셀 접촉이 확인될 때 피해를 준다.
- 진화형은 완성된 진 내부의 적을 낙인한다.
- 5레벨 장승진은 플레이어를 따라 제한된 간격과 속도로 재배치된다.

### 금줄

- 플레이어가 이동한 지점을 일정 간격으로 기록한다.
- 오래된 지점은 제한된 개수까지만 유지한다.
- 현재 위치가 이전 궤적에 접근하고 충분한 면적이 형성되면 봉인이 닫힌다.
- 봉인 내부의 적에게 한 번 피해를 준 뒤 궤적을 비운다.

## 시각 설계

### 장승진: 침범 반응형 설치 결계

1. 설치 예고
   - 설치 위치에 짧은 타원형 흙 그림자와 붉은 인장 문양을 표시한다.
   - 예고는 약 0.08초로 짧게 유지해 전투 흐름을 막지 않는다.
2. 장승 출현
   - 장승이 4~5프레임에 걸쳐 아래에서 솟는다.
   - 마지막 프레임에 흙먼지와 작은 부적 조각이 좌우로 퍼진다.
   - 장승은 어두운 외곽선, 밝은 얼굴, 붉은 부적의 세 덩어리로 작은 화면에서도 읽히게 한다.
3. 경계 형성
   - 장승 사이를 검은 외곽선이 있는 황갈색 새끼줄로 연결한다.
   - 줄에는 일정 간격으로 붉은 천 매듭 또는 부적을 배치해 금줄과 구분되는 고정 결계임을 보여준다.
   - 내부에는 불투명도가 낮은 사각·마름모 인장 문양만 두고 화면을 덮는 장판은 사용하지 않는다.
4. 경계 침범
   - 적이 통과한 구간만 0.12초 동안 흰색에서 금색으로 번쩍인다.
   - 접촉 지점에 작은 귀면 충격파와 짧은 역방향 밀림 잔상을 표시한다.
   - 피해 숫자는 기존 규칙대로 적 몸 가까이에 출력한다.
5. 재배치와 퇴장
   - 5레벨 재배치는 장승이 순간이동하지 않고 땅속을 스치는 흙 궤적과 함께 제한 속도로 이동한다.
   - 세트 교체 시 장승과 줄이 동시에 사라지지 않고 줄 소멸 후 장승이 짧게 가라앉는다.

### 금줄: 이동으로 그리는 봉인

1. 기본 궤적
   - 단색 선 대신 검은 외곽선과 황갈색 중심을 가진 짚 금줄 텍스처를 사용한다.
   - 선 폭은 카메라 거리에서도 2~3화면 픽셀 이상 유지하되 캐릭터 실루엣보다 강하지 않게 한다.
   - 일정 거리마다 작은 붉은 부적 매듭을 풀링된 스프라이트로 배치한다.
2. 시작점과 진행 상태
   - 첫 지점은 작은 말뚝 또는 부적 고리로 고정해 시작점임을 표시한다.
   - 최근 구간은 밝고 오래된 구간은 서서히 어두워져 진행 방향을 읽을 수 있게 한다.
   - 단순 이동 중에는 발광을 억제하고 닫기 가능 상태에서만 시작점이 금빛으로 맥동한다.
3. 봉인 완성
   - 닫히는 순간 마지막 지점과 시작점을 0.08초의 밝은 매듭 효과로 연결한다.
   - 내부를 약 0.1초 어둡게 눌러 영역을 분리한 뒤 금빛 인장 파동을 안에서 밖으로 한 번 보낸다.
   - 피해 판정은 기존 영역 판정 결과를 그대로 사용하고 연출만 그 결과를 따른다.
4. 실패와 자연 소멸
   - 봉인이 닫히지 않았을 때 별도 실패 효과는 표시하지 않는다.
   - 오래된 줄과 부적은 알파 감소 후 풀로 반환해 갑작스럽게 잘리는 느낌과 생성·파괴 비용을 줄인다.

## 에셋 구성

- 한 PNG에는 한 종류의 단일 프레임 에셋만 둔다.
- 장승:
  - 설치 예고 2프레임
  - 솟아오름 5프레임
  - 대기 4프레임
  - 침범 반응 4프레임
  - 흙먼지 4프레임
- 경계:
  - 반복 가능한 새끼줄 중앙 타일
  - 장승 연결부
  - 붉은 천 매듭 2종
  - 귀면 접촉 파동 4프레임
- 금줄:
  - 반복 가능한 짚 금줄 중앙 타일
  - 시작 말뚝 또는 부적 고리
  - 붉은 부적 매듭 2종
  - 닫기 가능 맥동 4프레임
  - 봉인 완성 인장 파동 6프레임
- 모든 에셋은 투명 배경, 불필요한 빈 여백 없음, Point 필터, 무압축 또는 품질 손실 없는 설정을 사용한다.

## 구현 구조

- 게임 판정은 `JangseungWardExecutor`와 `FirstPlayableController.TryCloseSeal`이 계속 소유한다.
- 장승의 설치·경계·통과 이벤트만 프레젠테이션 계층에 전달한다.
- 금줄 데이터와 봉인 판정은 기존 리스트를 유지하되, 단색 `LineRenderer` 설정을 반복 텍스처 기반 표현과 부적 세그먼트 풀로 교체한다.
- 자주 발생하는 먼지, 매듭, 접촉 파동, 봉인 파동은 풀링한다.
- 런 종료, 장면 변경, 무기 초기화 시 모든 지속 시각 요소와 풀 활성 항목을 명시적으로 정리한다.

## 성능 기준

- 금줄 최대 기록점 90개 제한을 유지한다.
- 부적 매듭은 모든 기록점이 아니라 화면 거리 기준 간격으로만 생성한다.
- 매 프레임 새 머티리얼을 만들거나 스프라이트 오브젝트를 생성·파괴하지 않는다.
- 화면 밖 장승 세트의 대기 애니메이션 갱신 빈도를 낮출 수 있게 구성한다.
- 모바일에서 투명 오버드로우가 큰 전체 화면 파티클이나 지속 발광 장판을 사용하지 않는다.

## 완료 조건

- 장승이 등장한 뒤 1초 안에 설치형 경계라는 사실을 시각적으로 알 수 있다.
- 적이 장승 경계를 통과한 정확한 구간과 순간에만 반응 효과가 나온다.
- 금줄이 정지 화면에서도 노란 선이 아니라 짚줄과 부적으로 식별된다.
- 금줄 시작점, 닫기 가능 상태, 봉인 완성 상태가 서로 명확히 다르다.
- 두 기술의 기존 피해량, 재사용 대기시간, 판정 범위와 진화 규칙은 변경되지 않는다.
- 장시간 이동해도 활성 금줄·부적·효과 오브젝트 수가 제한 범위를 넘지 않는다.
