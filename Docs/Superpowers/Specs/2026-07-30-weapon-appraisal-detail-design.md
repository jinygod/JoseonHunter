# 무기 운명 감정판 및 상세창 설계

## 목표

무기 강화 결과를 현대식 슬롯머신 대신 조선 민속 판타지의 `운명 감정`으로 표현한다.
플레이어는 짧은 시간 안에 다음 세 가지를 정확히 이해해야 한다.

1. 어떤 무기가 강화되었는가
2. 추가옵션이 몇 퍼센트 붙었는가
3. 새 잠재가 당첨되었는가

같은 상세창은 전투 중 무기 슬롯을 눌렀을 때 현재 무기 상태를 다시 확인하는 용도로 재사용한다.

## 승인된 시각 방향

- 기본 레이아웃은 세로형 무기 상세서다.
- 상단에는 무기 아이콘, 이름, 레벨, 한 줄 행동 설명을 둔다.
- 중단에는 이번에 획득한 추가옵션을 큰 숫자로 표시한다.
- 하단에는 잠재 슬롯 세 칸을 세로로 배치한다.
- 잠재가 실제 당첨된 순간에만 의식형 보라색 광륜, 도깨비불, 봉인 해제 섬광을 겹친다.
- 과일, BAR, 레버 등 현대 카지노를 연상시키는 심볼은 사용하지 않는다.

## 플레이 흐름

### 일반 추가옵션

1. 감정판이 0.10초 동안 확대되며 열린다.
2. 무기 정보는 즉시 표시된다.
3. 추가옵션 숫자는 `0%`에서 최종값까지 0.65초 동안 빠르게 상승한다.
4. 상승 속도는 처음에 빠르고 마지막 20% 구간에서 감속한다.
5. 최종값에서 0.08초 동안 가볍게 확대되며 확정된다.
6. 잠재가 없으면 다음 빈 잠재 슬롯 하나가 약하게 흔들리다가 서서히 멈춘다.
7. 결과 확인 상태에서는 플레이어가 탭할 때까지 정확한 수치를 유지한다.

### 높은 추가옵션

- 숫자 상승 도중 금빛이 점차 강해진다.
- 최종값 확정 순간에 짧은 금빛 테두리와 한 번의 타격음을 사용한다.
- 전체 자동 연출 시간은 약 1.55초를 넘지 않는다.

### 잠재 당첨

1. 이미 보유한 잠재는 처음부터 고정 표시한다.
2. 새 잠재가 들어갈 다음 빈 슬롯만 먼저 흔들린다.
3. 당첨 순간 배경이 잠깐 어두워지고 해당 슬롯 주위에 보라색 의식 광륜이 생긴다.
4. 봉인이 갈라지며 잠재 아이콘, 이름, 한 줄 효과 설명이 나타난다.
5. 한 번에 두 줄 또는 세 줄이 당첨되면 아래 슬롯을 0.18초 간격으로 연쇄 개방한다.
6. 잠재가 없으면 흔들림이 점차 줄어들고 빈 슬롯으로 남는다. 실패 문구나 붉은 실패 효과는 표시하지 않는다.
7. 잠재 1줄 연출은 약 2.1초, 2~3줄 연출은 최대 2.4초로 제한한다.

## 무기 상세창

전투 중 무기 랙의 슬롯을 누르면 동일한 상세창을 읽기 전용으로 연다.

- 현재 무기 레벨
- 기본 행동 설명
- 해당 판에서 획득한 추가옵션 목록
- 현재 보유 잠재와 효과 설명
- 남은 빈 잠재 슬롯

읽기 전용 상세창에서는 숫자 상승, 슬롯 흔들림, 의식 연출을 재생하지 않는다.
바깥 영역 또는 닫기 버튼을 누르면 즉시 전투로 돌아간다.
상세창이 열린 동안 전투 시간은 정지한다.

## 컴포넌트 구조

### `WeaponAppraisalViewModel`

화면에 필요한 값만 담는 불변 모델이다.

- 무기 ID, 표시 이름, 레벨, 행동 설명, 아이콘
- 이번 추가옵션 결과
- 현재까지 누적된 일반 추가옵션
- 기존 잠재 목록
- 이번에 새로 당첨된 잠재 목록

강화 연출과 읽기 전용 상세창이 동일한 모델을 사용한다.

### `WeaponDetailPresenter`

정적인 상세 레이아웃을 소유한다.

- 무기 헤더
- 추가옵션 행
- 잠재 슬롯 세 칸
- 확인 및 닫기 입력

애니메이션 규칙을 알지 않으며 전달받은 표시 상태만 그린다.

### `WeaponAppraisalRevealPresenter`

강화 결과의 시간 흐름만 소유한다.

- 숫자 카운트업
- 빈 슬롯 흔들림과 감쇠
- 잠재 연쇄 개방
- 높은 옵션 및 잠재 당첨 강조
- 스킵과 확인 상태

기존 `WeaponAffixRevealPresenter`의 진입점과 완료 이벤트는 호환되게 유지하고, 내부를 상세창과 연출 컨트롤러로 분리한다.

### `WeaponRackPresenter`

기존 무기 슬롯 표시는 유지한다.
각 슬롯의 탭 이벤트에 현재 `WeaponAppraisalViewModel`을 요청하는 연결만 추가한다.

## 데이터 흐름

1. 무기 보상 선택 시 런타임이 추가옵션과 잠재를 적용한다.
2. 적용 전 잠재와 적용 후 전체 상태를 이용해 감정용 뷰 모델을 만든다.
3. UI 부트스트랩이 감정 연출을 시작하고 전투 시간을 정지한다.
4. 연출 완료 후 기존 보상 완료 흐름을 호출하고 전투를 재개한다.
5. 이후 무기 랙 탭에서는 현재 런 상태로 읽기 전용 뷰 모델을 생성한다.

## 에셋 사용

- 기존 PixelLab 감정판 프레임, 잠재 아이콘, 봉인 슬롯, 잭팟 버스트를 우선 사용한다.
- 현대식 슬롯 릴 심볼은 최종 화면에서 제거한다.
- 배경 상세서 프레임이나 봉인 해제 프레임이 부족하면 PixelLab에서 한 PNG당 한 에셋으로 제작한다.
- 런타임에서 임시 도형을 최종 아트 대용으로 사용하지 않는다.

## 성능 및 안전

- UI 오브젝트는 최초 한 번 생성한 뒤 재사용한다.
- 매 프레임 문자열이나 배열을 새로 만들지 않는다.
- 숫자 카운트업은 `unscaledDeltaTime`을 사용해 전투 정지 상태에서도 진행한다.
- 잠재 슬롯은 항상 세 칸으로 고정해 레이아웃 재생성을 피한다.
- 빠른 연속 탭은 한 번의 스킵 또는 확인으로만 처리한다.
- 누락된 아트 카탈로그가 있으면 오류를 기록하고 연출을 건너뛰되 보상 적용과 전투 진행은 막지 않는다.

## 검증 기준

- `23.88` 퍼센트 포인트는 카운트업 후 `+24%`로 표시된다.
- 일반 옵션은 0에서 목표값까지 단조 증가한다.
- 음수 쿨다운 옵션은 `0%`에서 음수 목표값 방향으로 변화한다.
- 기존 잠재는 흔들리지 않고 새 잠재가 들어갈 슬롯만 흔들린다.
- 잠재가 없으면 빈 슬롯으로 조용히 멈춘다.
- 1~3개 신규 잠재가 올바른 슬롯 순서로 공개된다.
- 읽기 전용 상세창은 연출 없이 현재 전체 상태를 표시한다.
- 연출 중 스킵과 결과 확인 입력이 중복 완료 이벤트를 만들지 않는다.
- 기존 무기 강화 적용값과 잠재 확률은 변경하지 않는다.

## 제외 범위

- 무기 강화 확률과 수치 범위 조정
- 무기 잠재 효과 자체의 전투 로직 변경
- 영구 장비 도감이나 메타 진행 저장
- 상점, 로비, 인벤토리 화면
