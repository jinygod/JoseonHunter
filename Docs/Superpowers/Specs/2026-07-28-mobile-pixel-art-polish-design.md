# 모바일 전투 도트 아트 폴리싱 디자인

작성일: 2026-07-28  
상태: 사용자 방향 승인 완료

## 1. 목표

현재 전투 화면의 낮은 체감 해상도, 임시 주인공, 과도하게 큰 무기,
직선적인 투사체 움직임, 개발용 배경을 하나의 일관된 모바일 도트 아트
규격으로 교체한다.

도트 아트는 저화질처럼 보이지 않아야 한다. 모든 에셋은 화면에서 실제로
표시되는 크기와 정보량을 먼저 정하고, 캔버스 안의 작은 실루엣을 임의로
확대하는 방식은 사용하지 않는다.

## 2. 기준 화면과 픽셀 파이프라인

- 기준 가상 해상도는 세로 `360 x 800`이다.
- Pixel Perfect Camera의 기준 PPU는 `64`로 통일한다.
- 실제 기기에서는 가상 화면을 가능한 정수 배율로 확대하고 남는 영역만
  크롭 또는 안전 여백으로 처리한다.
- 모든 런타임 도트 텍스처는 Point 필터, 밉맵 없음, Android 무압축을
  사용한다.
- 월드 스프라이트 위치는 픽셀 격자에 스냅한다. 이동 로직의 월드 좌표는
  유지하고 표시 좌표만 스냅해 전투 판정에 영향을 주지 않는다.
- UI 텍스트와 벡터형 게이지는 화면 해상도로 렌더링하고 월드 도트
  스프라이트와 별도의 해상도 계층을 유지한다.

## 3. 화면 점유 크기

다음 수치는 `360 x 800` 기준 화면에서의 실제 불투명 실루엣 크기다.
투명 캔버스 크기가 아니라 플레이 중 보이는 몸체와 공격 픽셀의 크기를
의미한다.

| 대상 | 소스 캔버스 | 실제 불투명 영역 | 기준 화면 표시 |
| --- | --- | --- | --- |
| 한연화 | 96 x 96 | 폭 42~50, 높이 52~60 | 소스 픽셀과 1:1 |
| 인간형 일반 몬스터 | 64 x 64 | 폭 38~48, 높이 48~58 | 한연화와 비슷한 체급 |
| 소형 일반 몬스터 | 64 x 64 | 폭 40~52, 높이 36~48 | 낮고 넓어 면적은 비슷하게 |
| 부유형 일반 몬스터 | 64 x 64 | 폭 38~48, 높이 46~58 | 한연화와 비슷한 체급 |
| 엘리트 몬스터 | 80 x 80 | 폭 50~62, 높이 62~72 | 일반몹보다 약 20~28% 크게 |
| 보스 | 128 x 128 | 폭 78~96, 높이 92~112 | 화면 내 가장 큰 전투 실루엣 |
| 환도 비검 | 32 x 32 | 길이 18~24, 두께 5~8 | 다른 소형 무기와 비슷한 면적 |
| 각궁 화살 | 32 x 16 | 길이 18~24, 두께 4~7 | 환도와 비슷한 시각 무게 |
| 신기전 로켓 | 32 x 16 | 길이 18~24, 두께 5~8 | 화살과 비슷하되 더 굵게 |
| 부적 투사체 | 24 x 24 | 폭 10~14, 높이 16~20 | 얼굴보다 작게 |
| 호리병·폭탄 | 24 x 24 | 폭 12~18, 높이 14~20 | 손에 잡히는 소품 크기 |
| 경험치 픽업 | 16 x 16 | 폭 7~11, 높이 9~14 | 전투 실루엣보다 명확히 작게 |

한연화와 일반 몬스터는 같은 전투 체급으로 보이게 한다. 한연화는 색과
디테일로 주인공임을 구분하지만 크기로 일반몹을 압도하지 않는다. 엘리트는
일반몹보다 20~28% 크고, 보스는 모든 전투 개체 중 가장 크다. 소형 무기
투사체는 서로 비슷한 시각 무게를 유지하되 어느 것도 플레이어 몸체를
압도하지 않는다.

## 4. 한연화 전투 캐릭터

현재 임시 무녀 스프라이트를 제거하고 승인된 단일 주인공 한연화로
교체한다.

- 명확한 성인 여성의 2.2~2.5등신 치비 비율
- 긴 검은 머리와 굵은 땋은 머리, 금색 비녀
- 남색 상의, 아이보리 소매, 진홍 끈과 노리개
- 예쁘고 자신감 있는 눈매와 작은 미소
- 소매와 머리카락으로 실루엣을 풍성하게 만들되 얼굴을 가리지 않음
- 환도는 등에 차거나 허리 장식으로만 보이고 자동 공격 무기와 중복되지
  않게 작게 표현
- 외곽선은 순수 검정 대신 먹빛·짙은 남색을 사용하고, 얼굴과 장식에
  제한적인 밝은 픽셀을 배치

96 x 96 캔버스를 사용하되 인물이 캔버스 중앙의 작은 20 x 30 영역에
머무는 결과는 즉시 폐기한다. 발 기준 앵커와 좌우 여백을 제외한 세로
점유율은 최소 56%다.

## 5. 일반 몬스터, 엘리트, 보스

기존 몬스터의 정체성은 유지하면서 한연화와 같은 윤곽선 두께, 명암 단계,
얼굴 픽셀 밀도로 다시 제작한다.

- 역병쥐: 낮고 넓은 실루엣, 병든 녹색 포인트
- 원혼: 긴 머리와 청백색 영체, 몸통보다 꼬리가 가벼움
- 삿갓 귀신: 삿갓과 부적이 한눈에 구분되는 삼각 실루엣
- 도깨비: 짧고 넓은 몸, 뿔과 방망이를 과장
- 산적: 붉은 머리띠와 짧은 칼, 인간형 적 크기 기준
- 타락 장군: 128 x 128 보스 규격, 갑옷과 투구 장식으로 면적과 위압감 확보

적의 색은 전장과 분리되도록 명도 대비를 확보한다. 투명 여백 때문에
게임에서 콩알처럼 보이는 후보는 사용하지 않는다.

### 엘리트 몬스터

엘리트는 일반몹을 단순히 크게 복사한 개체가 아니라 한 단계 높은 전투
위협으로 읽혀야 한다.

- 일반몹보다 표시 크기 `1.20~1.28배`
- 최대 체력 `4배`
- 접촉 피해 `1.5배`
- 이동 속도 `0.92배`로 조금 무겁게 이동
- 경험치 보상 `5배`, 처치 카운트와 보상 효과는 엘리트로 별도 표시
- 짙은 진홍 또는 금색의 얇은 외곽광과 이마의 봉인 문양
- 등장 시 0.35초의 작은 경고 문양과 저음 임펄스
- 일반몹보다 넓은 충돌 마스크를 사용하되 투명 장식광은 피해 판정에서 제외

첫 폴리싱 배치에는 전용 `도깨비 장수` 엘리트 스프라이트를 제작한다.
이후 다른 일반 몬스터도 같은 엘리트 계약을 사용하는 전용 변형을 추가할
수 있다.

### 보스

보스는 플레이어와 엘리트보다 명확히 큰 최상위 실루엣이다.

- 한연화 높이의 약 `1.7~1.9배`
- 전용 128 x 128 소스와 별도 픽셀 마스크
- 크기만 키우지 않고 투구, 어깨 갑옷, 무기와 망토가 넓은 면적을 차지
- 등장 시 카메라 프레이밍과 상단 보스 체력 바로 위계를 전달

## 6. 환도 비검 폴리싱

환도 비검은 커다란 장검이 아니라 한연화가 주술로 조종하는 소형 비검이다.

- 출발 시 2~3프레임의 짧은 회전 가속
- 표적까지 완전 직선이 아닌 완만한 측면 곡선
- 이동 방향을 따라 2개의 짧은 반투명 잔상 파츠를 별도 표시
- 접촉 프레임에만 작은 금속성 십자 스파크 표시
- 귀환은 출발 경로를 역재생하지 않고 반대쪽 곡선으로 돌아옴
- 칼 본체의 최대 길이는 기준 화면 24픽셀
- 레벨 상승은 칼 한 자루의 크기 확대가 아니라 수량, 곡률, 잔상 색,
  시차로 표현

충돌 마스크는 칼날 불투명 픽셀만 포함하고 잔상과 스파크는 피해 판정에
포함하지 않는다.

## 7. 각궁 폴리싱

각궁 공격은 화면을 가로지르는 긴 막대가 아니라 작은 고속 화살과
발사 리듬으로 정밀함을 표현한다.

1. 표적 방향으로 0.08~0.12초의 가느다란 조준 반짝임을 표시한다.
2. 화살은 처음 15% 구간에서 가속하고 이후 최고 속도를 유지한다.
3. 발사 방향에 작은 좌우 편차 또는 얕은 포물선을 적용해 기계적인
   수평선 느낌을 없앤다.
4. 화살 몸체는 18~24픽셀이고, 외곽선보다 밝은 화살촉이 선행한다.
5. 접촉 시 4~7픽셀의 짧은 목재·금속 파편을 표시한다.
6. 풀드로우·진화형은 크기 대신 화살촉 광택, 속도, 관통 잔상, 후속
   분열 화살로 강화감을 만든다.

조준선은 피해 판정이 없고 화살의 실제 픽셀 접촉만 피해를 발생시킨다.

## 8. 전장과 가독성

현재 연녹색 개발용 격자를 제거한다.

- 먹빛이 섞인 어두운 흙길 또는 한지 질감 타일
- 64 x 64 반복 기본 타일 2종
- 돌, 마른 풀, 부적 조각 데칼 4~6종
- 아주 느린 청회색 안개 레이어
- 전투 중심부는 장식 밀도를 낮추고 화면 가장자리에서만 밀도를 높임
- 경험치 불꽃, 적, 무기 접촉 픽셀이 배경보다 최소 한 단계 밝게 보이도록
  명도 계층을 유지

배경은 PixelLab으로 재사용 가능한 작은 타일과 데칼만 생성하며 완성된
게임 화면을 한 장으로 굽지 않는다.

## 9. PixelLab 생성 정책

첫 폴리싱 배치는 약 30~40회 이내에서 관리한다.

1. 한연화 스타일 기준 후보 4종
2. 선택된 한연화를 참조한 일반 몬스터 5종
3. 전용 도깨비 장수 엘리트와 타락 장군 보스 후보
4. 환도·화살·접촉 스파크의 작은 전투 파츠
5. 배경 기본 타일과 데칼
6. 실패한 계열만 최대 2회 재생성

각 결과는 생성 프롬프트, 작업 ID, 크기, 사용 여부, 남은 횟수를 기존
PixelLab ledger에 기록한다. 마스크는 승인된 알파에서 자동 파생하고
PixelLab 횟수를 사용하지 않는다.

## 10. Unity 통합

- `FirstPlayableController`의 플레이어 스프라이트를 한연화로 교체한다.
- 일반, 엘리트, 보스의 체급과 전투 수치를 명시적인 적 등급 데이터로
  구분한다.
- 엔티티별 임의 `transform.localScale` 값을 제거하고 PPU와 표시 규격을
  기준으로 한 명시적 프레젠테이션 스케일 표를 사용한다.
- Pixel Perfect Camera를 적용하고 표시 Transform만 픽셀 스냅한다.
- 환도 비검과 각궁은 기존 피해·픽셀 접촉 권한을 유지하면서 이동 곡선과
  시각 프레젠테이션만 교체한다.
- Android 플랫폼 오버라이드에서 런타임 도트 텍스처 압축을 비활성화한다.
- 기존 잠재·진화 메커니즘과 공격 인스턴스 ID, 히트 메모리는 변경하지
  않는다.

## 11. 검증

- 기준 `360 x 800`, Unity Game 뷰, 대표 1080픽셀 폭 기기에서 비교
  캡처를 만든다.
- 정지 및 이동 중 외곽선이 흐려지거나 픽셀 열이 흔들리지 않아야 한다.
- 한연화의 얼굴, 땋은 머리, 남색·아이보리·진홍 의상이 전투 배율에서
  구분되어야 한다.
- 일반 몬스터와 플레이어는 비슷한 체급이어야 한다.
- 엘리트는 일반 몬스터보다 20~28% 크고 체력 4배여야 한다.
- 보스는 플레이어와 엘리트보다 확실히 커야 한다.
- 환도와 화살은 어느 프레임에서도 플레이어 몸체보다 크게 보이지 않아야
  한다.
- 환도는 출발과 귀환 경로가 서로 다른 곡선이어야 한다.
- 각궁은 조준 예고 후 발사되고 얕은 비직선 궤적을 가져야 한다.
- 실제 픽셀 접촉과 피해 숫자 발생 프레임이 일치해야 한다.
- Android 임포트 설정은 Point, 무밉맵, 무압축이어야 한다.
- Unity Console에 새 오류가 없어야 한다.

## 12. 완료 기준

- 임시 무녀 대신 한연화가 전투 주인공으로 표시된다.
- 캐릭터와 몬스터가 캔버스의 승인된 불투명 점유 범위를 충족한다.
- 일반몹, 엘리트, 보스의 크기와 체력 위계가 즉시 구분된다.
- 도트가 작은 것이 아니라 의도적으로 세밀하고 선명하게 보인다.
- 환도와 각궁의 크기·움직임이 캐릭터를 압도하지 않는다.
- 개발용 격자 배경이 조선 오컬트 전장 타일로 교체된다.
- 휴대폰 실기 또는 동등한 1080픽셀 폭 캡처에서 픽셀 정렬과 가독성이
  승인된다.
