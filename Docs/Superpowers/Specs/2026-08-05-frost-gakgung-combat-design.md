# 서리병·각궁 전투 역할 개선 설계

## 목표

- 서리병을 빠르게 착지해 피해·감속·빙결을 명확히 전달하는 제어형 장판 무기로 만든다.
- 각궁을 현재 화면 안의 위협적인 적을 강한 한 발로 처리하는 장거리 저격 무기로 만든다.
- 각궁이 화면 밖 보스나 정예를 조준한 뒤 사거리 부족으로 허공에 화살을 버리는 현상을 제거한다.

## 확인된 원인

### 서리병

`FirstPlayableController`가 서리병의 `durationSeconds`를 투사체 비행시간과 장판 지속시간 양쪽에 전달한다. 레벨이 오를수록 지속시간이 1.4초에서 2.2초로 증가하므로 병의 착지도 함께 늦어진다. 실제 피해와 감속은 착지 이후에만 시작되어 플레이어에게는 병만 날고 효과가 없는 것처럼 보인다.

현재 실행기에는 이미 다음 효과가 구현되어 있다.

- 착지 시 기본 피해 100%
- 장판 안에서 0.25초마다 기본 피해 50%
- 레벨에 따라 35~55% 감속
- 0.75초 체류 시 짧은 빙결

### 각궁

`GakgungExecutor.TrySelectTarget`은 사거리와 카메라 가시 여부를 확인하지 않고 모든 생존 적 중 보스, 정예, 위협도 순으로 대상을 고른다. 화살은 지정된 사거리만 이동하므로 화면 밖 강적을 겨냥하면 도달 전에 소멸한다.

레벨 1 피해 10은 초반 쥐 체력 약 13.5보다 낮다. 단일 대상 무기인데도 일반 적을 한 발에 처리하지 못하고, 레벨 4 관통과 레벨 5 다중 화살을 얻기 전까지 선택 보상이 약하다.

## 확정 설계

### 서리병: 빠른 제어 장판

- 비행시간은 모든 레벨에서 0.4초로 고정한다.
- 장판 지속시간 1.4~2.2초는 기존 성장값을 유지한다.
- 착지 피해, 0.25초 주기 피해, 감속, 빙결 구조는 유지한다.
- 착지 직후 피해가 발생하고 얼음 장판이 생성되는 기존 시각 연출을 유지하되, 실제 플레이에서 착지 전 대기 구간을 대폭 줄여 효과를 즉시 인지할 수 있게 한다.
- 서리병은 폭발 주력 무기가 아니라 다수 적을 늦추면서 꾸준히 피해를 주는 제어 무기로 남긴다.

### 각궁: 화면 내 장거리 저격

- 타깃 후보는 현재 게임 카메라의 뷰포트 안에 중심점이 들어온 생존 적으로 제한한다.
- 화면 안 후보의 우선순위는 보스, 정예, 위협도, 거리, 런타임 ID 순이다.
- 화면 밖 적은 보스나 정예라도 조준하지 않는다.
- 카메라 정보가 없는 단위 테스트나 독립 실행 환경에서는 기존 호환성을 위해 모든 적을 가시 대상으로 취급한다.
- 레벨별 기본 피해는 `15 / 19 / 24 / 30 / 38`로 상향한다.
- 레벨별 사거리는 `22 / 24 / 26 / 28 / 30`으로 상향해 세로 화면 반대편의 가시 적에게도 도달하게 한다.
- 레벨별 투사체 속도는 `26 / 28 / 30 / 32 / 34`로 상향해 저격 화살이 빠르고 묵직하게 읽히게 한다.
- 과도한 총 피해를 막기 위해 재사용 대기시간은 `0.72 / 0.69 / 0.66 / 0.63 / 0.60초`로 조정한다.
- 레벨 4 관통 2회, 레벨 5 3발·관통 3회와 기존 전승·잠재 효과는 유지한다.
- 기본 각궁에는 범위 폭발을 추가하지 않는다. 강한 단일 피해와 직선 관통이 무기 정체성이다.

## 데이터와 실행 흐름

1. `FirstPlayableController`가 매 프레임 게임 카메라 기준 가시성 판별 함수를 전투 런타임에 제공한다.
2. `GakgungExecutor`는 발사 가능 시점에 등록된 적을 복사하고 가시성 판별을 통과한 적만 비교한다.
3. 선택된 대상이 화면 안에 있는 동안 화살은 새 사거리와 속도로 발사된다.
4. 타깃이 발사 직후 움직이더라도 화살은 발사 방향을 유지한다. 유도탄으로 바꾸지 않는다.
5. 서리병 생성 시 장판 지속시간과 별개로 0.4초 비행시간을 전달한다.

## 경계 조건

- 화면 안에 적이 없으면 각궁은 발사하지 않고 재사용 대기시간도 소비하지 않는다.
- 화면 경계에 걸친 적은 중심점이 뷰포트 안에 있을 때만 후보가 된다.
- 카메라가 없거나 전투 런타임에 가시성 판별기가 설정되지 않은 테스트 환경에서는 기존 동작을 보존한다.
- 각궁의 화살은 화면 밖 적을 우연히 관통해 맞힐 수는 있지만 화면 밖 적을 최초 조준 대상으로 삼지는 않는다.
- 서리병 장판 수 제한, 상태 효과 정리, 공격 인스턴스 수명은 기존 로직을 유지한다.

## 검증 계획

- 각궁이 화면 밖 보스를 무시하고 화면 안 일반 적을 선택하는 실패 테스트를 먼저 작성한다.
- 화면 안에서 보스·정예 우선순위와 같은 등급의 거리 우선순위를 검증한다.
- 레벨 1 각궁의 기본 피해가 초반 쥐를 한 발에 처치할 수 있는지 데이터 계약 테스트로 검증한다.
- 각궁의 레벨별 피해·사거리·속도·재사용 대기시간을 콘텐츠 테스트로 고정한다.
- 서리병 실행기가 장판 지속시간과 무관하게 0.4초 비행시간을 받는지 검증한다.
- 서리병 착지 피해, 주기 피해, 감속, 빙결의 기존 회귀 테스트를 유지한다.
- 관련 EditMode/PlayMode 테스트 후 전체 테스트를 순차 실행한다.

## 범위 제외

- 새로운 서리병 또는 각궁 이미지 제작
- 각궁 유도 기능
- 기본 각궁의 스플래시 폭발
- 서리병의 전승·잠재 구조 변경
- 카메라 크기나 적 생성 범위 변경
