# 세로 UI 서체·감정 연출·전투 카메라 개선 설계

**상태:** 2026-08-01 사용자 승인

**대상 프로젝트:** `D:\UnityProjects\JoseonHunter`

**대상 화면:** 세로 전투 HUD, 레벨업 증강 선택, 무기 감정/상세, 전투 데미지 숫자

## 1. 목표

현재 세로 프로토타입에서 다음 문제를 한 번에 해결한다.

1. 모든 런타임 UI가 Noto Sans KR 하나를 공유해 조선 민속 판타지의 인상이 약하고,
   한지 위의 옅은 글자가 읽히지 않는다.
2. 무기 추가옵션 이름이 enum 영문 그대로 노출된다.
3. 감정 결과의 장식 아이콘이 엽전처럼 보이고 결과 의미를 전달하지 못한다.
4. 저해상도 픽셀 두루마리를 큰 세로 팝업까지 확대해 배경이 깨져 보인다.
5. 추가옵션 수치가 슬롯 정지 전에 이미 계산되어 최종값이 갑자기 나타난다.
6. 세로 전투 카메라가 너무 가까워 캐릭터와 무기가 화면을 과도하게 점유한다.

전투 최적화와 몬스터 웨이브 재설계는 이번 범위에 포함하지 않는다. 다만 카메라
줌아웃 때문에 생기는 가시 범위와 생성 거리 변화는 기존 전투 압력을 망가뜨리지
않도록 검증한다.

## 2. 선택한 접근법

### 채택: 역할별 서체 + 해상도 독립 UI + 단계형 감정 연출 + 2.5배 줌아웃

- 글의 역할에 따라 궁서, 본문 부리, 붓터치 숫자를 분리한다.
- 감정 배경의 넓은 면은 확대되는 단일 픽셀 이미지 대신 해상도 독립 한지 면과
  분리된 장식 테두리로 구성한다.
- 의미 없는 장식 심벌을 텍스트 낙관으로 교체한다.
- 슬롯 정지 후 수치가 0부터 최종값까지 별도 단계로 상승한다.
- 전투 월드만 현재 화면상 크기의 약 40%가 되도록 카메라를 멀리하고, Screen Space
  UI의 크기는 유지한다.

### 배제한 대안

- **글꼴과 문자열만 교체:** 픽셀 깨짐, 의미 없는 심벌, 약한 결과 연출이 남는다.
- **감정 화면 전체를 새 원화로 제작:** 시각 품질은 높일 수 있으나 현재 수직
  프로토타입 단계에서 제작 범위와 반복 비용이 너무 크다.
- **모든 월드 스프라이트를 개별 축소:** 카메라 외에 무기별 크기, 충돌 반경,
  이펙트 폭까지 연쇄 조정해야 하며 사용자 요청인 전체적인 줌아웃과도 맞지 않는다.

## 3. 서체 체계

### 3.1 역할

| 역할 | 서체 | 용도 |
| --- | --- | --- |
| 타이틀/짧은 대사 | 조선궁서체 | 화면 제목, 결과 등급 제목, 경고/대사 |
| UI/스탯/아이템 설명 | 마루 부리 Regular/SemiBold | HUD, 증강 카드, 무기 설명, 수치 라벨, 버튼 |
| 데미지 숫자 | Black And White Picture | 일반/치명타/보스 피해 숫자 |
| 폴백 | 기존 Noto Sans KR Dynamic SDF | 주 서체에 없는 글리프만 대체 |

궁서체는 긴 본문이나 작은 수치에 사용하지 않는다. 제목과 짧은 강조 문구에만
사용해 사극 분위기를 살리고, 실제 플레이 정보는 마루 부리로 읽기 쉽게 유지한다.

### 3.2 라이선스와 배포

- 조선궁서체는 조선일보 공식 배포본을 수정하지 않은 형태로 사용한다. 공식 안내는
  개인과 기업 사용자에게 무료 제공하고, 원형 그대로의 자유로운 배포를 허용한다.
- 마루 부리는 네이버 공식 배포본을 사용한다. 네이버 공식 안내는 상업적 사용,
  소프트웨어 번들, 재배포를 허용한다.
- Black And White Picture는 Google Fonts 공식 저장소의 SIL Open Font License
  1.1 배포본을 사용한다. 소프트웨어 임베딩과 재배포가 허용된다.
- 각 라이선스 원문을 프로젝트의 폰트 라이선스 디렉터리에 함께 포함한다.

공식 출처:

- 조선일보 전용서체: <https://event.chosun.com/100/100font.html>
- 네이버 마루 부리 및 라이선스: <https://hangeul.naver.com/font>
- Black And White Picture OFL: <https://github.com/google/fonts/blob/main/ofl/blackandwhitepicture/OFL.txt>

### 3.3 Unity 적용 구조

`RuntimeUiFactory`에 한 개의 전역 서체가 아니라 의미 기반 역할을 제공한다.

```text
Title
Body
BodyEmphasis
Damage
```

호출부는 구체적인 리소스 경로가 아닌 역할을 요청한다. 각 역할은 정적 캐시를
사용하고 누락 시 Noto Sans KR로 폴백한다. 한국어 전체와 숫자를 포함하는 동적 TMP
폰트 에셋을 만들되, 런타임마다 새 atlas나 material을 만들지 않는다.

## 4. 색상과 가독성

한지 위 텍스트는 저대비 회색을 금지하고 다음 역할 색을 사용한다.

| 역할 | 기준색 | 목적 |
| --- | --- | --- |
| 한지 본문 | 짙은 먹색 `#2B2118` | 작은 글자 가독성 |
| 한지 보조 설명 | 갈색 먹색 `#67533A` | 계층은 낮추되 읽을 수 있게 유지 |
| 어두운 패널 본문 | 따뜻한 한지색 `#F4E6BE` | 검은/남색 배경 대비 |
| 강조 금색 | `#D7A62A` | 확정값, 희귀 결과 |
| 낙관 주홍 | `#A93425` | 등급과 최종 확정 |
| 청록 포인트 | 기존 UI 청록 계열 | 선택 상태와 진행 표시 |

텍스트에는 배경과 같은 계열의 낮은 알파값을 사용하지 않는다. 작은 글자는 그림자나
외곽선보다 먼저 명도 대비와 크기로 해결하고, 효과는 한 단계만 사용한다.

## 5. 한글 현지화

추가옵션 enum을 직접 문자열로 출력하지 않고 하나의 표시명 매퍼를 사용한다.

| 내부 값 | 결과 표시 |
| --- | --- |
| `Damage` | `피해량 +N%` |
| `Cooldown` | `재사용 대기시간 -N%` |
| `Area` | `공격 범위 +N%` |
| `ProjectileSpeed` | `투사체 속도 +N%` |
| `Duration` | `지속 시간 +N%` |

`Cooldown`만 실제 강화 의미에 맞춰 빼기 부호를 유지한다. 증강 선택 카드, 감정 결과,
무기 랙 요약이 같은 매퍼를 사용해 표현이 다시 갈라지지 않게 한다. 플레이어에게
노출되는 `CONFIRM`, `LEVEL`, 영문 옵션명도 같은 작업에서 검색해 한국어로 정리한다.

## 6. 증강 선택 화면

- 카드 내부는 기존의 불투명 한지 면을 유지한다.
- 제목은 마루 부리 SemiBold와 짙은 먹색을 사용한다.
- 분류 라벨과 설명은 마루 부리 Regular를 사용하되 현재보다 한 단계 진하게 한다.
- 텍스트 안전 영역은 두루마리 끝 장식과 분리하며 카드 수직 중앙에 맞춘다.
- 화면 상단의 `레벨 N · 강화를 선택하세요`는 조선궁서체를 사용한다.
- 모든 영문 옵션명과 영문 버튼은 한국어로 바꾼다.

## 7. 무기 감정/상세 화면

### 7.1 배경 재구성

현재 405×210 픽셀 영역을 세로 팝업 전체로 늘리는 방식은 허용하지 않는다. 픽셀이
깨져 보이는 현재 상태는 최종 품질 기준에 맞지 않는다.

새 감정 패널은 다음 레이어로 분리한다.

1. 해상도 독립 짙은 외곽 그림자;
2. 일정한 두께의 나무/금속 테두리;
3. 반복 확대가 없는 평평한 한지 중앙면;
4. 상·하단의 작은 두루마리 장식;
5. 내용 레이어.

장식 픽셀은 가능한 한 원래 픽셀 밀도에 가까운 크기로 쓰고, 넓은 중앙 면을 채우는
용도로 사용하지 않는다. 360×640과 더 긴 세로 비율에서 모두 같은 텍스트 안전
영역을 유지한다.

### 7.2 등급 표현

엽전처럼 보이는 파란색/금색 장식 심벌을 제거한다. 그 자리는 작은 붉은 낙관으로
바꾸고 다음 글자를 표시한다.

- 일반: `일반`
- 높은 추가옵션: `고급`
- 최대 추가옵션: `최대`

낙관은 조선궁서체를 사용하고 등급별로 크기와 금색 테두리 강도만 차등한다. 새로운
동전이나 메달 이미지는 추가하지 않는다.

### 7.3 문구

- `완벽한 추가옵션` → `최대 추가옵션`
- `높은 추가옵션`은 유지한다.
- `확인 · 계속` → `확인`
- 잠긴 잠재 슬롯은 `잠재 능력 슬롯 N · 잠김`으로 일관되게 표시한다.

## 8. 추가옵션 카운트업 연출

현재 수치 상승은 슬롯이 도는 동안 완료된다. 새 연출은 슬롯 정지와 수치 상승을
분리한다.

```text
슬롯 회전
  -> 감속 및 정지
  -> 옵션 이름 공개
  -> 0부터 최종값까지 정수 카운트업
  -> 최종값 펀치 및 금빛 강조
  -> 등급 낙관 확정
  -> 확인 버튼 활성화
```

### 8.1 타이밍

- 일반 옵션 카운트업: 약 0.75초
- 고급/최대 옵션 카운트업: 약 0.90초
- 값은 정수 단위로 올라가며, 20%라면 `0, 1, 2, ... 20%`를 모두 거친다.
- 초반은 빠르게 진행하고 마지막 20% 구간은 약간 늦춰 기대감을 만든다.
- 각 숫자 변경에 작은 크기 펀치를 주고, 마지막 값은 1회 크게 확대 후 복귀한다.
- 최대 옵션은 마지막 순간에 금빛 섬광과 `최대` 낙관을 동시에 확정한다.
- 확인 버튼은 최종 확정 후에만 입력 가능하다.

빠른 진행 입력은 애니메이션을 한 프레임에 없애지 않고 약 0.18초의 축약 완료
연출로 보낸다. 완료 콜백은 한 번만 발생해야 한다.

## 9. 전투 카메라

### 9.1 확인된 현재 상태

현재 `MobilePortrait` 프로필은 다음 값을 사용한다.

- 카메라 orthographic size: `7.25`
- 플레이어 scale: `.82`
- 일반 적 scale: `.78`

가로 프로필의 카메라 크기 `10.5`보다 세로 프로필이 더 가까워, 사용자에게 캐릭터와
무기가 다시 커진 것처럼 보이는 현재 체감은 타당하다.

### 9.2 목표

전투 월드 오브젝트의 화면상 높이를 현재의 약 40%로 낮춘다. 1차 기준은 현재
`7.25`에서 약 2.5배 줌아웃한 `18.125`이며 실제 적용 상수는 `18.0`으로 정리한다.

- 플레이어, 적, 무기, 투사체, 월드 드롭이 함께 작아진다.
- Screen Space HUD, 증강 선택, 감정 팝업은 현재 화면 크기를 유지한다.
- 플레이어는 화면 중앙 추적을 유지한다.
- 카메라 흔들림의 화면상 강도는 줌아웃 후에도 과장되지 않게 재검증한다.

### 9.3 전투 압력 보존

카메라를 멀리하면 현재 viewport 외곽 기반 생성 위치도 약 2.5배 멀어진다. 단순히
카메라 값만 바꾸면 적이 플레이어에게 도달하는 시간이 길어지고 전투가 비어 보일 수
있다. 따라서 생성 거리를 카메라 배율과 분리한다.

- 일반 적의 생성 거리는 기존 전투 도달 시간을 기준으로 제한한다.
- 새 적은 넓어진 화면의 바깥쪽 구역에서 보일 수 있지만 중앙에 갑자기 팝업되지
  않도록 주변부 밴드에서 등장한다.
- 보스/중간보스는 별도의 안전한 주변부 생성 규칙을 유지한다.
- active enemy cap, 웨이브 구성, 몬스터 종류는 이번 작업에서 변경하지 않는다.

화면상 목표 크기는 캡처에서 기존 대비 0.33~0.50배 범위여야 하며 기본 목표는
0.40배다. 2.0배, 2.5배, 3.0배 비교 캡처 중 2.5배를 기본안으로 검증하고, 텍스트와
실루엣이 모바일 기준에서 무너지면 2.0배 쪽으로만 완화할 수 있다.

## 10. 상태와 데이터 흐름

- 도메인의 추가옵션 확률, 수치, 잠재 능력 적용은 변경하지 않는다.
- 표현용 현지화 매퍼가 enum과 부호를 화면 문자열로 변환한다.
- 감정 presenter는 `회전`, `정지`, `카운트업`, `확정`, `입력 가능` 상태를 소유한다.
- 폰트 역할은 런타임 UI factory에서 공급하고 presenter는 역할만 선택한다.
- 카메라 프로필은 화면 크기와 spawn presentation 규칙을 제공하되 웨이브 데이터는
  수정하지 않는다.

## 11. 오류와 폴백

- 역할별 TMP 폰트를 찾지 못하면 Noto Sans KR로 대체하고 한 번만 오류를 기록한다.
- 글리프가 없으면 fallback font asset을 사용해 네모 문자를 방지한다.
- 감정 연출이 중단되거나 화면이 닫혀도 게임 시간과 완료 콜백이 중복되지 않는다.
- 카메라가 scene에 없으면 기존 런타임 생성 경로가 같은 줌아웃 프로필을 사용한다.
- 감정 배경 장식이 없더라도 한지 중앙면과 텍스트는 정상 표시한다.

## 12. 검증 기준

### 자동 검증

- 서체 역할마다 올바른 TMP font asset이 할당된다.
- 모든 플레이어 노출 추가옵션 이름이 한국어이며 enum 이름이 직접 노출되지 않는다.
- `Cooldown`은 `-N%`, 나머지 강화 수치는 `+N%`로 표시된다.
- 20% 카운트업이 0부터 20까지 단조 증가하고 최종값을 건너뛰지 않는다.
- `완벽한 추가옵션`, `확인 · 계속`, `Area +`, `Damage +` 문자열이 플레이 화면에
  남지 않는다.
- 빠른 진행과 일반 진행 모두 완료 이벤트가 정확히 한 번 발생한다.
- 카메라 orthographic size와 목표 화면상 크기 비율을 검증한다.
- 줌아웃 후 생성 위치와 예상 도달 시간이 허용 범위 안에 있다.

### PlayMode/수동 검증

- 360×640 기준 증강 카드의 제목과 설명이 한눈에 읽힌다.
- 감정 화면의 중앙 한지가 확대 픽셀 블록처럼 보이지 않는다.
- 등급 표식이 엽전이 아니라 붉은 낙관으로 인식된다.
- 최대 20% 결과에서 0→20 상승과 마지막 펀치가 명확히 보인다.
- 일반, 고급, 최대, 신규 잠재 1~3개 결과가 모두 레이아웃을 벗어나지 않는다.
- 전투 캡처에서 플레이어와 일반 적이 기존 대비 약 40% 화면 크기로 보인다.
- HUD와 모달의 화면 크기는 카메라 변경 전과 동일하다.
- 줌아웃 후 전투 시작부와 급습 구간이 장시간 비어 있지 않는다.
- Unity Console에 새로운 error 또는 exception이 없다.

- 무기 공격 패턴 단순화
- 감정 화면 전체 신규 원화 제작
- 로비, 상점, 장비 메뉴 전면 개편
