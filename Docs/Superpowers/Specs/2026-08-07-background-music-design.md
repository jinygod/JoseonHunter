# 배경음악 시스템 설계

작성일: 2026-08-07  
대상 프로젝트: JoseonHunter Unity

## 목표

조선 요괴 판타지의 정체성을 유지하면서도 15분 전투의 압박 상승을 음악으로 전달한다. 음악은 효과음을 덮지 않아야 하며, 반복 플레이와 모바일 장시간 실행에서도 피로하지 않아야 한다.

음악 방향은 국악기와 현대 액션 타악·베이스를 섞은 형태로 고정한다. 이번 적용에서는 CC0 음원만 사용하며 보컬이나 알아들을 수 있는 대사가 포함된 곡은 제외한다.

## 첫 적용 범위

현재 플레이 가능한 `귀곡 들판`과 로비에 필요한 여섯 역할만 편입한다.

| 역할 | 재생 시점 | 음악적 성격 |
|---|---|---|
| 로비 | 로비 진입부터 출전 로딩 전환까지 | 75~85 BPM, 잔잔한 가야금·대금, 매우 약한 현대 베이스 |
| 전투 초반 | 0:00~5:00 | 약 95 BPM, 거문고 리듬과 가벼운 장구, 여유 있는 사냥 |
| 전투 중반 | 5:00~10:00 | 110~120 BPM, 북과 베이스를 보강한 압박 상승 |
| 전투 후반 | 10:00~최종보스 전 | 약 130 BPM, 강한 북·현대 타악과 짧은 국악 선율 |
| 중간보스 | 중간보스 생존 중 | 낮은 북과 불규칙한 장단, 일반 전투보다 긴장감 있게 구성 |
| 최종보스 | 최종보스 생존 중 | 대북·징·저음 베이스 중심의 가장 위압적인 구성 |

승리와 패배 화면은 긴 배경음악을 새로 추가하지 않고 현재 결과 효과음을 사용한다. 최종보스 격파 또는 런 종료 시 전투 음악을 정지한다.

## 스테이지 변주 원칙

세 스테이지가 모두 같은 음악처럼 들리지 않도록 공통 구간 구조 위에 지역별 악기와 공간음을 얹는다.

- 귀곡 들판: 대금 숨소리, 거문고, 바람의 공간감
- 도깨비 고개: 장구와 북, 장난스럽지만 거친 엇박
- 월식 왕릉: 해금, 징의 긴 잔향, 낮고 음산한 공간음

`도깨비 고개`와 `월식 왕릉`은 아직 플레이 콘텐츠가 없으므로 이번 작업에서 음원을 미리 편입하지 않는다. 각 스테이지가 실제 구현될 때 공통 전투 구조에 맞는 변주 음원을 추가한다.

난이도 `보통`, `흉조`, `대흉`은 별도 곡을 사용하지 않는다. 난이도 차이는 게임 밀도와 효과음으로 표현하고, 음악 파일 수를 불필요하게 세 배로 늘리지 않는다.

## CC0 음원 선정 기준

후보는 다음 조건을 모두 만족해야 한다.

- 상업 이용, 수정, 재배포가 가능한 CC0 또는 퍼블릭 도메인일 것
- 원본 페이지에서 라이선스를 직접 확인할 수 있을 것
- 보컬과 알아들을 수 있는 대사가 없을 것
- 기존 유명곡을 연상시키는 선율을 피할 것
- 국악기 또는 동양풍 악기와 현대 타악이 자연스럽게 섞일 것
- 무기·피격·경고 효과음을 가릴 정도로 고역과 타악이 빽빽하지 않을 것
- 자연스러운 반복 구간을 만들 수 있을 것
- 원본 URL, 제작자, 원본 파일명, 라이선스, 다운로드 날짜와 편집 내역을 문서화할 수 있을 것

조건에 맞는 완성곡을 찾지 못한 역할은 억지로 분위기가 다른 곡을 넣지 않고 비워 둔 채 다음 후보를 탐색한다.

## 재생 구조

효과음용 `GameAudioDirector`와 별도로 지속 음악만 관리하는 `GameMusicDirector`를 둔다. 이 객체는 Bootstrap에서 한 번 생성되어 장면 전환 중 유지된다.

`GameMusicDirector`는 두 개의 음악용 `AudioSource`를 번갈아 사용한다. 새 곡 요청 시 현재 소스의 음량을 낮추고 다른 소스의 음량을 높여 기본 2초 교차 전환한다. 같은 역할이 반복 요청되면 곡을 처음부터 다시 시작하지 않는다.

재생 흐름은 다음과 같다.

1. 로비 준비 완료 후 로비 음악 재생
2. 출전 로딩 중 로비 음악을 서서히 낮춤
3. Gameplay 준비 완료 후 선택된 스테이지의 초반 음악 재생
4. 전투 시간 5분과 10분을 통과할 때 다음 구간 음악으로 교차 전환
5. 중간보스 출현 시 현재 구간을 기억하고 중간보스 음악으로 전환
6. 중간보스 격파 시 현재 전투 시간에 맞는 구간 음악으로 복귀
7. 최종보스 출현 시 최종보스 음악으로 전환
8. 런 종료 시 음악을 페이드아웃하고 로비 복귀 후 로비 음악 재생

경고 효과음이 울릴 때는 음악 자체를 교체하지 않는다. 짧은 경고가 묻히지 않도록 음악 버스 음량을 잠시 낮추는 기능은 실제 청음에서 필요할 때만 추가한다.

## 파일과 모바일 설정

- 편입 위치: `Assets/JoseonHunter/Audio/Music/CC0/`
- 실행 시 참조용 음악 카탈로그를 별도 자산으로 둔다.
- 원본은 보존하고 게임용 사본만 반복 구간과 앞뒤 무음을 편집한다.
- 게임용 파일은 OGG Vorbis로 통일한다.
- Unity 임포트는 `Streaming`, 백그라운드 로드, 사전 오디오 데이터 로드 비활성화를 기본값으로 한다.
- 두 음악 소스 외에 추가 음악 소스를 만들지 않는다.
- 음악 기본 음량은 효과음보다 충분히 낮게 설정하고, 클리핑이 발생하지 않도록 여유를 둔다.

이번 범위에서는 새로운 설정 메뉴를 만들지 않는다. 음악과 효과음의 내부 볼륨 버스는 분리해 두고, 추후 설정 메뉴가 생기면 각각의 슬라이더를 연결할 수 있게 한다.

## 실패 처리

- 카탈로그에 곡이 없거나 로드에 실패하면 오류를 반복 출력하지 않고 역할별로 한 번만 경고한다.
- 음악 로드 실패가 로비 진입이나 게임 진행을 막아서는 안 된다.
- 보스 음악이 없으면 현재 전투 구간 음악을 그대로 유지한다.
- 장면 전환 중 중복 요청이 와도 음악 소스가 셋 이상 생성되거나 같은 곡이 겹쳐 재생되지 않게 한다.

## 검증

자동 검증 항목:

- 모든 편입 음악이 CC0 출처 장부에 등록되어 있다.
- 카탈로그의 여섯 역할이 실제 음악 파일을 참조한다.
- 5분·10분 경계에서 올바른 역할이 선택된다.
- 중간보스 격파 후 현재 시간대 음악으로 복귀한다.
- 같은 역할의 중복 요청은 재시작하거나 중첩 재생하지 않는다.
- 장면 전환 후에도 음악 재생기가 하나만 존재한다.
- 음악 누락 시 게임 흐름이 계속된다.

수동 검증 항목:

- 각 곡의 반복 지점에서 끊김, 클릭음, 갑작스러운 박자 변화가 들리지 않는다.
- 전투 후반에도 무기, 피격, 경고 효과음이 음악에 묻히지 않는다.
- 중간보스·최종보스 전환이 2초 안에 자연스럽게 인지된다.
- 15분 연속 플레이에서 반복 피로와 음량 클리핑이 없다.
- 안드로이드 기기에서 장면 전환 중 끊김이나 눈에 띄는 메모리 급증이 없다.

## 이번 범위에서 제외

- 음악 생성형 AI 서비스 사용
- CC-BY 등 저작자 표시가 필요한 음원
- 도깨비 고개·월식 왕릉 전용 변주
- 난이도별 별도 음악
- 승리·패배 전용 장곡
- 음악 설정 UI
