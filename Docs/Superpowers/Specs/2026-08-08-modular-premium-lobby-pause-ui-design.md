# 모듈형 프리미엄 로비·일시정지 UI 설계

## 목표

- 제공된 디자인 시안의 짙은 남청색·먹색·금색·적색 조선 판타지 분위기를 현재 로비와 일시정지 화면에 적용한다.
- 실제로 구현된 기능만 노출하며, 선택 상태와 잠금 상태를 모바일 화면에서 즉시 구분할 수 있게 한다.
- PixelLab으로 만든 모듈형 픽셀 에셋과 Unity uGUI/TMP를 조합하여 여러 모바일 해상도에서도 선명함을 유지한다.
- 하단 내비게이션은 글자 없이 픽셀 아이콘만 사용한다.

## 적용 범위

### 로비 출전 화면

- 상단 계정 정보 영역
- 스테이지 전환 제목과 좌우 화살표
- 중앙 캐릭터 및 야간 배경
- 난이도 선택 카드
- 시작 무기 카드
- 출전 버튼
- 하단 내비게이션

### 일시정지 화면

- 일시정지 안내
- 배경 음악과 효과음 슬라이더
- 계속하기 버튼
- 로비로 돌아가기 버튼

무기 연구와 수련의 내부 콘텐츠를 전면 재설계하거나 캐릭터 선택 기능을 새로 추가하는 일은 이번 범위에 포함하지 않는다. 다만 하단 내비게이션의 외형은 두 화면에도 동일하게 적용한다.

## 핵심 방향

### 모듈형 에셋 구성

시안 전체를 한 장의 고정 이미지로 사용하지 않는다. PixelLab으로 글자가 없는 프레임, 패널, 버튼, 아이콘을 각각 제작하고 Unity에서 9-slice 또는 일반 Sprite로 조립한다. 이 방식은 720×1280과 1080×2340에서 동일한 비율과 테두리 굵기를 유지하며 선택·잠금·비활성 상태를 코드로 갱신할 수 있다.

모든 한글과 숫자는 이미지에 굽지 않고 TextMeshPro로 표시한다. 폰트 크기와 줄바꿈은 현재 세이프 에어리어와 캔버스 스케일 규칙을 따른다.

### 색상 체계

- 기본 배경: 짙은 남청색과 먹색
- 일반 테두리: 탁한 황동색
- 선택 테두리: 밝은 금색과 작은 청록 포인트
- 주 행동: 어두운 적색 내부와 밝은 금색 외곽선
- 보조 행동: 먹색 내부와 황동색 외곽선
- 잠금 상태: 채도를 낮춘 먹색과 회갈색, 금색 자물쇠

흰색 외곽선, 과도한 그라데이션, 작은 픽셀 노이즈는 사용하지 않는다. 색상 수와 명암 단계를 제한해 멀리서도 형태가 읽히게 한다.

## 로비 화면 설계

### 상단 계정 정보

- 왼쪽에 계정 레벨 정사각형 배지, 중앙에 `요괴 사냥꾼` 이름과 경험치 바를 둔다.
- 오른쪽에 픽셀 엽전 아이콘과 보유량, 톱니바퀴 설정 아이콘을 배치한다.
- 현재 저장 데이터와 기존 설정 동작을 그대로 사용하며 표현만 교체한다.

### 스테이지 전환

- 화면 상단 중앙의 금색 명패에 현재 장과 스테이지 이름을 표시한다.
- 이전·다음 화살표는 캐릭터 좌우가 아니라 스테이지 명패 좌우에 배치한다.
- 화살표는 실제로 이동 가능한 방향만 활성화하고, 이동 불가능한 방향은 채도와 밝기를 낮춘다.

### 중앙 캐릭터와 배경

- 현재 플레이어 캐릭터를 중앙 타원형 금색 액자 안에 배치한다.
- 배경은 조선 야간 마을의 단순한 픽셀 실루엣으로 유지하고 캐릭터 뒤 명암만 살짝 밝게 해 분리한다.
- 캐릭터 선택 기능이나 캐릭터 전환 화살표는 추가하지 않는다.

### 난이도 카드

- `보통`, `흉조`, `대흉` 세 카드를 가로로 배치한다.
- 선택된 난이도는 밝은 금색 액자와 내부 하단 광택으로 표시한다.
- 잠긴 난이도는 텍스트에 `잠김`을 붙이지 않는다. 카드에 대각선 봉인선과 중앙 자물쇠 아이콘을 표시한다.
- 잠금 조건 안내는 잠긴 카드를 눌렀을 때 기존 피드백 영역에 한글로 출력한다.

### 시작 무기와 출전

- 시작 무기는 작은 무기 아이콘, `시작 무기` 보조 표기, 무기명, 오른쪽 이동 표시가 있는 먹색·금색 카드로 표현한다.
- 출전 버튼은 화면에서 가장 강한 적색·금색 주 행동 버튼으로 유지한다.
- 출전 불가 상태에서는 버튼 구조를 유지한 채 채도와 광택만 낮춘다.

### 하단 내비게이션

- `무기 연구`, `출전`, `수련`의 글자를 제거하고 책·교차 무기·수련 인물 형태의 픽셀 아이콘만 사용한다.
- 세 메뉴의 터치 영역 크기는 동일하게 유지한다.
- 선택된 메뉴는 밝은 금색 프레임과 적갈색 내부를 사용하고, 미선택 메뉴는 먹색 내부와 낮은 황동색 프레임을 사용한다.
- 접근성과 테스트 식별을 위해 GameObject 이름과 내부 기능 키는 기존 이름을 유지한다.

## 일시정지 화면 설계

- 전체 화면 어둡게 처리는 유지하되, 중앙 패널은 불투명한 먹색과 금색 장식 프레임으로 만든다.
- 상단에 `일시정지`, 짧은 안내 문구, 장식 구분선을 배치한다.
- 배경 음악과 효과음 슬라이더는 청록색 진행 바, 어두운 빈 바, 금색 손잡이, 오른쪽 백분율로 표시한다.
- `계속하기`는 적색·금색 주 행동 버튼으로 표시한다.
- `로비로 돌아가기`는 먹색·금색 보조 행동 버튼으로 표시한다.
- 별도의 `설정` 버튼은 만들지 않는다. 일시정지 패널 자체가 설정 화면의 역할을 겸한다.
- 버튼 동작과 저장 로직은 기존 일시정지 및 오디오 설정 흐름을 그대로 사용한다.

## PixelLab 신규 에셋

- 로비 외곽 장식 프레임
- 어두운 중앙 패널용 9-slice 프레임
- 스테이지 명패 프레임
- 타원형 캐릭터 액자
- 난이도 카드 기본·선택 프레임
- 대각선 봉인선과 자물쇠 아이콘
- 시작 무기 카드 프레임
- 주 행동·보조 행동 버튼 프레임
- 하단 메뉴 기본·선택 프레임
- 무기 연구·출전·수련 픽셀 아이콘
- 스테이지 이전·다음 화살표 아이콘
- 톱니바퀴 설정 아이콘
- 장식 구분선과 모서리 장식

에셋은 투명 배경 PNG로 저장한다. 9-slice 에셋은 모서리 장식이 늘어나지 않도록 중앙과 변 영역을 분명히 하고, 픽셀 필터는 Point로 고정한다.

## Unity 구성과 상태 흐름

- 기존 `LobbyBootstrap`, `PatrolPresenter`, `LobbyNavigationPresenter`, `AudioSettingsPresenter`, `AbandonRunPresenter`의 기능 책임은 유지한다.
- 공통 시각 규칙은 기존 `JoseonButtonSkin`과 `LobbySelectionChrome`을 확장하거나 소형 전용 스킨 유틸리티로 분리한다.
- 로비 상태 변경 시 스테이지, 난이도, 잠금, 하단 메뉴의 스프라이트와 색상이 한 번에 갱신된다.
- 일시정지 진입 시 현재 오디오 값을 표시하고, 슬라이더 조작 시 즉시 재생 볼륨과 저장 데이터에 반영한다.
- 기존 버튼 이벤트와 저장소 인터페이스는 유지해 UI 교체가 게임 진행 데이터에 영향을 주지 않게 한다.
- PixelLab 에셋 로드에 실패하면 기존 단색 배경과 텍스트가 남도록 안전한 폴백을 유지한다.

## 검증 기준

- 로비에서 상단 계정 정보, 스테이지 화살표, 난이도 카드, 시작 무기, 출전 버튼이 서로 겹치지 않는다.
- 좌우 화살표가 스테이지만 변경하고 캐릭터 선택 동작을 만들지 않는다.
- 선택 난이도와 잠긴 난이도를 색상만 보지 않아도 프레임·자물쇠·봉인선으로 구분할 수 있다.
- 하단 메뉴에는 한글 라벨이 보이지 않고 픽셀 아이콘만 표시되며 기존 세 메뉴가 정상 전환된다.
- 일시정지 화면에 별도 설정 버튼이 없고 두 오디오 슬라이더, 계속하기, 로비로 돌아가기만 존재한다.
- 오디오 설정값이 로비와 일시정지 사이에서 유지된다.
- 기존 로비, 일시정지, 오디오, 출전 PlayMode 테스트와 전체 EditMode 테스트가 통과한다.
- 720×1280과 1080×2340 캡처에서 세이프 에어리어를 벗어나거나 글자가 잘리지 않는다.

## 제외 범위

- 신규 캐릭터 선택 시스템
- 신규 로비 메뉴 또는 미구현 버튼 추가
- 난이도 해금 규칙과 스테이지 진행 규칙 변경
- 무기 연구·수련 내부 정보 구조의 전면 개편
- 이미지에 한글 문구를 직접 포함
- ImageGen 또는 비 PixelLab 이미지 생성 도구 사용
