# 한 판 전용 무기 추가옵션·잠재 잭팟 설계

## 1. 목표

레벨업 때 무기를 신규 획득하거나 강화할 때마다 기존의 고정 레벨 효과에
랜덤 추가옵션을 하나 더 부여한다. 낮은 확률로 무기 전용 잠재옵션이 최대
3줄까지 열리며, 높은 수치 또는 잠재 당첨 때만 짧고 강한 슬롯머신 연출을
사용한다.

핵심 목표는 다음과 같다.

- 같은 무기와 같은 최종진화를 선택해도 매 판 빌드가 달라진다.
- 평범한 강화는 약 1초 이내에 끝나 전투 템포를 끊지 않는다.
- 높은 추가옵션과 잠재 잭팟은 결과가 확정되기 직전 긴장감을 주고 전용
  픽셀 이펙트로 희귀성을 전달한다.
- 옵션은 해당 판에서만 유지하고 런 종료 또는 재시작 때 완전히 초기화한다.
- 모든 공격형 옵션은 기존 픽셀 마스크 접촉과 공격 인스턴스 중복 방지
  규칙을 보존한다.

## 2. 범위

이번 기능 범위에 포함한다.

- 무기별 한 판 전용 강화 프로필
- 신규 무기 획득을 포함한 매 무기 선택의 일반 추가옵션 추첨
- 잠재 0~3줄 누적과 한 번에 여러 줄이 열리는 연속 잭팟
- 8종 무기의 전용 잠재 24종
- 옵션을 실제 일반형·최종진화형 실행기에 적용하는 공통 수정자
- 빠른 슬롯머신 결과 화면과 높은 결과 전용 긴장·잭팟 연출
- HUD 무기 슬롯의 일반 옵션 및 잠재 줄 표시
- PixelLab으로 제작한 정식 슬롯·등급·속성·무기 전용 잠재 픽셀 에셋

다음 항목은 후속 범위로 분리한다.

- 캐릭터와 몬스터 크기 축소 및 몹 밀도 재조정
- 기본 경험치 획득 반경 축소와 획득 반경 증강
- 보물상자 다중 증강과 엽전·엽전뭉치·엽전주머니 보상
- 한 판 전용 옵션의 영구 저장 또는 메타 성장 전환

## 3. 상태와 소유권

`WeaponRunAffixProfile`은 무기 하나의 해당 판 상태를 소유한다.

- 무기 ID
- 현재 일반 옵션 롤 목록
- 합산된 공통 수정 수치
- 잠재옵션 0~3줄
- 원소·상태효과 정보
- 마지막 추첨 결과와 표시 등급

`WeaponRunAffixState`는 현재 획득한 무기별 프로필을 관리한다. 소유자는
`FirstPlayableController`이며 런 초기화 때 새로 만들고, 무기 실행기 재구성
시 같은 상태를 다시 전달한다. 최종진화는 프로필을 초기화하지 않고 기존
옵션을 그대로 계승한다.

무기 실행기는 원시 옵션 목록을 직접 해석하지 않는다. 공통 계산기에서
완성된 `WeaponRuntimeModifiers`를 받아 공격력, 범위, 재사용시간, 속도,
지속시간과 정수형 행동 횟수를 적용한다. 무기 전용 잠재는 ID가 명확한
작은 정책 또는 해당 실행기의 제한된 분기로 구현한다.

## 4. 강화와 추첨 흐름

1. 플레이어가 증강 카드에서 신규 무기 또는 보유 무기 강화를 선택한다.
2. 기존 1~5레벨의 고정 효과를 적용한다.
3. 호환 가능한 일반 추가옵션 풀에서 하나를 뽑고 수치를 확정한다.
4. 현재 잠재 줄 수에 따라 잠재 잭팟을 판정한다.
5. 잠재에 당첨되면 새 잠재 한 줄을 확정하고 연속 잭팟을 판정한다.
6. 남은 잠재 칸이 있고 연속 판정에 성공하면 같은 추첨에서 2~3줄까지
   차례로 공개한다.
7. 결과를 프로필에 저장한 뒤 무기 실행기를 안전하게 재구성한다.
8. 슬롯 결과 화면을 표시하고 자동으로 닫는다.

결과는 즉시 확정되며 재굴림이나 확인 버튼은 없다. 이미 보유한 잠재는
다시 후보에 들어가지 않는다. 무기 특성에 맞지 않는 일반 옵션과 잠재도
후보에서 제외한다.

## 5. 일반 추가옵션

일반 옵션은 무기를 선택할 때마다 반드시 하나가 붙는다. 같은 항목은 다시
나올 수 있으며 수치는 합산한다.

| 계열 | 수치 | 표시 방식 |
| --- | --- | --- |
| 공격력 | +10~30% | 퍼센트 |
| 재사용 대기시간 | -5~12% | 퍼센트 |
| 범위 | +8~20% | 퍼센트 |
| 투사체 속도 | +10~30% | 퍼센트 |
| 지속시간 | +10~25% | 퍼센트 |

무기 태그로 후보를 제한한다. 투사체가 없는 무기에 투사체 속도를 주거나,
지속 개체가 없는 공격에 지속시간을 주는 식의 무효 롤은 허용하지 않는다.

생존 옵션을 후속 확장할 때는 최대 체력·회복·방어를 절대값으로, 투사체
수·관통·연쇄 횟수를 정수로, 치명타 확률을 퍼센트포인트로 표시한다. 잠재
옵션에서만 강한 최대 체력 비율 증가 같은 예외를 허용한다.

### 결과 등급

수치 범위 내 위치로 표시 등급을 정한다.

- 일반: 하위 75%. 빠른 기본 연출.
- 상급: 상위 20%. 회전 감속과 금빛 테두리를 추가한다.
- 극상: 상위 5%. 정지 직전 짧은 암전·정적과 무기색 폭발을 추가한다.

등급은 연출과 문구만 결정하며 이미 확정된 수치를 바꾸지 않는다.

## 6. 잠재 잭팟 확률

매 신규 획득과 레벨 강화에서 잠재를 판정한다.

- 잠재 0줄: 5%
- 잠재 1줄: 2%
- 잠재 2줄: 0.5%
- 잠재 3줄: 추첨 종료

첫 잠재가 당첨된 같은 추첨에서 남은 칸을 대상으로 연속 판정을 한다.

- 다음 줄 연속 당첨: 8%
- 그다음 줄 연속 당첨: 1%

따라서 한 번에 두 줄 또는 세 줄이 열릴 수 있지만 세 줄 동시 당첨은
극도로 희귀하다. 모든 확률과 수치 범위는 단일 설정 카탈로그에 두어 코드
변경 없이 밸런스를 조정할 수 있게 한다.

## 7. 무기 전용 잠재 24종

### 환도 비검

- `독아`: 실제 칼날 접촉 시 중독을 누적한다. 녹색 독액 픽셀과 보라색
  지속 피해 숫자를 사용한다.
- `잔영회수`: 귀환 적중 뒤 같은 궤적을 잔영이 지연 추적한다.
- `비검연무`: 서로 다른 적을 연속 적중할수록 해당 투척의 피해가 상승하고
  궤적이 백색, 금색, 적색으로 변한다.

### 각궁

- `파갑촉`: 첫 관통 대상에게 파갑을 걸어 이후 받는 피해를 증가시킨다.
- `갈래깃`: 적중 지점에서 얇은 소형 화살 두 발이 사선으로 분열한다.
- `만력장궁`: 이동 거리에 따라 피해와 화살 크기, 화살촉 광량이 증가한다.

### 주술부적

- `오행순환`: 화염, 빙결, 번개 부적을 투척마다 순환한다.
- `봉인전이`: 봉인 대상이 죽으면 가장 가까운 유효 적에게 봉인이 이전된다.
- `역귀폭부`: 봉인 대상 사망 시 작은 귀화가 가까운 적을 찾아 접촉 폭발한다.

### 벽력탄

- `지맥잔뢰`: 본 폭발 뒤 바닥 균열에서 지연 낙뢰가 한 번 발생한다.
- `뇌심과충전`: 흡인한 적 수에 따라 압축 폭발 피해와 중심 광량이 증가한다.
- `피뢰표식`: 가장 강한 적에게 표식을 남기고 잠시 뒤 수직 낙뢰로 재공격한다.

### 장승진

- `귀면장승`: 낙인된 적을 진 중심 반대 방향으로 밀어내며 장승 눈이 붉게
  점등한다.
- `사방결계`: 네 번째 장승 완성 시 경계가 한 바퀴 회전하며 실제 접촉
  피해를 준다.
- `수호신강림`: 완성된 진에서 작은 수호령이 나타나 낙인 대상 하나를
  응징한다.

### 신기전

- `화약궤적`: 로켓 비행 경로에 짧은 화염선을 남기고 접촉한 적에게 화상을
  건다.
- `자탄분열`: 집중탄 적중 시 소형 자탄 세 개가 가까운 유효 적에게 분산된다.
- `연쇄점화`: 집중 포격으로 적을 처치하면 남은 로켓이 다음 밀집군으로
  재조준된다.

### 서리병

- `균열표식`: 빙결 체류 시간에 따라 취약을 중첩해 파쇄 피해를 높인다.
- `서리전염`: 파쇄 지점의 냉기가 주변 유효 적에게 퍼져 빙결 체류를
  시작한다.
- `빙무`: 장판 가장자리의 서리 안개가 지속시간 동안 범위를 확장한다.

### 풍뢰선

- `진공인`: 바람날의 실제 접촉 대상에게 출혈을 건다.
- `원뢰증폭`: 부채에서 멀리 있는 표식일수록 낙뢰 피해가 증가한다.
- `회천연쇄`: 귀환 낙뢰로 적을 처치하면 가까운 표식 대상으로 한 번 더
  튕긴다.

## 8. 슬롯머신 UX

평범한 결과는 전투 흐름을 거의 끊지 않는다.

- 카드 선택·전환: 0.10초
- 일반 슬롯 회전: 0.35초
- 감속·정지: 0.20초
- 결과 강조·자동 종료: 0.30초
- 총 소요: 약 0.95초

상급 또는 극상 추가옵션만 회전음의 피치가 낮아지고 정지 직전 짧은
긴장 구간을 넣는다. 잠재 잭팟은 다음 최대 시간을 사용한다.

- 잠재 1줄: 1.3초
- 잠재 2줄: 1.6초
- 잠재 3줄: 1.9초

화면을 터치하면 결과는 바꾸지 않고 연출만 단축한다. 일반 결과는 약
0.3초, 3줄 잭팟도 최대 0.7초 안에 확인 가능하다. 확인 버튼은 없으며
연속 레벨업이 대기 중이면 자동 종료 뒤 바로 다음 카드 선택으로 넘어간다.

HUD 무기 슬롯에는 누적 일반 옵션의 작은 요약과 잠재 3칸을 표시한다.
잠재가 열릴 때 해당 무기 슬롯이 전용 색으로 한 번 강하게 점등된다.

## 9. PixelLab 에셋 제작 원칙

임시 도형이나 단색 대체물을 최종 화면에 사용하지 않는다. 코드 구현 전에
필요한 에셋을 시트 단위로 목록화하고 PixelLab API 호출을 묶는다.

최소 제작 묶음은 다음과 같다.

- 슬롯 프레임, 회전 심벌, 감속·정지·잭팟 프레임
- 일반·상급·극상 등급 테두리와 잠재 1·2·3줄 공개 이펙트
- 독·화상·빙결·출혈·파갑·봉인·피뢰 표식
- 무기 전용 잔영, 분열 화살, 귀화, 지맥 균열, 수호령, 자탄, 빙무,
  왕복 낙뢰 파츠

같은 팔레트와 규격으로 재사용 가능한 심벌 시트를 먼저 만들고 무기 전용
파츠만 별도 생성한다. 원본 알파와 피해 마스크를 분리해 장식 글로우나
연기는 접촉 픽셀에 포함하지 않는다. 생성 전 프롬프트와 수량을 확정해
불필요한 변형 생성을 피한다.

## 10. 접촉, 중복 피해와 실패 처리

- 추가 피해와 상태효과는 원 공격의 실제 픽셀 접촉이 확인된 뒤에만
  시작한다.
- 잔영, 분열탄, 자탄, 귀화, 지연 낙뢰는 각각 명시적인 공격 인스턴스와
  반복 타격 정책을 가진다.
- 대상이 죽거나 등록 해제되면 추적·전이·연쇄 대상에서 건너뛴다.
- 호환 가능한 일반 옵션 후보가 없으면 무효 옵션을 주지 않고 공격력 후보를
  사용한다.
- 잠재 카탈로그가 부족하거나 중복만 남으면 해당 잠재 판정을 종료하고
  일반 옵션 결과는 유지한다.
- 슬롯 연출이 중단되거나 오브젝트가 비활성화되어도 게임 상태에 이미
  확정된 결과는 유실되지 않는다.

## 11. 검증 기준

- 같은 시드와 상태는 같은 일반 옵션, 수치와 잠재 결과를 만든다.
- 신규 무기 획득과 레벨 2~5 강화 모두 일반 옵션을 정확히 하나 추가한다.
- 잠재는 3줄을 넘지 않고 중복되지 않으며 한 번에 여러 줄이 열릴 수 있다.
- 최종진화와 실행기 재구성 후에도 프로필이 유지된다.
- 무효 태그 옵션이 후보에 나오지 않는다.
- 전용 잠재 24종이 일반형과 최종진화형에서 정의된 방식으로 작동한다.
- 추가 공격은 실제 접촉, 공격 인스턴스와 중복 피해 규칙을 지킨다.
- 일반 결과는 약 0.95초, 잠재 3줄도 1.9초 이내에 자동 종료한다.
- 터치 단축은 결과를 바꾸지 않는다.
- PixelLab 장식 픽셀은 피해 마스크에 포함되지 않는다.
- 런 재시작 후 모든 일반 옵션과 잠재 줄이 초기화된다.
