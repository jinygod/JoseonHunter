# 무기 전승 분기·상태 연계·특수 적 설계

작성일: 2026-08-03

대상 프로젝트: JoseonHunter Unity 세로형 수직 프로토타입

상태: 사용자 구두 승인 완료, 구현 계획 작성 전

## 1. 목표

현재의 레벨업 선택은 무기를 많이 모으고 수치가 높은 선택지를 고르는 흐름에 가깝다. 이 설계의 목표는 한 판마다 다음 세 가지 판단을 만들면서도, 속성표를 외워야 하는 복잡한 게임은 피하는 것이다.

1. 네 개뿐인 무기 슬롯에 무엇을 남길지 선택한다.
2. 각 무기의 두 전승 경로 중 하나를 선택하고 반대 경로를 포기한다.
3. 상태 연계와 특수 적 대응을 고려해 무기 조합을 완성한다.

어떤 정상적인 무기 조합도 기본 난이도를 클리어할 수 있어야 한다. 연계를 잘 구성한 빌드는 그렇지 않은 빌드보다 화력 또는 생존 효율이 약 25~35% 좋아지는 것을 목표로 한다. 잘못된 선택 하나 때문에 한 판이 사실상 실패하는 함정 선택은 만들지 않는다.

이 설계는 현재 한 판의 길이와 전체 콘텐츠 양을 늘리지 않는다. 선택의 질, 전투 판독성, 반복 플레이 차이를 높이는 데 범위를 한정한다.

## 2. 핵심 선택 구조

### 2.1 슬롯 제한

- 무기 슬롯은 최대 4개다.
- 보조 능력 슬롯은 최대 3개다.
- 빈 무기 슬롯이 있으면 새 무기를 바로 획득한다.
- 네 슬롯이 찬 뒤 새 무기를 고르면 교체 화면을 연다.
- 플레이어는 기존 무기 하나를 버리고 새 무기를 받거나, 새 무기를 포기하고 현재 무기 강화 선택으로 돌아간다.

### 2.2 교체 비용

- 버린 무기는 해당 판에서 다시 등장하지 않는다.
- 버린 무기의 레벨, 전승 경로, 추가옵션은 모두 사라진다.
- 새 무기는 `버린 무기 레벨 - 1`로 들어온다.
- 새 무기의 시작 레벨은 최소 1, 최대 3이다.
- 새 무기가 3레벨로 들어오면 즉시 전승 경로 선택 화면을 연다.

이 규칙은 교체를 의미 있는 기회비용으로 만들면서도 후반 교체가 완전히 손해가 되는 것을 막는다.

### 2.3 성장 순서

| 레벨 | 역할 | 선택 여부 |
|---|---|---|
| 1~2 | 기본 공격 방식과 성능 강화 | 일반 레벨업 선택 |
| 3 | 두 전승 경로 중 하나 선택 | 전용 양자택일 화면 |
| 4 | 선택한 경로의 핵심 효과 강화 | 자동 적용 |
| 5 | 선택한 경로의 완성 기술 해금 | 자동 적용 |

3레벨 화면에는 긴 설명 대신 다음 세 줄을 크게 표시한다.

- 전투 방식
- 강해지는 점
- 감수해야 할 약점

선택한 경로의 반대편은 해당 판에서 잠긴다.

## 3. 추가옵션과 잠재능력

- 현재의 추가옵션 숫자 상승 연출은 유지한다.
- 추가옵션은 공격력, 범위, 재사용 대기시간과 같은 보조 수치만 담당한다.
- 기존의 무작위 잠재능력 효과는 3·4·5레벨 전승 경로 효과로 재배치한다.
- 선택한 경로와 충돌하는 잠재능력이 무작위로 붙지 않는다.
- 무기 상세 화면의 잠재 슬롯 영역은 `전승 경로`, `현재 경지`, `다음 경지` 표시로 바꾼다.
- 추가옵션 결과가 빌드 방향을 바꾸지는 않지만 같은 분기 안에서 작은 행운과 성장감을 제공한다.

## 4. 여덟 무기의 열여섯 전승 경로

아래 비율은 현재 무기의 기본 성능을 기준으로 한 첫 구현값이다. 첫 통합 플레이 테스트에서 한 번에 ±10% 범위로 조정할 수 있지만, 장점과 약점의 방향은 바꾸지 않는다.

| 무기·경로 | 3레벨 선택 | 4레벨 강화 | 5레벨 완성 |
|---|---|---|---|
| 환도 비검·독니 | 직접 피해 -20%, 4초간 독 피해 | 중독된 적 사망 시 주변 3마리로 전염 | `혈독난무`: 중독된 적을 연속 베고 독 폭발 |
| 환도 비검·월식 | 재사용 대기시간 +20%, 되돌아오는 70% 피해 잔영 | 교차하는 두 번째 잔영 | `환도·월식`: 교차점에서 220% 폭발 |
| 각궁·관일 | 공격 속도 -20%, 관통 +3, 관통마다 피해 +15%(최대 +60%) | 2.5초간 방어력 25% 감소 | `각궁·관일`: 우두머리 피해 +30%, 마지막 관통 폭발 |
| 각궁·갈래깃 | 화살 피해 -25%, 70% 피해 화살 3발 | 60% 피해 화살 5발 | `천우산개`: 네 번째 사격마다 부채꼴 일제사격 |
| 주술 부적·천쇄봉인 | 직접 피해 -25%, 적을 2초간 봉인 | 봉인된 적이 받는 피해 +15% | `천쇄부진`: 봉인된 적의 죽음이 주변 봉인을 연쇄 폭발 |
| 주술 부적·원귀폭발 | 봉인 전염 제거, 0.6초 뒤 200% 범위 폭발 | 범위 +30%, 두 번째 작은 폭발 | `백귀폭진`: 최대 3회 연쇄 폭발 |
| 벽력탄·뇌옥 | 재사용 대기시간 +25%, 1초간 끌어당김 | 중심부 피해 +60%, 끌어당김 강화 | `벽력탄·뇌옥`: 압축된 적에게 300% 중심 폭발 |
| 벽력탄·지맥 | 최초 폭발 피해 -30%, 3초간 지면 전류 | 지속시간 4초, 최대 3마리 연쇄 | `뇌맥연쇄`: 처치 시 최대 5마리로 전류 확산 |
| 장승진·사방수호 | 공격 피해 -30%, 사방 결계와 밀쳐내기 | 접촉 피해 20% 감소, 결계 강화 | `십이지신 장승진`: 네 방향에서 세 차례 수호 파동 |
| 장승진·수호신강림 | 결계 유지시간 -40%, 180% 피해 내려찍기 | 두 번째 내려찍기 | `산신강림`: 중심부에 320% 대형 내려찍기 |
| 신기전·화룡포 | 공격 범위 -35%, 지정 적 집중 포격 | 강한 적 우선 조준, 총피해 +60% | `신기전·화룡포`: 표적에 다섯 차례 집중 포격 |
| 신기전·화망 | 최초 폭발 피해 -30%, 3초간 화약 흔적 | 처치 시 주변 3마리에 점화 | `연화화망`: 연결된 화약 흔적 동시 폭발 |
| 서리병·빙무 | 직접 피해 -35%, 범위 +35%, 둔화 45% | 세 번 맞은 적을 빙결하고 받는 피해 +10% | `서리병·빙화원`: 서리꽃이 세 차례 피어나며 빙결 |
| 서리병·파쇄 | 장판 지속시간 -50%, 착지 피해 +50% | 빙결을 소모해 180% 범위 파쇄, 최대 3마리 연쇄 | `빙결파쇄`: 최대 5마리까지 연쇄 파쇄 |
| 풍뢰선·진공 | 번개 피해 -30%, 끌어당김 +50%, 출혈 3중첩 | 출혈 3중첩 시 추가 파열 피해 | `회천풍진`: 진공 소용돌이가 반복 파열 |
| 풍뢰선·천뢰 | 끌어당김 제거, 70% 피해로 최대 4회 튕김 | 천뢰 표식 후 되돌아오며 80% 추가 피해 | `풍뢰선·천뢰귀환`: 최대 7회 연쇄 후 표식 중심 폭발 |

분산형 공격의 동시 투사체와 연쇄 대상 수는 표의 상한을 넘지 않는다. 이는 화면 판독성과 성능을 함께 지키기 위한 제한이다.

## 5. 상태 연계

한 타격은 최대 한 종류의 연계만 일으킨다. 같은 적에게 발생하는 연계에는 약 0.6초의 재발동 제한을 둔다. 연계는 필수 정답이 아니라 조합을 발견한 플레이어에게 주는 보너스다.

| 연계 | 조건 | 결과 | 기회비용 |
|---|---|---|---|
| 빙쇄 | 빙결된 적에게 폭발 또는 강공격 | 빙결을 소모하고 주변에 얼음 파편 피해 | 안전한 제어 시간을 순간 화력으로 바꿈 |
| 화풍 | 화상 또는 중독된 적에게 바람·끌어당김 | 남은 지속시간 일부를 소모하고 최대 4마리에 전염 | 단일 대상 지속 피해를 군중 확산으로 바꿈 |
| 파진 | 봉인 또는 방어력 감소 적에게 베기·관통 | 표식을 소모하고 강한 추가 피해 | 약화 유지 시간을 즉시 피해로 바꿈 |
| 과부하 | 감전된 적에게 결계·밀치기·끌어당김 | 감전을 소모하고 최대 3회 연쇄 피해와 짧은 경직 | 지속 감전을 짧은 제압으로 바꿈 |

무기별 담당 상태는 다음과 같다.

- 환도 비검: 중독, 베기
- 각궁: 방어력 감소, 관통
- 주술 부적: 봉인, 원귀 폭발
- 벽력탄: 감전, 끌어당김, 폭발
- 장승진: 결계, 밀치기, 내려찍기
- 신기전: 화상, 폭발
- 서리병: 둔화, 빙결
- 풍뢰선: 바람, 끌어당김, 감전

전승 선택 카드와 무기 상세 화면에 가능한 연계를 작은 한글 표식으로 보여준다. 처음 연계를 일으키면 이름과 짧은 결과를 한 번만 표시한다.

## 6. 특수 적과 웨이브 배치

특수 적은 특정 빌드를 막는 면역 장치가 아니라, 움직임과 표적 우선순위를 바꾸게 하는 부드러운 대응 문제다. 피해 저항은 최대 35%이며 모든 빌드가 끝내 처치할 수 있다.

| 특수 적 | 성질 | 유리한 대응 |
|---|---|---|
| 방패 도깨비 | 정면 직접 피해 35% 감소 | 끌어당김, 측후면 공격, 범위 공격 |
| 원혼 무당 | 주변 일반 적을 강화 | 장거리 관통, 연쇄 공격, 우선 표적화 |
| 돌진 쇠뿔귀 | 명확한 예고 뒤 직선 돌진 | 빙결, 밀치기, 결계 |
| 분열 쥐 | 죽을 때 작은 쥐로 분열 | 상태 전염, 범위 공격, 연쇄 공격 |

웨이브 배치 원칙은 다음과 같다.

- 초반에는 일반 쥐 중심으로 기본 전투를 익힌다.
- 중반에는 특수 적을 한 종류씩 소개한다.
- 후반에는 특수 적을 최대 두 종류까지 조합한다.
- 특수 적은 화면에 보이는 적의 25%를 넘지 않는다.
- 최초 등장 시 짧은 한글 안내와 공격 예고를 보여준다.
- 동시에 어려운 특수 적 둘을 처음 소개하지 않는다.

## 7. 전투 표시와 아트 방향

새 이미지는 PixelLab을 사용해 다음 범위만 제작한다.

- 32×32 또는 48×48 전승 분기 문양 16개
- 특수 적 4종의 기본 스프라이트
- 특수 적별 2~4프레임 공격 예고 동작
- 상태 연계 표식 4개

무기 본체 이미지는 이 기능을 위해 전부 다시 만들지 않는다. 분기 공격 효과는 기존 무기 스프라이트와 Unity의 단순한 도형·파티클·색 변화를 조합한다.

PixelLab 및 전투 효과 제작 규칙은 다음과 같다.

- 투명색을 제외하고 한 이미지에 최대 3색만 사용한다.
- 흰색 외곽선을 사용하지 않는다.
- 명암은 최대 2단계로 제한한다.
- 멀리서도 읽히는 굵은 실루엣을 우선한다.
- 현실적인 질감, 자잘한 장식, 불필요한 발광을 피한다.
- Unity 임포트는 Point 필터와 무압축 또는 손실 없는 설정을 사용한다.
- 실제 게임 카메라 배율과 세로 화면에서 먼저 판독성을 검수한다.

상태 연계 효과도 화면을 덮는 별도 대형 일러스트보다 2~3색의 짧은 섬광, 파편, 원형 파동으로 표현한다.

## 8. 시스템 경계와 데이터 흐름

구현은 다음 책임을 분리한다.

1. `전승 정의`: 무기별 두 경로, 레벨별 효과, 장단점 문구를 데이터로 제공한다.
2. `전승 상태`: 현재 선택한 경로와 단계만 보관한다.
3. `슬롯·교체 규칙`: 무기 4칸, 보조 3칸, 버린 무기 잠금과 계승 레벨을 관리한다.
4. `상태 효과`: 중독·화상·봉인·방어력 감소·감전·빙결을 적 단위로 관리한다.
5. `연계 판정`: 타격 정보와 현재 상태를 받아 연계 하나만 선택해 실행한다.
6. `특수 적 행동`: 각 적의 이동·방어·강화·분열만 담당하고 웨이브 수량은 생성기가 담당한다.
7. `표시 계층`: 분기 선택, 연계 안내, 특수 적 예고를 한글 UI로 표현한다.

공격 한 번의 데이터 흐름은 다음과 같다.

`무기 공격 → 기본 피해 계산 → 전승 효과 적용 → 적 상태 확인 → 연계 하나 선택 → 피해·상태 갱신 → 화면 효과 요청`

화면 효과는 전투 결과를 결정하지 않는다. 효과 재생에 실패하거나 풀이 가득 차도 피해와 상태 처리는 정상적으로 끝나야 한다.

## 9. 성능 안전장치

- 연쇄 대상은 가장 가까운 유효 대상부터 고르고 표의 최대 수를 넘지 않는다.
- 전체 적을 매 타격마다 검색하지 않고 기존 공간 질의 또는 재사용 버퍼를 이용한다.
- 투사체, 장판, 타격 효과, 피해 숫자, 특수 적 예고는 풀링한다.
- 상태 효과는 적마다 필요한 고정 크기 데이터로 관리하고 매 프레임 새 컬렉션을 만들지 않는다.
- 지속 장판은 프레임마다 판정하지 않고 고정 간격 틱으로 처리한다.
- 화면 밖 효과와 피해 숫자는 생성하지 않거나 즉시 회수한다.
- 갈래깃, 연쇄 번개, 분열 쥐가 동시에 등장해도 각 시스템의 개체 상한을 지킨다.

## 10. 예외 처리

- 전승 데이터가 없으면 해당 무기는 기존 기본 성장으로 동작하고 오류를 한 번 기록한다.
- 잠긴 반대 경로를 다시 선택하려는 요청은 무시하고 현재 경로를 유지한다.
- 교체 대상이 없거나 새 무기 데이터가 유효하지 않으면 교체하지 않고 선택 화면으로 복귀한다.
- 상태 대상이 연계 도중 죽거나 비활성화되면 다음 유효 대상으로 넘어가며, 새 대상을 찾지 못하면 연계를 종료한다.
- 분열 쥐가 적 개체 상한에 도달한 상태에서 죽으면 추가 개체를 만들지 않고 작은 범위 피해로 대체한다.
- PixelLab 에셋 제작이 지연되면 개발용 단색 실루엣을 사용하되, 최종 검수 전에는 승인된 에셋으로 교체한다.

## 11. 검증 기준

### 자동 테스트

- 무기 4칸과 보조 3칸을 초과하지 않는다.
- 버린 무기는 같은 판의 선택 후보에서 제외된다.
- 교체 무기의 시작 레벨이 `기존 레벨 - 1`, 최소 1, 최대 3으로 계산된다.
- 3레벨에서 한 경로를 고르면 반대 경로가 잠긴다.
- 4·5레벨 효과가 선택한 경로에만 적용된다.
- 한 타격에서 연계가 하나만 발생하고 재발동 제한을 지킨다.
- 연쇄·전염·분열 개체 수가 각 상한을 넘지 않는다.
- 특수 적 저항이 35%를 넘지 않는다.
- 모든 신규 플레이어용 문자열에 영어가 노출되지 않는다.

### 플레이 테스트

- 세 가지 선택지를 3초 안에 읽고 전투 방식 차이를 설명할 수 있다.
- 정상적으로 강화한 임의의 무기 4개 조합으로 기본 난이도 클리어가 가능하다.
- 두 개 이상의 연계를 구성한 빌드는 비연계 빌드보다 화력 또는 생존에서 체감 가능한 25~35% 이득을 얻는다.
- 특수 적은 대응 무기가 없어도 처치 가능하고, 대응 수단이 있으면 행동 선택이 편해진다.
- 원거리 카메라에서 전승 효과, 상태 표식, 특수 적 실루엣이 배경과 구분된다.
- 갈래깃·지맥·분열 쥐가 함께 등장하는 부하 상황에서 심각한 프레임 저하나 첫 사용 순간의 긴 멈춤이 없다.

## 12. 구현 범위 밖

- 영구 성장과 계정 단위 메타 진행
- 새 캐릭터 또는 새 기본 무기 추가
- 한 판의 길이 변경
- 온라인 기능과 순위표
- 모든 기존 몬스터와 무기 이미지의 전면 재제작
- 하드 면역, 복잡한 속성 상성표, 세 개 이상의 동시 상태 연계
