# 프리미엄 로비 시안 충실도 재작업 설계

## 목표

사용자가 제공한 시안 이미지의 구조와 시각적 위계를 실제 모바일 로비에 가깝게 재현한다. 기존 기능과 데이터 흐름은 유지하고, 로비와 일시정지 화면의 이미지 자산·레이아웃·상태 표현만 전면 재구성한다.

기준 시안은 `codex-clipboard-8f72cace-2805-4886-975a-01e95da9dc53.png`이다.

## 현재 결과의 문제

- `panel_frame.png`가 얇은 UI 외곽선이 아니라 건축물 전체를 묘사해 중앙 콘텐츠보다 장식 비중이 크다.
- 큰 건축 프레임을 모든 메뉴에 공통 사용하면서 연구·출전·수련의 정보 구조가 구분되지 않는다.
- `card_idle_frame`과 `stage_plaque_frame`이 같은 계열의 긴 프레임이라 크기와 역할에 따른 위계가 없다.
- 선택·비선택·잠금을 동일 프레임의 색조 차이로만 표현해 작은 모바일 화면에서 즉시 구분되지 않는다.
- 기존 콘텐츠 좌표에 큰 장식 이미지를 씌워 제목, 잠금 대각선, 카드 글자가 프레임과 겹친다.
- 시안의 핵심인 얇은 테두리, 넓은 여백, 독립 카드, 명확한 붉은 주 행동 버튼이 충분히 구현되지 않았다.

## 재작업 원칙

1. 기존 거대 건축 프레임을 로비 콘텐츠 패널에 사용하지 않는다.
2. 배경 픽셀 아트와 한연화 픽셀 캐릭터는 유지한다.
3. 모든 새 UI 이미지는 PixelLab으로 제작하고 이미지 안에 글자를 넣지 않는다.
4. 새 프레임은 검정·먹갈색·낡은 금색·탁한 적색·소량의 옥색만 사용한다.
5. 흰색 외곽선, 밝은 회색 테두리, 그라데이션, 촘촘한 장식 픽셀을 사용하지 않는다.
6. 프레임과 배경판을 분리한다. 프레임 중앙은 투명하게 두고 Unity Image 색상으로 내부 면을 제어한다.
7. 1080×1920 논리 캔버스를 기준으로 구성하고 720×1280과 1080×2340에서 같은 위계를 유지한다.

## 새 모듈 자산

다음 자산을 PixelLab으로 새로 제작한다.

- `thin_outer_frame`: 전체 콘텐츠 영역을 감싸는 얇은 금색·먹색 외곽선
- `header_bar`: 계정 레벨, 경험치, 엽전을 담는 낮은 상단 바
- `stage_title_plate`: 스테이지 이름만 담는 얇은 가로 명패
- `content_backplate`: 연구·수련 설명 영역에 사용하는 단색 먹색 배경판
- `difficulty_idle`: 어두운 기본 난이도 카드
- `difficulty_selected`: 금색 테두리와 안쪽 적색 강조가 있는 선택 카드
- `difficulty_locked`: 밝기를 낮춘 잠금 카드
- `weapon_selector_frame`: 시작 무기 아이콘과 이름을 담는 낮은 카드
- `primary_red_button`: 출전·수련하기 전용 붉은 주 행동 버튼
- `secondary_dark_button`: 계속하기·로비 복귀·초기화 등 보조 행동 버튼
- `tab_idle`: 하단 메뉴 비선택 프레임
- `tab_selected`: 하단 메뉴 선택 프레임
- `small_item_frame`: 연구 무기 선택과 수련 항목에 쓰는 작은 카드
- 기존 연구·출전·수련·설정·이동·잠금 아이콘은 선명도가 충분하면 재사용하고, 부족한 것만 동일 팔레트로 재제작한다.

모든 9-slice 프레임은 모서리 장식이 8~16픽셀 안에 끝나도록 설계해 세로 또는 가로로 늘여도 건축물처럼 보이지 않게 한다.

## 공통 로비 구조

### 상단

- 화면 높이 약 8%의 낮은 헤더를 사용한다.
- 왼쪽에 계정 레벨 배지와 이름·경험치 바를 둔다.
- 오른쪽에 엽전 아이콘·보유량과 작은 설정 아이콘을 둔다.
- 헤더와 중앙 콘텐츠 사이에는 얇은 금색 선만 둔다.

### 중앙 콘텐츠

- 화면 좌우에 각각 약 4% 여백을 둔다.
- 메뉴 전체를 감싸는 외곽선은 `thin_outer_frame` 한 겹만 사용한다.
- 내부는 배경 픽셀 아트가 보이되 텍스트가 놓이는 부분만 반투명 먹색 배경판을 사용한다.

### 하단 메뉴

- 연구·출전·수련 세 칸을 동일 폭으로 배치한다.
- 글자는 표시하지 않고 픽셀 아이콘만 사용한다.
- 선택 칸은 `tab_selected`, 나머지는 `tab_idle`을 사용한다.
- 선택 칸만 금색과 적색이 살아 있고 비선택 칸은 먹색과 탁한 금색으로 낮춘다.

## 출전 화면

위에서 아래 순서로 다음 여섯 영역만 둔다.

1. `stage_title_plate`와 좌우 스테이지 화살표
2. 타원형 테두리 안의 한연화 픽셀 캐릭터
3. 보통·흉조·대흉 난이도 카드 3개
4. 시작 무기 선택 카드 1개
5. `primary_red_button` 출전 버튼
6. 하단 메뉴

난이도 카드는 캐릭터와 무기 카드 사이에 충분한 간격을 둔다. 선택 카드는 금색 이중선과 어두운 적색 안쪽선으로 표현한다. 잠금 카드는 글자를 바꾸지 않고 대각선 1개와 중앙 잠금 아이콘으로 표시한다.

## 무기 연구 화면

- 상단에 `환도 비검 연구` 제목과 무기 아이콘을 배치한다.
- 제목 아래에 숙련도 진행 바와 `연구 중 564 / 2,000` 형식의 상태를 둔다.
- 무기 선택은 4열×2행의 작은 카드로 구성한다.
- 운용법 설명은 세 개의 독립 `content_backplate` 카드로 나눈다.
- 각 카드에는 단계 이름, 상태, 핵심 효과 두 줄만 표시한다.
- 긴 설명이나 거대한 세로 프레임을 사용하지 않는다.

## 수련 화면

- 상단에 `수련` 제목과 계정 레벨에 따른 한도 문장을 둔다.
- 활력·완력·보법·학습·수호·공명을 3열×2행 `small_item_frame` 카드로 구성한다.
- 선택 수련의 현재 효과, 다음 효과, 비용은 하나의 `content_backplate`에 세 줄로 배치한다.
- 아래에는 붉은 `수련하기` 버튼과 어두운 `전체 초기화` 버튼을 나란히 둔다.
- 비용 부족 시 버튼 밝기와 안내 문구로만 상태를 표현한다.

## 일시정지 화면

- 전체 화면 중앙에 얇은 `thin_outer_frame`과 먹색 배경판을 사용한다.
- 제목·설명·장식 구분선·배경 음악·효과음·계속하기·로비로 돌아가기 순서로 배치한다.
- 별도 설정 버튼은 만들지 않는다.
- 계속하기는 붉은 주 행동 버튼, 로비 복귀는 어두운 보조 버튼을 사용한다.
- 패널 장식이 글자나 버튼보다 시각적으로 강하지 않게 한다.

## Unity 구조

- `LobbyBootstrap`, `LobbyNavigationPresenter`, `PatrolPresenter`, `WeaponResearchPresenter`, `CommonTrainingPresenter`, `AudioSettingsPresenter`, `AbandonRunPresenter`의 책임과 이벤트는 유지한다.
- `PremiumPixelUiSkin`의 프레임 종류를 새 역할별 자산으로 교체한다.
- 기존 공개 메서드와 저장 데이터 형식은 변경하지 않는다.
- `LobbySceneBuilder`는 의미별 스킨을 적용한 프리팹과 씬을 다시 생성한다.
- 현재 거대 프레임 자산은 새 자산 연결과 전체 테스트가 끝날 때까지 보관하고, 참조가 없음을 확인한 뒤 제거한다.

## 성능과 안정성

- 프레임은 Sprite Single과 Point 필터, mipmap 비활성, 무압축 설정을 유지한다.
- 런타임에 매 프레임 UI를 재생성하거나 Resources.Load를 반복하지 않는다.
- UI 스킨은 Build 또는 상태 변경 시에만 갱신한다.
- 기존 버튼 이벤트, 무기 선택, 난이도 잠금, 수련 구매, 오디오 저장 흐름을 그대로 유지한다.

## 검증 기준

- 720×1280 출전·연구·수련 화면이 기준 시안과 같은 정보 순서와 비율을 가진다.
- 1080×2340에서도 카드가 늘어지거나 텍스트가 프레임에 닿지 않는다.
- 거대한 건축 프레임이 중앙 콘텐츠를 둘러싸지 않는다.
- 선택 난이도와 선택 하단 메뉴를 1초 안에 구분할 수 있다.
- 대흉 잠금선과 잠금 아이콘이 카드 밖으로 나오지 않는다.
- 연구와 수련의 설명 카드가 서로 겹치지 않고 한 화면 안에서 읽힌다.
- 일시정지의 모든 글자와 버튼이 얇은 패널 안에 들어온다.
- EditMode와 PlayMode 전체 테스트 실패가 0이다.
- 최종 완료 전 기준 시안과 실제 720×1280 캡처를 나란히 비교한다.

## 범위 제외

- 로비에 새 메뉴나 새 게임 기능 추가
- 계정·숙련도·수련 밸런스 변경
- 한연화 신규 캐릭터 일러스트 제작
- 전투 HUD와 인게임 무기 카드 전면 개편
- 저장 데이터 마이그레이션
