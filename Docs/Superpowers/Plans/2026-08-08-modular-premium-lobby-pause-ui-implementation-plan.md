# Modular Premium Lobby and Pause UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the existing lobby deployment screen and pause overlay with a modular PixelLab-made Joseon fantasy UI kit, icon-only bottom navigation, clear stage/difficulty states, and no redundant pause settings button.

**Architecture:** PixelLab produces text-free transparent PNG frames and icons. A new `PremiumPixelUiSkin` runtime utility owns resource lookup and sprite application, while existing presenters retain navigation, save, audio, stage, and routing behavior. Editor import and scene builder code guarantee Point filtering, 9-slice borders, prefab assignment, and deterministic mobile captures.

**Tech Stack:** Unity 6.0.5 (`6000.5.5f1`), C# uGUI, TextMeshPro, Unity Test Framework, PixelLab `create_ui_asset`/`create_image_pixen`, Git on `master`.

## Global Constraints

- Work in `D:\UnityProjects\JoseonHunter` on `master`; commit and push each completed task to `origin/master`.
- Preserve unrelated modified captures, `.meta` files, and the existing modified TMP font asset; stage only paths named by the active task.
- Generate every new bitmap in this plan with PixelLab. Do not use ImageGen or draw Korean text into PNGs.
- Keep visible Korean and numeric content as TextMeshPro components.
- Use transparent PNGs, Point filtering, no mipmaps, no compression, and limited navy/ink/brass/gold/crimson/jade colors.
- Do not add character selection, new lobby destinations, or new stage/difficulty progression rules.
- Bottom navigation must show only pixel icons; retain existing GameObject names and button behavior for automation and accessibility seams.
- Pause contains background music, sound effects, `계속하기`, and `로비로 돌아가기`; it must not contain a separate settings action.
- Run Unity locally and sequentially to avoid CPU and memory spikes.

- [ ] **Step 5: Implement deterministic import settings**

```csharp
namespace JoseonHunter.Editor.AssetProduction
{
    public static class PremiumLobbyUiAssetImporter
    {
        private const string Folder = "Assets/JoseonHunter/Resources/UI/PremiumJoseon";
        private static readonly string[] Sliced =
        {
            "panel_frame", "stage_plaque_frame", "card_idle_frame", "card_selected_frame",
            "nav_idle_frame", "nav_selected_frame"
        };

        [UnityEditor.MenuItem("JoseonHunter/Assets/Import Premium Lobby UI")]
        public static void Apply()
        {
            foreach (var guid in UnityEditor.AssetDatabase.FindAssets("t:Texture2D", new[] { Folder }))
            {
                var path = UnityEditor.AssetDatabase.GUIDToAssetPath(guid);
                var importer = (UnityEditor.TextureImporter)UnityEditor.AssetImporter.GetAtPath(path);
                importer.textureType = UnityEditor.TextureImporterType.Sprite;
                importer.spriteImportMode = UnityEditor.SpriteImportMode.Single;
                importer.alphaIsTransparency = true;
                importer.mipmapEnabled = false;
                importer.filterMode = UnityEngine.FilterMode.Point;
                importer.textureCompression = UnityEditor.TextureImporterCompression.Uncompressed;
                importer.spritePixelsPerUnit = 100f;
                var name = System.IO.Path.GetFileNameWithoutExtension(path);
                importer.spriteBorder = System.Array.IndexOf(Sliced, name) >= 0
                    ? new UnityEngine.Vector4(24f, 24f, 24f, 24f)
                    : UnityEngine.Vector4.zero;
                importer.SaveAndReimport();
            }
        }
    }
}
```

```csharp
public enum PremiumFrame
{
    Panel, StagePlaque, CardIdle, CardSelected, NavigationIdle, NavigationSelected, HeroOval
}

public enum PremiumIcon
{
    Research, Patrol, Training, Previous, Next, Settings, Lock
}

public static class PremiumPixelUiSkin
{
    public static void ApplyFrame(Image image, PremiumFrame frame)
    {
        image.sprite = Resources.Load<Sprite>("UI/PremiumJoseon/" + FrameName(frame));
        image.type = frame == PremiumFrame.HeroOval ? Image.Type.Simple : Image.Type.Sliced;
        image.preserveAspect = frame == PremiumFrame.HeroOval;
        image.color = Color.white;
    }

    public static void ApplyIcon(Image image, PremiumIcon icon)
    {
        image.sprite = Resources.Load<Sprite>("UI/PremiumJoseon/" + IconName(icon));
        image.type = Image.Type.Simple;
        image.preserveAspect = true;
        image.color = Color.white;
        image.raycastTarget = false;
    }
}
```
