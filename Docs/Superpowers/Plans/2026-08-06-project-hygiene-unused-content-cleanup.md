# Project Hygiene and Unused Content Cleanup Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove which code, packages, assets, and repository artifacts are unused; remove only recoverable, high-confidence waste; then validate that the Unity project still compiles, tests, and builds for Android.

**Architecture:** Keep the current Domain/Content/Runtime/Presentation/Infrastructure/Editor assembly boundaries and Bootstrap/Lobby/Gameplay scene flow. Build a conservative reachability inventory from serialized GUIDs, C# references, Resources paths, editor callbacks, command-line entry points, tests, and generation manifests. Treat dynamic loading and source-art provenance as retained unless evidence proves otherwise.

**Tech Stack:** Unity 6000.5.5f1, C#, URP 2D, uGUI/TMP, Unity Test Framework, PowerShell, Git

## Safety Rules

- Preserve pre-existing dirty PNG metadata and unrelated local ProjectSettings changes unless a cleanup task necessarily owns the same line.
- Use Git-tracked deletion only; every removed source file remains recoverable from repository history.
- Never classify `Resources`, serialized assets, Unity callbacks, command-line methods, tests, generation sources, or license files by filename reference alone.
- Run Unity sequentially at BelowNormal priority with four-core affinity to avoid saturating the workstation.
- Commit and push each verified cleanup unit directly to `master` as requested.
