# slot-kit — affix-slot-kit-v1

Generate one **256 x 128 transparent PNG pixel-art atlas**, no text and no letters. Use the Joseon Hunter master palette and hard nearest-neighbor 1-pixel edges. Arrange exactly eight isolated 64 x 64 UI ornament sprites in a 4 columns x 2 rows grid, with clear transparent gutters and no full panel fills: upper row reel frame, standard border, high border, perfect border; lower row one-line jackpot burst, two-line jackpot burst, three-line jackpot burst, rarity flash. Dark indigo metal, old brass, vermilion accents, jade highlights. Every cell must be an ornament/frame/burst only, not a rectangular panel, not a button, no pseudo-writing, no icons of people. Fully transparent background, flat pixel shading, no anti-aliasing, no gradients, no translucent pixels.
