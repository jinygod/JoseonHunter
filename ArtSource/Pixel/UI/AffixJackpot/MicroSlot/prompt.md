# PixelLab Micro-Slot Prompt

Shared direction:

> Pixel art game UI component for a Joseon Korean folklore fantasy survivor game. Dark iron, warm brass, subtle jade glow, restrained red talisman accent, crisp hard pixel edges, centered isolated object, transparent background, no letters, no numbers, no pseudo-writing, no human, no scenery.

The shell is a wide empty shrine mechanism with one upper reel opening and three lower potential openings. Reel windows, locked shutters, anticipation symbols, stop flash, and jackpot bursts are generated as separate PNG files. The final affix and potential result icons come from the gameplay catalog and are not baked into the shell.

Rejected generation rules:

- reject casino fruit, sevens, levers, labels, or pseudo-text;
- reject an object occupying less than half its canvas when it must work as a panel;
- reject opaque backgrounds or soft antialiasing;
- reject a jackpot tier that reads weaker than the previous tier.
